# 戦闘スキル

## 意図

通常攻撃を含む戦闘行動を、武器種に制限されたスキルとして扱う。
キャラの習得スキルと、武器が付与するスキルは分ける。

## 実装の入口

- ID・表示名・必要武器: `SkillId` / `SkillDefinition` / `CombatSkillCatalog`
- 使用可能一覧: `Character.AvailableCombatSkills`
- 生成: `CombatSkillFactory`
- 個別効果: `Assets/Scripts/Combat/Skills/Implementations/`
- 実行: `CombatSkillCaster` / `SkillExecutionContext`
- AI選択: `CombatAiPlanner`

現在のSkillIdと効果の正本はコード。ここに一覧や数値を複製しない。

## 実行契約

```text
使用可能スキル → AIがPlan化 → 対象・地点を固定 → 詠唱 → 効果適用 → CT開始
```

- 詠唱中は移動と再判断を止める。
- 詠唱開始時に対象・地点・対象一覧・距離・実効ステータスを固定する。
- 開始後に対象が視界や射程から外れても、固定した文脈で完了する。
- 戦闘離脱・終了・リセット時だけ詠唱を破棄する。
- 対象が離脱した場合は不発でも完了扱いにし、CTを開始する。

## 共通の考え方

- 範囲効果は地点と対象条件を分ける。
- 認識中の敵は最後に得た情報として扱い、未認識の実位置は使わない。
- ステルス、継続効果、無敵、状態異常は共通基盤へ寄せる。
- 自傷を含むコストは、そのスキルの意図に合わせて通常ダメージか専用コストかを明示する。

射程・威力は実装コード、見た目は [スキル演出](スキル演出.md) を正本とする。
