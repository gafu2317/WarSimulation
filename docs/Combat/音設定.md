# 編成画面の音設定

編成画面の「音設定」で戦闘中BGMと通常攻撃を含む全スキルのSEを設定する。スキルは3列で一覧表示し、必要な高さに収める。残りの表示領域は4列の音素材一覧に使用する。画面に収まらない部分は各一覧をスクロールする。

1. ブラウザではPCの wav / mp3 / ogg などの音声ファイルを用意する。Editorでは Unity の Assets に追加する。
2. 編成画面の「音設定」を開く。開いてから素材を追加した場合は開き直す。
3. ブラウザではPCのファイルをBGM・スキルの割り当て欄へ直接ドロップする。「音声ファイル追加」から選択して下部一覧に追加し、一覧から各欄へドラッグしてもよい。複数ファイルをドロップした場合は先頭をその欄へ配置し、残りは一覧へ追加する。
4. ▶で試聴すると同じボタンが■に変わり、再度押すと停止する。別の音を再生した場合や再生終了時は▶へ戻る。×で割り当てを削除する。素材名のクリックでも試聴・停止できる。
5. 閉じて戦闘を開始する。BGMはループ再生し、スキルSEは詠唱完了・発動時に再生する。キャンセル・失敗したスキルでは鳴らない。

全体のBGM・SE音量に加え、BGM欄・各スキル欄と、音素材一覧の各素材にも0〜100%の音量スライダーを表示する。実際の音量は「全体音量 × 欄の個別音量 × 素材音量」。一覧からの試聴は全体SE音量と素材音量を使う。試聴中にスライダーを動かすと即座に反映し、欄の音を差し替えても欄の個別音量は維持する。試聴は同じ再生ボタンをもう一度押すか、画面を閉じると止まる。戦闘の終了、再開、編成への復帰では前の音を停止する。

Editorでは `Assets/Resources/Combat/Audio/CombatAudioSettings.asset` へ変更を自動保存するため、Playモードを終了しても設定を保持する。ビルドにもこの設定と割り当てた素材を含む。ビルド内で変更した設定はその起動中だけ保持する。

EditorではAssets内のAudioClipを素材一覧に表示する。ビルドでは設定アセットのLibraryに登録された素材を表示する。一度割り当てた素材はLibraryに残るので、欄から削除した後も再配置できる。×は素材ファイル自体を削除しない。

実装入口: `CombatAudioSettingsView` / `CombatAudioSettings` / `CombatAudioPlayer`。戦闘の開始・停止は `CombatBattleFlow`、SE発動は `CombatSkillActionEvents.Completed` と接続する。

ブラウザから追加する音声はローカルで処理し、サーバーへ送信しない。対応形式はブラウザの音声デコード機能による。1ファイル50MB、展開後の音声は約128MBまで。読込失敗は画面上部に表示する。追加した音声と割り当てはシーンを移動しても起動中は保持するが、ページの再読込では失われる。既存のWebGL配布物へ反映するには再ビルドが必要。

ゴツメのSEは反撃時、肩代わりのSEは攻撃を引き受けた時、鉄壁のSEはダメージ軽減時に再生する。この3種は使用時には再生しない。防御時の再生は `CombatDamageEvents.Resolved` と接続する。盾通常・挑発を含む他スキルは使用時に再生する。

音設定はSE/BGMタブで切り替える。SEタブはスキル一覧とSE全体音量、BGMタブは編成・戦闘中・勝利・敗北の割り当てとBGM全体音量を表示する。各BGM欄で個別音量・ループ試聴・削除ができる。音素材一覧とファイル追加は共通で、一覧の試聴は現在のタブの全体音量を使う。タブを切り替えると試聴を停止する。
戦闘中BGMは従来の設定を引き継ぐ。編成・勝利・敗北の設定は保存と試聴まで対応し、場面に応じた自動再生は未接続。
