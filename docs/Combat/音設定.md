# 編成画面の音設定

編成画面の「音設定」で戦闘中BGMと通常攻撃を含む全スキルのSEを設定する。スキルは3列で一覧表示し、画面に収まらない部分はスクロールする。

1. wav / ogg / mp3 などの音素材を Unity の Assets に追加する。
2. 編成画面の「音設定」を開く。開いてから素材を追加した場合は開き直す。
3. 下部の音素材一覧から、BGMまたはスキルの欄へドラッグ＆ドロップする。
4. ▶で試聴、×で割り当てを削除する。素材一覧のクリックでも試聴できる。
5. 閉じて戦闘を開始する。BGMはループ再生し、スキルSEは詠唱完了・発動時に再生する。キャンセル・失敗したスキルでは鳴らない。

BGMとSEの音量は個別に調整できる。試聴は閉じるか「試聴停止」で止まる。戦闘の終了、再開、編成への復帰では前の音を停止する。

Editorでは `Assets/Resources/Combat/Audio/CombatAudioSettings.asset` へ変更を自動保存するため、Playモードを終了しても設定を保持する。ビルドにもこの設定と割り当てた素材を含む。ビルド内で変更した設定はその起動中だけ保持する。

EditorではAssets内のAudioClipを素材一覧に表示する。ビルドでは設定アセットのLibraryに登録された素材を表示する。一度割り当てた素材はLibraryに残るので、欄から削除した後も再配置できる。×は素材ファイル自体を削除しない。

実装入口: `CombatAudioSettingsView` / `CombatAudioSettings` / `CombatAudioPlayer`。戦闘の開始・停止は `CombatBattleFlow`、SE発動は `CombatSkillActionEvents.Completed` と接続する。
