# スキル射程・威力

## 意図

数値はコードとアセットを正本にする。この文書では、調整時に守る関係だけを残す。

- 射程と射線は別条件にする。
- 遠距離職は安全距離を得る代わりに、近接職より接敵後の瞬間火力を抑える。
- 近接職は接敵までのリスクを、接敵後の火力で回収する。
- 回復・バフ・デバフは、支援位置と視界の価値を消さない。
- 高所の視界拡大は、全スキルの射程拡大を意味しない。
- 強い効果ほど、詠唱・CT・対象条件のいずれかで隙を作る。
- 距離補正を持つスキルは、近距離と遠距離の両方で確認する。

## 調整場所

- 武器の射程・CT・主ステ補正: `Assets/Data/Map/Weapon/*.asset`
- 個別スキル: `Assets/Scripts/Combat/Skills/Implementations/`
- 共通効果: `Assets/Scripts/Combat/Skills/CombatSkillFactory.cs`

調整後は、平地・高所・遮蔽物ありで「届く／届かない」とAIの位置取りを確認する。
数値一覧を新しく書く前に、コードとアセットの変更で済むかを確認する。
