# 岩配置デバッグUI

戦闘デバッグUIの下部にある「Iの字」「くの字」「Uの字」「まる型」から、岩の形状・向き・設置位置を選ぶ。確定すると単純なメッシュとBoxColliderで岩を生成する。同時に存在する岩は1つだけで、次の確定で置き換える。

高さは全形状3m、I・く・Uは全体約6m・厚さ1.5m、まる型は外径約6m・厚さ1.5mの輪。形状ごとに90°単位で回転でき、まる型は回転しない。岩全体がマップ内に収まらない場所は確定できない。

ボタンを押すと戦闘を一時停止し、マップ編集と同じ色分けの俯瞰図に両軍キャラと魔石の位置を重ねて表示する。撤退中のキャラも含め、マップ外のキャラは表示しない。開いた時点のカメラ前方を上に合わせ、回転した画像全体が表示領域に収まるよう縮小する。キャラ・魔石・岩の印も同じ向きで表示し、画像外の余白では位置を選択しない。再度開くと最新のカメラ方向に合わせる。座標はマップ原点の変換を適用したワールドXZ座標とする。

形状を選ぶと、前回の確定位置（初回はマップ中央）に岩の印を表示する。マップをクリックして位置を選び、左ボタンを押したままドラッグすると印と座標がリアルタイムに追従する。画像外の余白では移動せず、画像内に戻ると追従を再開する。必要なら90°ずつ回転して確定する。斜面ではTerrainCollider上の岩底面の接点を0.25m以下の間隔で調べ、底面直下の最も低い地面まで埋める。平地での最小埋め込みは2cm。地形そのものの高さは変更しない。

岩のコライダーと重なる木は元オブジェクトを非表示にする。木の幹・葉の当たり判定と視界遮蔽も同時に消える。NavMeshは保存済みデータのコピーを非同期更新し、木の元の穴を解消して岩を通行不可にする。元データと木のPrefabには変更を保存しない。実行時更新で使う木10種・既存岩5種・魔石のFBXは、Read/Writeを有効にする。

更新が完了するまで戦闘を止め、更新後は経路キャッシュを無効にして再計算する。岩に重なったキャラは近傍の有効なNavMeshへ退避させ、撤退中のキャラも経路を取り直す。輪の中央は地面として残り、輪の壁を通り抜ける経路は選べない。

確定済みの岩がある場合、設置画面の「岩を撤去」で木と元のNavMeshを復元できる。生成岩のGameObjectを無効化・削除した場合も同じ復元処理を行う。キャンセルまたはEscapeでは以前の岩を保持する。再度開くと前の位置を復元し、同じ形状なら向きも復元する。別形状は0°から始める。

閉じると元の速度・一時停止状態・カメラ操作に戻る。戦闘終了、編成への帰還、マップ変更、戦闘再開始では岩を撤去して確定結果を破棄する。実体の配置結果は `CombatMapSystem.RuntimeRockPlacement`、UIの確定結果は `CombatFlow.ConfirmedRockPlacement` から取得できる。
