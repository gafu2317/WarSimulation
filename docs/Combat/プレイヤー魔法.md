# プレイヤー魔法

戦闘デバッグUIの画面下、岩配置ボタンの隣に「広範囲魔法」「全員無敵」を表示する。プレイヤー操作専用で、通常UI、キャラの習得・装備、AIの使用候補には追加しない。マップ未準備時は使用できない。

| 魔法 | 初期値 | 対象 |
|---|---|---|
| 広範囲魔法 | 半径10m、固定40ダメージ | 指定中心からXZ距離が半径以下の敵キャラ |
| 全員無敵 | 10秒 | 両軍の戦闘参加キャラ。復帰予定の撤退中も含み、戦闘離脱済み・非表示のキャラは除く |

ボタンで開く地図は、岩配置と共通の背景生成・座標変換・カメラ方向・キャラ／魔石マーカーを使う。表示中は戦闘を止め、背後の操作とカメラ入力を遮断する。

広範囲魔法は中央から始まり、クリック・左ドラッグで中心を動かす。半透明の円は実際の効果半径を示し、地図の余白では移動しない。半径とダメージを入力欄で変更できる。全員無敵は配置と対象人数を確認し、持続秒数を変更する。半径・秒数は有限の正数、ダメージは1以上の整数が必要で、不正な値では発動できない。

「発動」で画面を閉じ、元の戦闘速度・停止状態へ戻る。広範囲魔法は神の手と同じ2.5秒の詠唱演出後、発動時点の敵位置で範囲判定してダメージとSEを発生させる。中心位置は詠唱開始時から固定する。詠唱は戦闘時間に従い、停止中は進まず、倍速では早く完了する。全員無敵は詠唱せず即時適用する。再使用待ち・消費コストはなく、広範囲魔法の詠唱中も次の魔法を選べる。戦闘終了・マップ変更・再開始では未完了の詠唱を取り消す。キャンセル・Escapeは今回の編集を破棄する。最後に発動した数値と中心は同じ戦闘内で復元し、戦闘終了・再開始・編成帰還・マップ変更では破棄する。

どちらの魔法も「発動」を押した瞬間に「魔法名発動」のカットインを表示する。カットインは1.2秒の実時間で表示し、戦闘や操作は止めない。連続使用では最新の魔法名に更新する。

範囲攻撃は `CombatHealth.TakeDamage` を使い、無敵・ダメージ軽減・撤退中の対象制限を維持する。魔石と味方には当てない。発生元は `SkillId.Player_AreaMagic` として記録し、術者キャラは生成しない。

全員無敵は既存の無敵状態を `PlayerAllInvulnerable` キーで付与する。再使用で残り時間を指定秒数へ更新する。通常の無敵スキルとは別キーで管理し、初期化時もプレイヤー魔法分だけ解除する。

初期値と範囲魔法の色は `Assets/Resources/Combat/PlayerMagicSettings.asset` に保存する。マップ画面での数値変更は戦闘中だけ保持し、このアセットには保存しない。

広範囲魔法は青系の「神の手」着弾演出を半径に合わせて拡大する。全員無敵は通常の無敵と同じ演出を対象ごとに追従表示し、無敵終了や対象破棄時に終了する。VFX確認画面でも2種類を試再生できる。

音設定には2つの専用項目を追加する。SEと音量の初期値は「神の手」「無敵」からコピーし、その後は個別に変更・試聴できる。通常スキル側の設定とは同期しない。対象人数にかかわらず、SEは発動1回につき1回再生する。
