# 戦闘AI 状況カタログと判断軸

戦闘AIを賢くするための土台ドキュメント。個別の状況を分岐で作り込むのではなく、
**「状況 → 判断軸 → 指標(metric) → 目的スコアへの反映」** の写像として整理する。

- 状況は「検証シナリオ」であり、実装上のif分岐ではない。
- 各状況の裏にある一般的な判断軸を抽出し、指標として持たせる。
- 1つの一般ルール（指標＋重み）で複数状況を同時に満たすことを目指す。
- 性格（`game.md` の絶対ルール。戦闘狂・猪突猛進など）だけは例外的なオーバーライドとして扱う。

## 現在の判断フロー

```text
CombatAiContext（観測）
  └─ CombatAiAssessmentBuilder（指標を算出）
       └─ CombatAiObjectiveScorer（目的を選択）
            Score = Base + Situation + Weapon + Personality
       └─ CombatAiMoveScorer / SkillContextBuilder（移動・スキル選択）
```

目的選択は `AttackEnemy` / `DestroyEnemyStone` / `DefendOwnStone` / `SupportAlly` / `Search` / `Retreat` の
スコア最大値を選ぶユーティリティ方式。この基盤は維持する。

## 既存の指標（CombatAiMetricIndex）

| 指標 | 意味 | 主に効く目的 |
|---|---|---|
| `OwnStoneThreat` | 自陣魔石がどれだけ攻められているか | DefendOwnStone |
| `SelfThreat` | 自分がどれだけ狙われ/倒されそうか | Retreat, AttackEnemy(減点) |
| `AllyFragility` | 味方の脆さ・瀕死度 | SupportAlly, DefendOwnStone |
| `ReachableEnemyValue` | 攻撃できる敵の「殴る価値」 | AttackEnemy |
| `EnemyStoneReachability` | 敵魔石への到達しやすさ | DestroyEnemyStone |
| `TerrainAdvantage` | 地形的優位（高所など） | AttackEnemy, Search |
| `EnemyLocationConfidence` | 敵位置の把握度 | Search |
| `RetreatRouteSafety` | 撤退経路の安全度 | Retreat |
| `SelfExposure` | 敵にどれだけ認識・露出しているか | 隠密系の移動 |
| `EnemyThreatLevel` | 敵集団を放置した時の危険度（武器脅威×接敵補正×行動補正） | AttackEnemy, DestroyEnemyStone(減点) |
| `KillableTargetValue` | その敵を今倒し切る価値（役割価値×倒しやすさ×自分の到達しやすさ） | AttackEnemy, 攻撃スキル |

## 整理済みの弱点

### 1. `ReachableEnemyValue` は敵の「役割・脅威」を見ていない

現状はHP残量・視認・射程内・距離だけで算出する。ヒーラーだけの敵陣でも「攻撃価値が高い」と誤認する。
「殴れる価値」であって「倒す価値／倒すべき相手か」ではない。

対応として `EnemyThreatLevel` と `KillableTargetValue` を追加済み。
`ReachableEnemyValue` は「殴れるか」、`EnemyThreatLevel` は「放置すると危ないか」、
`KillableTargetValue` は「今倒し切る価値があるか」に分離する。

### 2. `DestroyEnemyStone` の一律ペナルティ

敵が1体でも見えると固定で大きく減点する実装があり、「回り込んで魔石破壊」を物理的に不可能にしている。
本来は「敵の存在」ではなく「敵が魔石破壊を止められる脅威か」で判定すべき。

対応として固定ペナルティは `EnemyThreatLevel` ベースへ置換済み。

## 追加する指標

指標を増やしすぎると、何が判断を動かしたのか追いにくくなる。
追加するものは「既存指標で表せない判断」かつ「複数の目的/移動/スキル評価に再利用できるもの」だけに絞る。

追加する指標は現時点で8個。

| 追加指標 | 意味 | 満たす状況 |
|---|---|---|
| `WinProximity` | 勝利への前進度（敵魔石HP残量など） | 詰め切り判断 |
| `AllyEngagementState` | 味方が誰とどれだけ交戦しているか | 一匹狼、寂しがり、献身、集中攻撃 |
| `CastRisk` | 詠唱中に倒される/不利位置で足を止める危険 | 長詠唱の大技を撃つか、退避/短詠唱へ切り替えるか |
| `SkillOpportunityCost` | 高CT・大技・自己コスト技を今使う価値と温存価値の差 | 大技温存、無駄撃ち防止 |
| `AreaTargetValue` | 範囲/全体スキルで有効対象をどれだけ巻き込めるか | 範囲攻撃、全体攻撃、地点選択 |
| `SkillTargetSynergy` | スキル種別と対象の武器/役割/現在目的/状態の相性 | バフ、デバフ、拘束、主火力対策 |
| `StatusRedundancy` | 既に同種・同目的の状態効果が入っている無駄度 | Bind重複、バフ/デバフ重複の回避 |
| `BodyBlockValue` | 自分が間に入ることで味方/魔石を守れる価値 | 献身、盾、防衛 |

## 状況カタログ

各行は「状況 → 期待挙動 → 判断軸 → 必要指標（既存/要追加）」。

### 戦略判断（魔石 vs 敵）

| 状況 | 期待挙動 | 判断軸 | 指標 |
|---|---|---|---|
| 相手がヒーラー/支援のみ | 敵を無視して魔石を攻撃 | 敵は自分を倒せない＝脅威が低い | `EnemyThreatLevel`(実装済) |
| 敵火力を迂回して魔石へ | 回り込んで魔石破壊 | 経路が敵射線を避けられる | 移動候補ごとの経路安全評価, `EnemyStoneReachability` |
| 敵魔石が残りわずか | 多少無理でも詰めに行く | 勝利が近い | `WinProximity`(要追加) |
| 敵が味方1体を袋叩き中 | 横槍か魔石か撤退を選ぶ | 自分が倒しきれる相手がいない | `KillableTargetValue`(実装済), `SelfThreat` |
| 味方前線が安定 | 火力職は魔石破壊へ切替 | 前線を任せられる | `AllyFragility`, `OwnStoneThreat`, `AllyEngagementState`(要追加) |

### 情報戦・偵察・経路

| 状況 | 期待挙動 | 判断軸 | 指標 |
|---|---|---|---|
| 敵魔石への最短が危険 | 迂回/安全ルートを選ぶ | 最短より生存率の高い経路 | 移動候補ごとの経路安全評価 |
| 最短ルートの橋に敵が張っている | 別の橋を経由するルートを選ぶ | チョークポイントの分散 | `BridgePositions`(既存), 移動候補生成 |
| 高所を経由・占拠したい | 目標地点を山（高所）に設定して移動 | 視界と地形優位の確保 | `HighGroundCandidates`(既存), `TerrainAdvantage` |
| 敵位置が不明＆高所がある | 高所へ登り偵察し味方へ位置共有 | 情報共有の価値 | `EnemyLocationConfidence`, `TerrainAdvantage`, `AllyEngagementState`(要追加) |
| 敵が高所で偵察・共有中 | その敵を撃墜/妨害し敵の視界を潰す | 敵の情報源を断つ | `EnemyThreatLevel`(実装済), `SkillTargetSynergy`(要追加), `TerrainAdvantage` |
| 味方が高所偵察へ向かっている | 火力職は前進、偵察は任せる | 役割の重複回避 | `AllyEngagementState`(要追加), `EnemyLocationConfidence` |

橋（`BridgePositions`）と高所（`HighGroundCandidates`）は既にcontextへ離散点として入っている。
そのため「別の橋ルート」は経由する橋を差し替える離散選択で軽く実装でき、
「目標地点を山にする」も既存の高所候補を移動目標に流用するだけで済む。
任意経路の生成より、これら既知のチョークポイント/高所を経由点にする方式を先に入れる。

「係（役割分担）」はキャラ単体のスコアだけでなく、味方間の重複を避けるチーム調整レイヤーが要る。
偵察係・詰め係などは、個体のユーティリティに「味方が既に担っているか」の情報を足して決める。

### 交戦判断（敵の選び方）

| 状況 | 期待挙動 | 判断軸 | 指標 |
|---|---|---|---|
| 瀕死の敵がいる | 仕留めを優先 | 低コストで確実にキル | `KillableTargetValue`(実装済), `SkillOpportunityCost`(要追加) |
| 敵の主火力が生きている | デバフ/拘束で無力化 | 脅威源の除去 | `EnemyThreatLevel`(実装済), `SkillTargetSynergy`(要追加) |
| 自分が集中攻撃されている | 隠れる/撤退 | 被弾を減らす | `SelfThreat`, `SelfExposure`, `RetreatRouteSafety` |
| 敵位置が不明 | 索敵/高所へ | 情報を得る | `EnemyLocationConfidence`, `TerrainAdvantage` |

### スキル運用判断

| 状況 | 期待挙動 | 判断軸 | 指標 |
|---|---|---|---|
| 長詠唱中に敵前衛が接近できる | 大技を撃たず退避/短詠唱を選ぶ | 詠唱完了前に不利になるか | `CastRisk`(要追加), `SelfThreat` |
| 敵1体が瀕死 | 大技を温存して通常攻撃/低CTスキルで処理 | 過剰火力を避ける | `SkillOpportunityCost`(要追加), `KillableTargetValue`(実装済) |
| 高CTの大技が使えるが敵の価値が低い | 温存して別行動 | 今撃つ価値が将来価値を上回るか | `SkillOpportunityCost`(要追加), `EnemyThreatLevel`(実装済) |
| 敵が密集している | 範囲/全体攻撃を優先 | 複数対象に効果を出せる | `AreaTargetValue`(要追加) |
| 敵主火力が生きている | 対応するデバフ/拘束を優先 | 脅威源に合った妨害を入れる | `SkillTargetSynergy`(要追加), `EnemyThreatLevel`(実装済) |
| 味方前衛がこれから殴り合う | STR/防御/移動補助など相性のよいバフを選ぶ | 対象の武器・役割・現在目的と噛み合うか | `SkillTargetSynergy`(要追加), `AllyEngagementState`(要追加) |
| 既に拘束/デバフ中の敵がいる | 同じ効果を重ねず別対象/別スキルを選ぶ | 状態異常の残り時間と重複価値 | `StatusRedundancy`(要追加) |
| 自己コスト技で自分が危険になる | 撃たない/回復後に撃つ | コスト後の生存率 | `SkillOpportunityCost`(要追加), `SelfThreat` |

詠唱スキルは開始後に対象や効果量を固定し、完了まで移動できない。
そのためスキル評価では「現在撃てるか」だけでなく、詠唱完了時点まで生きて有利を保てるかを評価する。

### 連携・位置取り

| 状況 | 期待挙動 | 判断軸 | 指標 |
|---|---|---|---|
| 味方が攻撃中の敵を倒し切れそう | 火力を合わせて確殺 | 集中攻撃の価値 | `AllyEngagementState`(要追加), `KillableTargetValue`(実装済) |
| 味方火力だけで既に倒せる敵がいる | 別対象/魔石/支援へ回る | 過剰集中を避ける | `SkillOpportunityCost`(要追加), `AllyEngagementState`(要追加) |
| 後衛や魔石へ敵の射線が通っている | 盾/献身的キャラが間に入る | 自分が遮ることで守れるか | `BodyBlockValue`(要追加) |
| 敵が後衛へ接近中 | 盾や前衛が迎撃/進路妨害 | 敵が味方へ届く前に止められるか | `BodyBlockValue`(要追加) |

### 防衛・支援判断

| 状況 | 期待挙動 | 判断軸 | 指標 |
|---|---|---|---|
| 自陣魔石が攻められている | 防衛へ戻る | 拠点を守る | `OwnStoneThreat` |
| 味方が瀕死 | 回復/庇う | 戦力維持 | `AllyFragility` |
| 数的不利で押されている | 撤退して立て直す | 全滅回避 | `SelfThreat`, `RetreatRouteSafety` |

### 武器指針との対応（game.md 基本行動指針）

| 武器 | 指針 | 主に使う指標 |
|---|---|---|
| 双剣 | 敵に近づいて攻撃 | `ReachableEnemyValue` |
| 盾 | 味方にくっつく | `AllyFragility`, `OwnStoneThreat` |
| 杖 | 隠れて攻撃 | `SelfExposure`, `ReachableEnemyValue` |
| 魔導書 | 隠れていやがらせ | `SelfExposure`, `EnemyThreatLevel`, `SkillTargetSynergy`(要追加) |
| 聖書 | 隠れて回復 | `SelfExposure`, `AllyFragility` |
| ロザリオ | 隠れて支援 | `SelfExposure`, `AllyFragility` |

## ケース別の実装方針（アルゴリズム）

ここでは各ケースを直接 `if (case)` で実装せず、観測値から指標を作り、目的・移動・スキル候補のスコアへ足す。
指標は原則 0〜1 に正規化し、スコア側で武器・性格補正を掛ける。

### 戦略判断（魔石 vs 敵）

| ケース | 実装方針 |
|---|---|
| 相手がヒーラー/支援のみ | 敵ごとに武器種・使用可能スキルから火力/回復/支援の役割重みを推定し、敵全体の `EnemyThreatLevel` を作る。敵脅威が低く、敵魔石へ到達可能なら `AttackEnemy` を下げ、`DestroyEnemyStone` を上げる。 |
| 敵火力を迂回して魔石へ | 敵魔石までの移動候補を複数作り、候補ごとにナビメッシュ経路、敵射程、射線を評価する。安全な候補がある場合だけ、その移動候補と `DestroyEnemyStone` を押し上げる。 |
| 敵魔石が残りわずか | 敵魔石HP率から `WinProximity = 1 - hpRate` を作る。`WinProximity` が高いほど `DestroyEnemyStone` と魔石へ向かう移動候補を加点し、ただし `SelfThreat` が即死級なら撤退/防御の減点を残す。 |
| 敵が味方1体を袋叩き中 | 味方への集中度と自分が倒し切れる敵の有無を別々に見る。`KillableTargetValue` が高ければ横槍、低くて敵魔石経路が安全なら魔石、`SelfThreat` も高ければ撤退を上げる。 |
| 味方前線が安定 | 味方のHP、人数差、被ターゲット数、回復/防御支援の有無から前線安定度を出す。安定度が高い時だけ火力職の `DestroyEnemyStone` を上げ、支援/盾は前線維持や防衛の価値を残す。 |

初回実装では `EnemyThreatLevel` を以下の簡略式で計算する。

```text
敵単体脅威 = 役割脅威 × 接敵補正 × 行動補正
敵脅威度 = 最大の敵単体脅威 + それ以外の合計 × 0.3
```

役割脅威は武器種ごとの固定値とする。

```text
双剣 0.9 / 杖 0.9 / 魔導書 0.7 / 盾 0.55 / 聖書 0.35 / ロザリオ 0.25
```

行動補正は「通常 1.0、瀕死 0.6、束縛/行動不能 0.35、瀕死かつ束縛/行動不能 0.25、戦闘離脱 0.0」とする。
瀕死や束縛中の敵への追い討ちは `EnemyThreatLevel` ではなく、別指標の `KillableTargetValue` で扱う。

`KillableTargetValue` は敵魔石破壊の減点には使わない。これは `EnemyThreatLevel` と相殺させないため。
`EnemyThreatLevel` は「放置すると危ないか」、`KillableTargetValue` は「今倒し切る価値があるか」として分離する。

### 情報戦・偵察・経路

| ケース | 実装方針 |
|---|---|
| 敵魔石への最短が危険 | 直線/ナビ最短経路とは別に、橋・高所・外周などの経由点付き候補を評価する。敵射線や射程内滞在時間を危険コストに変換し、総コストが低い候補を採用する。 |
| 最短ルートの橋に敵が張っている | `BridgePositions` ごとに「敵密度」「敵射程内滞在時間」「味方支援距離」を評価する。最短橋の危険コストが高い場合、別橋を経由点にした移動候補を上げる。 |
| 高所を経由・占拠したい | `HighGroundCandidates` を移動候補に混ぜ、視界拡大・射線・被接近しにくさを `TerrainAdvantage` として評価する。攻撃/索敵/後衛武器ほど高所候補の移動スコアを上げる。 |
| 敵位置が不明＆高所がある | `EnemyLocationConfidence` が低い時に、高所候補を索敵向け移動候補として加点する。味方が既に高所へ向かっているかは `AllyEngagementState` で見て、重複を下げる。 |
| 敵が高所で偵察・共有中 | 高所にいる敵は `EnemyThreatLevel` と `TerrainAdvantage` で脅威を上げる。撃破/妨害可能なら `SkillTargetSynergy` で攻撃・デバフ・拘束対象として加点する。 |
| 味方が高所偵察へ向かっている | 味方の現在目的/位置から偵察担当の有無を推定する。既に味方が高所へ向かっているなら、他キャラの索敵加点を下げ、火力/支援/詰めへ役割を分散する。 |

### 交戦判断（敵の選び方）

| ケース | 実装方針 |
|---|---|
| 瀕死の敵がいる | 敵HP率、到達/射程、予測与ダメージから `KillableTargetValue` を作る。倒し切れる敵は通常攻撃や低CTスキル候補に加点し、高CT大技は `SkillOpportunityCost` で抑える。 |
| 敵の主火力が生きている | 敵の武器・主能力・与ダメージ期待値から脅威源を推定する。主火力には攻撃対象価値だけでなく、対応するデバフ/拘束の `SkillTargetSynergy` を上げる。 |
| 自分が集中攻撃されている | 自分を狙える敵数、射程内敵数、予測被ダメージ、退路の有無から `SelfThreat` を作る。高い時は `Retreat`、遮蔽/距離を取る移動、短時間で安全になるスキルを加点する。 |
| 敵位置が不明 | `EnemyLocationConfidence` が低いほど `Search` を上げ、最後に敵を見た方向・高所・魔石周辺を探索候補にする。魔石や味方が危険なら索敵より防衛を優先できるよう、脅威指標とは独立させる。 |

### スキル運用判断

| ケース | 実装方針 |
|---|---|
| 長詠唱中に敵前衛が接近できる | スキルの詠唱時間と敵の到達予測を比較し、詠唱完了前に敵が有効射程へ入るなら `CastRisk` を上げる。`CastRisk` は長詠唱スキルを減点し、退避移動や短詠唱スキルを相対的に上げる。 |
| 敵1体が瀕死 | スキル候補ごとに予測ダメージ、敵残HP、CT、自己コストを見る。倒せる最低コストの候補を上げ、高CT/大技/自己コスト技は `SkillOpportunityCost` で下げる。 |
| 高CTの大技が使えるが敵の価値が低い | スキルのCT、範囲、威力、自己コストを「消費価値」として持ち、対象の脅威/勝利貢献が低い時は温存する。敵魔石詰めや主火力撃破など勝敗に近い場面だけ大技加点を上げる。 |
| 敵が密集している | 範囲スキルの候補地点を敵位置中心・敵クラスタ中心・魔石周辺から生成する。地点ごとの対象数と対象価値合計を `AreaTargetValue` として、単体スキルと同じスコア式で比較する。 |
| 敵主火力が生きている | デバフ種別ごとに、下げる能力値が敵の主能力と一致するかを見る。STR職へSTR低下、INT職へINT低下、FAI職へFAI低下、接近前衛へBindのように `SkillTargetSynergy` を作る。 |
| 味方前衛がこれから殴り合う | 味方の武器、主能力、現在目的、敵との距離、残HPから `SkillTargetSynergy` を作る。直後に行動機会があり、効果時間を活かせる味方ほどバフ候補を上げる。 |
| 既に拘束/デバフ中の敵がいる | 対象の状態一覧から同種効果の残り時間を読み、残りが十分なら `StatusRedundancy` で同効果を減点する。残り時間が短い時だけ更新候補として再加点する。 |
| 自己コスト技で自分が危険になる | スキル使用後の自分HPと予測被ダメージから使用後生存率を計算する。生存率が低ければ自己コスト技を減点し、回復/退避/防御後に使う判断へ寄せる。 |

### 連携・位置取り

| ケース | 実装方針 |
|---|---|
| 味方が攻撃中の敵を倒し切れそう | 味方の現在対象と予測与ダメージを集計し、自分が加わることで倒し切れる差分を見る。倒し切りに必要な最小火力だけ加点し、それ以上は `SkillOpportunityCost` で抑える。 |
| 味方火力だけで既に倒せる敵がいる | 味方だけの予測ダメージが敵残HPを超える場合、その敵への追加攻撃を `SkillOpportunityCost` で減点する。代わりに別敵、魔石、支援、位置取り候補を相対的に上げる。 |
| 後衛や魔石へ敵の射線が通っている | 敵と保護対象の間の線分/経路を評価し、自分が入れる遮断候補点を作る。遮断で被弾期待値や接近成功率を下げられるなら `BodyBlockValue` を上げる。 |
| 敵が後衛へ接近中 | 敵の移動速度・距離・ナビメッシュ経路から後衛到達時間を推定する。自分が先回り/迎撃できる地点を移動候補にし、到達前に止められるほど加点する。 |

### 防衛・支援判断

| ケース | 実装方針 |
|---|---|
| 自陣魔石が攻められている | 自陣魔石付近の敵数、敵の魔石到達時間、予測DPS、味方防衛数から `OwnStoneThreat` を作る。高い時は `DefendOwnStone`、魔石周辺への移動、敵足止めスキルを上げる。 |
| 味方が瀕死 | 味方HP率、被ターゲット数、回復射程、回復後生存率から `AllyFragility` を作る。回復だけで救えない場合は防御/遮断/撤退支援も候補にする。 |
| 数的不利で押されている | 周辺の敵味方数、HP総量、行動可能人数、退路安全度を比較する。局所戦闘の勝率が低く `RetreatRouteSafety` があるなら撤退、ないなら防御/足止めを上げる。 |

## 進め方（このカタログの使い方）

1. カタログを随時追記し、状況を増やす。
2. 各状況を判断軸へ還元し、既存指標で足りるか／新指標が要るかを表で管理する。
3. 新指標を `CombatAiAssessmentBuilder` に追加し、`CombatAiObjectiveScorer` の重みへ組み込む。
4. 実装後、カタログの各状況が期待挙動を出すかデバッグ可視化で検証する。
