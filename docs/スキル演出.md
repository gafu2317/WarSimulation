# スキル演出（見た目エフェクト）

判定・数値・AI は [戦闘スキル.md](戦闘スキル.md) の責務。  
この文書は **見た目だけ**（いつ・どこに・何が見えるか）を決める。

## 方針

- まず演出意図をここに書く。Prefab や Particle の作り込みは後。
- 実装の受け皿は `SkillVfxCatalog`（`SkillId` → Prefab / Anchor）と EffectTest シーンでの確認。
- 本番戦闘は `SkillVfxRuntimeBridge` が `CombatSkillActionEvents.Completed` を購読して再生する（Catalog Prefab、なければプロシージャル）。
- 旧デバッグ用のキューブ／球マーカー（`CombatSkillDebugIndicatorSystem`）は削除済み。
- 表のスキル名はゲーム内表示名。括弧内は `SkillId`（Catalog 登録用）。

## 決める項目

各スキルについて、次を埋める。

| 項目 | 意味 |
|------|------|
| タイミング | 詠唱中 / 発動瞬間 / 継続中 / 着弾 |
| Anchor | `Self` / `Target` / `Point`（Catalog の発生点） |
| 見え方 | 一言で何が見えるか |
| 尺 | おおよその秒数、またはループ |
| 大きさ | キャラより小さい / 足元リング / やや大きい など |
| 色・雰囲気 | 武器種の系統が分かる程度でよい |

未定は `TBD` のまま残してよい。完璧より「後で Prefab を当てられる粒度」を優先する。

## 進め方

1. この表の「見え方」を会話で確定していく（全部一度にやらなくてよい）。
2. 優先度の高い数個から Prefab を作り、`SkillVfxCatalog` に登録する。
3. EffectTest で発生点・尺・大きさを確認する。
4. 問題なければ戦闘側の再生接続に進む。

### 最初の優先候補（仮）

見分けやすさ優先で、まずこの3つ。

1. 魔弾（単体着弾）
2. 範囲魔法（地点範囲）
3. STRバフ（自己／味方バフ）

Catalog のプレースホルダも、現状この3つに紐づいている（STRバフの Anchor は後で `Target` に揃える）。

## 非ゴール

- ダメージ数値や AI 判定の変更
- 最初から全スキル分の本番品質アートを揃えること
- VFX の有無でゲームバランスを調整すること（見た目はフィードバック用）
