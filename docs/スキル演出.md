# スキル演出

各スキルの本番演出コンセプト。スキルごとの印象が重ならないように、固有の雰囲気を持たせる。

配色はバフ・守護を金系、デバフ・毒を紫系、回復を緑系で統一。同分類内は形・位置・動きで区別する。

発動時は大きな主役・太い軌跡・重なる閃光で強く見せ、遅れて広がる余韻につなぐ。持続中も光の帯や巡る輝きを残し、毒は渦巻く煙、回復は芽吹きと上昇光で豪華さを出す。不可視は消える瞬間を強調する。

括弧内は、コード上同じ日本語表示名になるスキルを区別するための仕様書上の補足。
