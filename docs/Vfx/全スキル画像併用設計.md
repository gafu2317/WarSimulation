# 画像併用エフェクトの設計

2026-09-15更新。現行の各スキルのコンセプトは [スキル演出](../スキル演出.md) を参照。

- バフ・守護は金、デバフ・毒は紫、回復は緑で統一。同分類の違いは形・発生位置・時間変化で示す。通常攻撃と魔法攻撃は固有の色を使う。
- 強さの象徴は拳、知性は本、信仰は光輪。強化は立ち上がる・整う・灯る。弱体化は沈む・裂ける・割れて落ちる。
- 肩代わりは術者から滑り込む一枚の盾。無敵は閉じた全身障壁と外周の盾。ゴツメは外向きの棘。守護の役割を輪郭で分ける。
- 金縛りは胴を締める交差した太い鎖、AGIデバフは足枷。毒は髑髏・滴・泡。不可視は煙で輪郭を消す。
- 遠隔癒しは弧を描いて届くハート、大回復は包み込む花弁、継続回復は育つ芽、回復エリアは範囲の水紋と縁の芽吹き。
- 羽・花弁・紋章を無関係なスキルの主役として使い回さない。羽は足元の翼、花弁は回復の包容や葉、紋章は呪弾に用途を絞る。

## 素材と負荷

従来11部品に盾・鎖・本・拳・髑髏の専用画像を追加し、2048×2048の16部品アトラスへ再構築。1演出1メッシュ・1共有マテリアルと既存プールを維持。光輪・ハート・数珠の珠は輪郭メッシュ、芽と足元の翼は既存画像とメッシュで組み立てる。未生成の専用画像を生成済みとは扱わない。

ゲームルール、効果音、キャラクターのアニメーション、戦闘カメラは変更しない。検証結果は [引き継ぎ](全スキル画像併用引き継ぎ.md) に記載。
