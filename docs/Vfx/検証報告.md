# 仮スキル視覚エフェクト・検証報告

作業日: 2026-09-14。

## この版の位置付け

全29種を実戦へ接続した仮エフェクトの区切り。本番品質としての完成ではない。図形の組み合わせが目立ち、質感・有機的な輪郭・動きの作り込みが不足している。次段階では代表スキルで素材と時間変化を比較できる制作環境を整え、表現を改善する。最終的な見た目の確認はユーザーへ引き継いだ。

## 実装

全29種を、共有Unlitマテリアルと動的メッシュによる演出に置換。各スキルの形と動きは [演出設計](演出刷新設計.md) に記載。旧Placeholderの粒子・線は本番再生経路から外した。音、キャラクターアニメーション、カメラ演出、ダメージ・射程・CT・状態効果時間は変更していない。不可視の透明度変化は視覚効果として追加した。

- 武器系統ごとの色と造形を統一し、剣の刃、盾板、五指の手、鎖、欠損した紋章、光翼、珠、葉・花弁を個別に作成。
- 発生・収束・飛跡・命中・余韻を時間で接続。詠唱のある魔弾は詠唱終盤に飛翔し、効果適用時刻に命中。詠唱0秒の攻撃・遠隔癒しは、既存判定を遅らせず命中と短い飛跡を表示する。EffectTestの単体プレビューでは飛翔の形を確認するため0.45秒の飛翔段階を含む。
- キャラクター原点と地表のずれをCombatMapSystem経由で補正。対象への追従はキャラクターの拡縮・親子構造を継承しない。範囲演出の半径は実行されたSkillBase.AreaRadiusから取得。
- 回復エリアは所有者・地点・未割当の実体を照合。同じ所有者が同じ地点へ重ねても別の領域に紐付く。領域を終了すると対応する演出だけが終了。
- 状態キーと守護・移動の実体を参照し、死亡・解除・期限終了・戦闘終了・シーン切替で終了。通常の終了は0.25秒で消失する。再適用は既存の同種演出を置き換え、無限に積み重ねない。
- 実行中インスタンスを再利用。1演出1Renderer、共有1マテリアル、ライティング・影・画面コピー・ノイズテクスチャなし。1Playerあたり96件の同時表示上限を設け、超過時は追加演出を省略する。

## 実行環境

- macOS 15.5 / Apple M3 Pro / メモリ36GB / Metal。
- Unity 6000.4.3f1 / URP 17.4。Editorでの検証。
- Game View: 1308×736。録画: カメラ出力960×540、約0.1秒ごとにPNG記録し動画化。
- 実戦: GafuTest、既存の地形・キャラクター・戦闘カメラ。全種を確実に試すため、検証中だけAIを停止し3人の位置とHPを整えて、既存CombatSkillCaster.TryStartCastから順に実行した。自然なAI戦闘も別途確認。
- EffectTest: 既存シーン、俯瞰の検証視点。UIを除くカメラ映像を記録。Play Modeだけでシーンを切り替え、検証配置をシーンへ保存しない。
- 480pxへの縮小表示も確認対象。実機計測ではない。

## 自動検証

SkillVfxProceduralFactoryTests: 6/6 Passed。

1. 全29種に有限の描画ジオメトリ・時間変化があり、1Renderer・共有マテリアル・4096頂点未満。
2. 100回の再生・クリアでオブジェクトを再利用。120件要求して96件を保持、24件省略。クリア後0件。
3. 状態効果の対象移動へ追従し、解除後に終了。
4. 詠唱キャンセルとNoEffectで余計な演出が残らない。
5. 神の手の予兆寿命がゲーム側の詠唱時間に一致。
6. 重複した回復エリアが独立した実体へ紐付き、一方の終了が他方を消さない。

範囲魔法・金縛り・回復エリアを各300回、ウォームアップ後に描画更新した限定計測では、管理メモリ割り当てはいずれも0 bytes。生成処理、戦闘全体、GPUのメモリ割り当てを0と保証する測定ではない。[生データ](../../Captures/Vfx/allocation-probe.txt)

## 負荷計測

録画を停止して測定。各条件8秒、最初の2秒を除き、VFX専用のProfilerMarkerとフレーム間隔を記録した。EffectTestでは同じ画面内へ4件または32件を1.2秒ごとに繰り返し再生した。通常条件は4件同時とする検証用の目安であり、全端末の標準負荷を定義するものではない。

## 視覚確認と修正

代表5種（斬撃・魔弾・神の手・金縛り・大回復）から作成し、Unityで複数時刻を確認。手と花弁の形を広げ、人物を塗りつぶさない外側の輪郭へ調整した。全29種を再生して、信仰デバフ・高速移動の動き、頭上紋章の位置、地面演出の高さ、遠距離の線幅を修正。修正後のEffectTestは29種を再録画。実戦は初回29種を再生し、修正後の再録画は21種完了時点でユーザーの指示により停止した。残り8種の修正後の実戦確認と実戦での負荷計測は未完了。自然なAI戦闘での全29種の網羅確認も行っていない。

## 制約

- iOS/Android実機、発熱・電力・長時間負荷、端末別GPU時間は未検証。スマホでの性能確認済みとは扱わない。
- 地表追従は固定地形の9×9サンプルを補間する。急峻な崖・橋などの複雑な立体交差を完全に覆うデカールではない。
- 1Playerあたり96件を超える描画は省略する。ゲーム側の効果判定は省略しない。
- 全景まで引いたカメラでは、頭上の小さな状態紋章の細部には判読限界がある。色・外形・運動と既存の状態アイコンを併用する。
- 旧Catalog/Placeholder素材は既存ファイルとして残るが、刷新したPlayerはそれらを再生しない。

## 保存物

録画・画像・計測の生データはローカルの `Captures/Vfx/` に保存し、大容量のためこのコミットには含めない。本報告のCapturesへのリンクは同じ作業環境で参照できる。

`Assets/Scenes/GafuTest.unity` は作業開始時点でEditor上に未保存の変更があり、テスト中に保存された可能性がある。ユーザーの「全部コミットしていい」という指示により、このシーン変更もコミットに含めた。検証用の実行時配置は保存していない。
