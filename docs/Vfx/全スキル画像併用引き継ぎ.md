# 全29スキル・画像併用版

2026-09-15。ブランチ `codex/skill-vfx`。仮エフェクトの基点は `cdd89d4`。この版の変更は未コミット。

## 設計と変更

演出コンセプトは `docs/スキル演出.md` から設計し直した。旧エフェクトの描画内容・旧演出設計書は制作の参照に使っていない。先行試作でユーザーが評価した斬撃と大回復の質感を継承。サブエージェントは使用していない。

各スキルの形・動き・消失は [全29種の演出設計](全スキル画像併用設計.md) に記載。呪いは沈み込み・錯乱・侵食、祝福は整列・上昇・安定、回復は包容・循環として個別に構成した。

神の手は追加指示に従い、掌底案を取りやめ「巨大な拳が上から叩き下ろされ、押し潰す」演出に変更。拳は柔らかく潰さず、地面へ逃げる圧力波と低い煙で衝撃を出す。詠唱中に降下し、完了時に接地する。EffectTestの単体プレビューにも詠唱からの連続表示を追加した。

## Unityでの確認

- 既存のEffectTestで全29種を通常再生できる。実戦の既存イベントにも新しい描画処理を接続済み。
- EffectTestのPlayモードで「全自動」ボタン（Pキー）を押すと、全29種を先頭から順番に繰り返し再生する。各プレビューの終了後に0.5秒空けて進み、持続効果も消失まで表示する。速度ボタンは再生と待ち時間の両方に適用。もう一度押すと自動送りを停止し、現在のエフェクトは最後まで再生する。手動選択・手動再生・消去でも自動送りを停止する。
- `Tools > Combat > Skill VFX Studio`（旧 `Skill VFX Comparison` からも開ける）で全29種を選択。
- 時刻スライダー、発生・主動作・消失ボタン、0.1〜1倍速、1〜4件の同時表示を使用できる。
- 3つの画面は選択時刻の0.15秒前／選択時刻／0.15秒後。幅1000px以上なら横並び。各画面は最大480px幅。
- 「詠唱段階」でゲーム定義の詠唱時間を使用。通常プレビューの神の手は詠唱から命中までを連続して見せる。
- Studioは見た目の確認専用。ゲームのダメージ・回復・状態効果の判定は実行しない。実戦での確認時は通常の戦闘を使う。
- PNG保存先は `Captures/VfxArt/`。今回は新しい録画を作成していない。

## 素材と実装

組み込みimage_genで9種類の部品を新規生成し、先行試作の斬撃・花弁と合わせて11部品にした。後続の識別性改善で盾・鎖・本・拳・髑髏を追加し、現在は16部品。原画は `Assets/Art/SkillVfx/Source/`。掌底・開いた手の不採用案は本番アセットへ含めない。

[生成プロンプト](全スキル生成プロンプト.md) / [原画のアルファ検査結果](素材検査.json)

- 全部品を `Assets/Resources/Combat/Vfx/Art/Atlas.png`（2048×2048）へ集約。1共有マテリアル、1演出1MeshRenderer、既存プールと同時表示上限96件を維持。
- シェーダーは1回のテクスチャサンプル、頂点色、アルファ変化による消失。照明・影・画面コピー・歪み・Bloomに依存しない。
- 原画の透明度を保持。アルファ下限で微小な外周ノイズや強すぎるぼかしを抑える。内部の灰色を残し、拳や煙の面が白く潰れないよう調整。
- 原画はResourcesの外へ分離。ゲームはアトラスを参照し、元画像を個別ロードしない。
- `Tools > Combat > Rebuild Skill VFX Atlas` で原画から再生成できる。
- スキル開始・命中・対象追従・状態終了・戦闘終了の接続処理を維持。ゲームの効果量・射程・CT・効果時間は変更していない。描画内容は新しいSkillVfxArtに置き換えた。

## スキルの識別性改善（2026-09-15）

「色や汎用の形が似すぎる」というフィードバックを受け、配色と主役の形を見直した。追加指示に従い、バフ・守護を金、デバフ・毒を紫、回復を緑に統一。能力ごとの色分け案は不採用。各スキルの短い最新コンセプトは `docs/スキル演出.md` に反映済み。

- 盾・鎖・本・拳・髑髏を専用素材として追加。原画の透明度を保持してアトラスを再構築した。
- STRは拳の上昇／崩壊、INTは本の整列／分裂、FAIは光輪の点灯／破損、AGIは足元の翼／足枷。金縛りは胴の鎖、毒は髑髏と滴・泡に変更。
- 肩代わりは味方の前へ滑り込む大盾、無敵は閉じた全身障壁、ゴツメは棘。回復はハート／花弁／芽吹き／水紋で区別する。
- 追加の画像生成は5素材の生成後に利用上限へ到達。光輪・足元の翼・芽・ハートの専用画像は未生成。これらは既存画像とメッシュで表現し、有料APIへの切り替えは行っていない。
- 対象Unityへの接続を復旧し、アトラス16部品のインポート、コンパイルを確認。EffectTestカメラで全29種×3時刻を出力した。主要なバフ・デバフ・回復と盾撃・数珠を目視し、足元の視認性、障壁の閉じ方、光輪の破損姿勢を調整した。

## 発動の迫力を強める調整（2026-09-15）

- 斬撃を速い振り抜きと長い刃筋へ変更。盾撃・魔弾・聖撃は短い命中閃光と方向性のある火花を追加。
- 神の手は接地の閃光、二段の地面衝撃、横へ逃げる煙。極大魔弾は魔力核を囲む渦と圧縮からの解放を強調。
- 金縛りは急な締め付けと減衰する鎖の揺れ。STR・INT等のモチーフは発生時に少し大きく現れて落ち着く。持続時間は変更しない。
- 大回復は速い開花と上向きに包む光、遠隔癒しは受け取りの閃光、回復エリアは初回の拡張波、神雷は二撃目の幅と火花を強調。毒・不可視・継続回復は静かな性質を維持。
- 追加の閃光は0.32秒、火花は0.48秒以内に終了。火花は最大6本のメッシュ線で、ParticleSystemや追加オブジェクトは使わない。アトラス・共有マテリアル・プール・ゲームルールは維持。
- EffectTestカメラで代表6種×3時刻を出力し、主動作を目視確認。画像は `Captures/VfxPunch/`。録画なし。最終EditModeテスト9/9成功。
- macOS Unity 6000.4.3f1のEditorで範囲魔法のCPUメッシュ更新のみを180回計測。1演出の中央値0.050ms／95パーセンタイル0.055ms、12演出では0.597ms／0.624ms。全29種の採取時刻中の最大頂点数1536（回復エリア）。カメラ描画・GPU・実戦処理・スマホ性能を含まない測定。
