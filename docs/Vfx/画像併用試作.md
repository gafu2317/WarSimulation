# 斬撃・大回復の画像併用試作（初回記録）

現在は全32種版へ移行済み。以下は初回2種の試作時の記録で、操作手順・素材パス・検証結果は当時のもの。[現在の全32種版](全スキル画像併用引き継ぎ.md) を参照。

仮エフェクトの基点は `cdd89d4`（ブランチ `codex/skill-vfx`）。今回の対象は `Sword_Slash` と `Rosary_CloseHeal` の2種。残り27種の造形は変更していない。本番採用の判断前の比較用試作。

## 試し方

1. UnityでEffectTestを開き、`Tools > Combat > Skill VFX Comparison` を開く。
2. 「斬撃」「大回復」を選び、「繰り返し再生」を押す。元の仮エフェクト・メッシュ改良・画像併用を同じ時刻と視点で比較できる。
3. 時刻スライダー、発生・主動作・消失ボタン、0.1〜1倍速、1〜4件の同時表示を使う。ウィンドウ幅1000px以上では3版を横並び、狭い場合は縦並びにする。各画像は最大480px幅。
4. 「素材・透明度・支点」で黒・白・地形色の背景上に原画と支点を表示する。ゲーム内の色・透明度は上のプレビューで確認する。
5. 実戦背景を使う場合はGafuTestで戦闘を開始し、カメラ・術者・対象を指定する。比較用表示はダメージ・回復判定を行わない。実際の発動は通常の戦闘で確認する。

EffectTestの通常再生と実戦の2スキルには、試作の画像併用版を接続した。比較ウィンドウは元の版も保持している。再生速度の操作は比較表示にのみ作用し、ゲームのTime.timeScaleは変えない。ウィンドウを閉じる／Play Modeを切り替えると比較用オブジェクトとRenderTextureを破棄する。シーンやカメラ設定は保存しない。

## 表現の差

| スキル | メッシュ改良 | 画像併用 |
|---|---|---|
| 斬撃 | 0.16秒で加速して振り抜く太い先細りの弧、明るい刃先、短い衝撃片、薄い残像 | 同じ動きに、裂け目と不均一な筆致のある三日月を使用。後半に透明度の低い部分から欠けて消える |
| 大回復 | 曲線で縁取った5枚の花弁が開き、少し弾んで上昇。中央は薄くし人物を残す | 花弁素材の濃淡を利用し、輪郭と内側の光を表現。外側から広がる5枚と4つの小さな上昇光 |

大回復の視覚的な余韻は1.15秒から1.65秒へ延長。回復量・効果判定時刻・詠唱時間・CTは変更していない。斬撃は0.55秒のまま。

## 素材の仕様と採否

生成は組み込みimage_genを使用。プロンプトは [生成プロンプト](画像併用生成プロンプト.md) に保存。

- `Assets/Resources/Combat/Vfx/Prototype/SlashBrush.png`: 1254×1254 RGBA。右開きの三日月。中央を支点に回転・拡張する。微小な外周の点はシェーダーのアルファ下限で抑える。
- `Assets/Resources/Combat/Vfx/Prototype/HealingPetal.png`: 1024×1536 RGBA。上向きの花弁。下端の支点はUV約(0.5, 0.16)。初稿にはぼかしが強く入ったため、アルファ下限0.24・上限0.82で輪郭を整える。RGBの写実的な陰影は使わず、シェーダーで着色する。
- 回復素材の修正版は市松模様が画像に焼き込まれ、実際のアルファを持たなかったため不採用。生成への再指示だけで透明化を保証できない点を確認した。採用した初稿は実際のアルファを持ち、元のアルファを保持して保存した。
- Unityへのインポートは最大512、ミップマップあり、Clamp、Bilinear、透明境界の色補正あり。元PNGは生成時の解像度を保持する。

## 実装と負荷の範囲

1演出1MeshRendererと既存プールを維持。追加は2枚のテクスチャ、2つの共有マテリアル、テクスチャを1回サンプルするUnlitシェーダー。画面コピー、歪み、照明、リアルタイム影、Bloomへの依存はない。2種以外は従来の共有マテリアルを使用する。

比較ウィンドウはシーンを3回描画するEditor専用の道具であり、ここでのフレームレートをゲーム本体の負荷として扱わない。画像併用版の実機性能は未検証。過去の仮実装の負荷計測を、この版の測定値として流用しない。

## 今回の確認

- Unity 6000.4.3f1 / macOS / Metal。コンパイルエラーなし。
- 既存6件と、試作2方式の発生・消失端を含む有限座標・UV整合の2件、計8件のEditModeテストが成功。
- EffectTestとGafuTestの既存カメラで、2種×3方式×3時刻を比較表示。実戦背景の比較はAIを停止した場面で行い、カメラを寄せていない。
- 既存SkillCaster経由で斬撃・大回復の開始とVFX生成を確認。終了後のruntime playerのactive数は0、表示上限による省略0。
- 大規模な同時発動・全32種の再検証・スマートフォン実機計測は今回行っていない。最終的な見た目の採否はユーザーへ引き継ぐ。

比較静止画はローカルの `Captures/VfxPrototype/`。録画は新規作成していない。静止画では速度や余韻を評価しきれないため、比較ウィンドウの時間操作を使用する。
