# Grand Study — 書斎・応接室の部品セット

原本: `ArtSource/Blender/GrandStudy.blend`
再生成: `Tools/Blender/generate_grand_study.py`
部品一覧: `manifest.json`

参考画像の濃色木製家具、真鍮の縁取り、赤い座面、革張りソファ、腰壁・格天井を基にしたオリジナルの73部品。
1 Blender単位 = 1m。既存の城・学校・Unityのファイルには変更なし。

## シーン

- `01 Furnished Study`: 6×8×3.6mの組み立て済み書斎。室内全景と応接側のカメラ。
- `02 Asset Catalogue`: 73部品を並べた一覧。各インスタンス名から部品を選択できる。一部の小物は一覧上のみ3倍で表示し、ラベルに[3x]を記載。原本と室内の寸法は変更していない。
- `03 Furniture Detail`: 机、ソファ、照明、小物をまとめた確認用シーン。

部品ごとにコレクションを分離し、Asset Browser用のアセットマーク付き。
部屋と一覧はコレクションインスタンスなので、同じ部品の原本編集が両方に反映される。
コレクションのインスタンスはObject > Apply > Make Instances Realで必要に応じて実体化できる。

## 配置基準

- 壁モジュールは幅方向X、厚み方向Y、高さZ。室内面は-Y。原点は幅中央・床高さ。
- 窓は窓下端をZ=0として作成。作例では床から0.8m上。
- 床・天井は2mグリッド。作例の天井高さ3.6m。
- 床置き家具・小物は底面付近をZ=0に統一。卓上物は机天板の高さへ置く。
- 家具や壁の面取りは非破壊モディファイア。木目、革、布の質感はノードで編集できる。

## 仕上げと制限

風景画・人物画の生成画像2枚はBlender原本内へ埋め込み済み。外部画像の参照先や追加フォント、有料アセットがなくても原本を開ける。参考画像の写真や絵画の切り抜きは使用していない。
額の絵は新規生成した油彩風画像、地球儀は架空の陸地。参考の特定の絵画・地図・レース模様をそのまま再現したものではない。
家具の彫刻、布のしわ、革の縫製は簡略化しており、接写用のフォトリアル完成品とは異なる。
照明器具と室内確認用ライトは分離。電球やロウソクに発光材は付けていない。
棚の本、チェス駒、花束等はセット部品内の個別オブジェクトとして編集できる。
開閉アニメーション、リグ、LOD、当たり判定、UVベイク、FBX出力、Unityへの取り込みは未実施。
Blenderのプロシージャル材質は、そのままFBXへ書き出してもUnityでは再現されないため、移行時にベイクまたはマテリアルの作り直しが必要。

## 参考画像に合わせた改訂

家具の縮尺は維持し、室内を6×8mに変更。奥に書斎・会議卓、手前に応接席をまとめ、東壁の入口からの通路を確保した。
カーテンは床近くまで届く青灰色の厚手布と透ける内布に変更。束ね位置の幅とひだ、留め紐・房を再制作。
赤い椅子と革張り椅子の背もたれは、枠とクッションを連続した曲面へ変更。上端の弧、側面の絞り、後傾を追加。
本は単体12種を追加。8色の装丁、3系列の背表紙意匠、幅・高さ・奥行きの違いを作り、棚には平積み・傾き・前後差を加えた。
Review_01〜04の4方向画像もこの改訂モデルから再描画する。

## 背もたれ・カーテンの構造修正

赤い椅子は上下の横桟と左右の支柱からなる木枠に変更。クッションを枠内に収め、背全体を7度後傾させた。以前の横方向に湾曲・変幅する背面メッシュは撤去した。革張り椅子とソファも、厚みのある背板とクッションを分離した構造に変更。
カーテンは上端の吊り位置から側方の留め紐へひだを集め、留め紐より下はほぼ真下へ垂らす。腰部分で急に括れ、裾が窓中央へ戻る輪郭を撤去した。布シミュレーションではなく、吊り位置と留め位置を基準に作った静的メッシュ。
単体確認画像: `Chair_Front.png`、`Chair_Side.png`、`Curtain_Structure.png`。

## 接写向けの形状・材質修正

追加仕上げ: `Tools/Blender/refine_grand_study_details.py`。ベースの再生成後にこのスクリプトを実行すると、最新の家具・材質・確認画像へ更新される。

- 置きクッションは膨らみと側面・縫い目のある独立メッシュ。底面を座面上面の0.56mへ合わせ、肘掛けの内側に収めた。
- 革張り背面は一体のパッドにくぼみを作り、ボタンをくぼみへ配置。座面の縫い目を追加。
- 敷物の織柄と壁紙模様、家具の金属装飾の厚みを削減。深い凹凸に見えていた木材のバンプも縮小。
- 木材は木目・塗膜、革は細かな粒状感、布は織りとシーン、真鍮は金属度と粗さのばらつきを別設定。
- クッション布には繰り返しの花形模様を追加。参考画像の布柄そのものではない。
- 接写: `Upholstery_Closeup.png`、`Desk_Closeup.png`。室内4方向と一覧も更新。

この工程の後、絵画・植物・彫刻は下記の追加工程で更新。ラグの図柄、家具の彫刻などは引き続き簡略化しており、参考画像のすべての造形や写実品質を再現したものではない。

## 卓上小物の形状修正

再生成の順番は `generate_grand_study.py` → `refine_grand_study_details.py` → `refine_grand_study_focal_props.py` → `refine_grand_study_art_botanicals.py`。最後の工程は既存のコレクションを維持して内部のモデルを交換するので、室内・家具確認・一覧のインスタンスにも反映される。

- 卓上ランプ: 円錐台の傘を厚みのあるドーム形ガラスへ交換。曲面に沿う細い区切り、縁、頂部金具、内側の支持金具を追加。区切り柄は参考画像の八角形柄とは異なる。
- 電話: 傾斜ダイヤル全体を筐体の前に配置。数字、指穴を表す暗いくぼみ状の部材、中央ラベル、指止め、木製受話器・受け金具を追加。指穴は貫通穴ではない。
- 蓄音機: 薄肉の開いたラッパ、連続した曲管、レコード溝、針・サウンドボックス、巻き上げハンドルを追加。
- 戸棚の上下板はメッシュへスケールを適用し、面取り幅を実寸5mmへ統一。側板・背板の上端を天板の下面へ収め、上面の重複を解消。真鍮のバンプを抑え、粗い粒状の凹凸を軽減。
- 最新接写: `Focal_Props_Closeup.png`。室内4方向、家具確認、部品一覧も更新。

従来の `Desk_Closeup.png` と `Upholstery_Closeup.png` は前工程の家具形状確認用。小物の最新形状は上記接写または最新の室内・家具確認画像を参照。


## 絵画・植物・彫刻の追加仕上げ

最終工程: `Tools/Blender/refine_grand_study_art_botanicals.py`。素材コレクション名は維持し、73部品・3シーンの構成を変更しない。既存の城・学校・Unityアセットには変更なし。

- 絵画: 浮き出た記号状の図柄を撤去。新規生成した城と川の風景画・女性の人物画を、UVを持つ平面キャンバスへ適用。縦横比は維持して枠に合わせて端をクロップする。木製額、細い金色モール、鋲、キャンバスの微細バンプを追加。卓上写真立てには同じ人物画を使用。
- 画像: `ArtSource/Blender/Textures/GrandStudy/landscape.png`、`portrait.png`。built-in image_genで生成したオリジナルの絵柄。正確なプロンプトは同フォルダの `generation-prompts.md`。2枚とも原本にpack済みで、画像ファイルを別途配置しなくても表示できる。
- 植物: フィカス風広葉植物・ヤシ・クロトン風斑入り植物を再制作。曲面の葉、先端の反り、葉脈用UV、葉の厚み、枝への接続、頂芽、ヤシの弓なりの葉軸と小葉を作成。3種類の鉢は開口・土・縁のある陶器。
- 花束: 球状の花を撤去し、巻いた花びら・内側のつぼみ・葉・茎で構成したバラ9輪へ交換。
- 彫刻: 胸像に鼻筋・顎・眼窩・まぶた・耳・髪の巻き・衣服の起伏を追加し、頭・髪・肩を一体の石の面へ接続。鳥は細い脚・足指・連続したS字の首・先細りのくちばし・翼の羽模様を持つサギ風のブロンズ像へ交換。トロフィーの取っ手も滑らかな曲線へ変更。
- 接写: `Art_Botanicals_Closeup.png`、`Sculptures_Closeup.png`、`Paintings_Closeup.png`。最初の接写では小型彫刻・花束のみ約1.5〜1.65倍にして形を見やすくしている。室内の実寸は維持。
- 室内4方向・部品一覧・家具確認も再描画。従来の形状確認用接写は各工程の状態を示すため、最新全体はReview_01〜04を参照。

植物は静的な手続き生成メッシュで、風のアニメーションやLODは未実装。胸像は小型室内小物向けの造形で、人物スキャンや高解像度の美術彫刻の複製ではない。

広葉植物の葉が本棚に入り込まないよう、室内インスタンスを(1.80, 2.95, 0)mへ移動。鉢や葉の縮尺は変更していない。
