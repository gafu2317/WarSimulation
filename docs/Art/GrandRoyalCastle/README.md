# 王城本体の拡張
編集原本: ArtSource/Blender/GrandRoyalCastle.blend
生成: Tools/Blender/generate_grand_royal_castle.py

60×54m（旧30×27mの4倍）の敷地に、一つの連続するコの字形の王城を作成。
城本体は幅40m、奥行30m。主館5階、両翼4階、中央部に上層3階を重ねた構成。
階高は約3.2m、標準窓は幅0.7m・高さ1.55m。窓や扉の一括拡大はしていない。
主館と中央部は一つの段状の壁メッシュ。両翼は主館に端面で接続。
屋根は接合面で区切り、塔を屋根へ差し込む構造を廃止。
内側の城壁、元の小さな城、独立した6棟の追加建築は削除。城壁は外周の1周のみ。
付属棟や別の塔を増やす方法ではなく、城本体の窓列・階数・床面積を増やした。

正面・背面・上面のレンダリングで確認。

旧城コレクションが存在しないことと敷地60×54mを検査。
