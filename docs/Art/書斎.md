# 書斎・応接室

濃色木製家具、真鍮の縁取り、赤い座面、革張りソファ、腰壁・格天井を持つ73部品のセット。1 Blender単位を1mとし、6×8×3.6mの書斎・応接室を組み立てる。

- 編集用原本: `ArtSource/Blender/GrandStudy/GrandStudy.blend`
- 部品一覧: [Records/GrandStudy/manifest.json](Records/GrandStudy/manifest.json)
- Unity用FBX・テクスチャ: `Assets/Models/GrandStudy/`
- Unity用部品Prefab: `Assets/Prefabs/GrandStudy/Objects/`
- 部屋Prefab: `Assets/Prefabs/GrandStudy/GrandStudyRoom.prefab`
- Unityシーン: `Assets/Scenes/GrandStudyRoom.unity`

## 部品と配置基準

| 分類 | 数 | 主な内容 |
| --- | ---: | --- |
| 内装 | 13 | 壁、窓・ドア開口壁、窓、ドア・枠、床、格天井、廻り縁、巾木、格子、カーテン |
| 家具 | 14 | 両袖机、会議卓、ローテーブル、脇机、戸棚、本棚、飾り棚、椅子、ソファ、革椅子、花台、ワゴン |
| 小物 | 32 | 本、紙、筆記具、花瓶、花束、茶器、時計、地球儀、電話、蓄音機、チェス、彫像 |
| 照明 | 5 | 燭台、卓上灯2種、壁灯、シャンデリア |
| 布類 | 3 | 大判ラグ、ランナー、レース敷物 |
| 植物 | 3 | 広葉植物、ヤシ、クロトン風植物 |
| 額装 | 3 | 風景、肖像、卓上写真立て |

以下はBlender基準。壁は幅X・厚みY・高さZ、室内面は-Y、原点は幅中央・床高さとする。
窓の原点は窓下端で、作例では床から0.8m上。床・天井は2mグリッド。床置き部品は底面付近をZ=0にそろえ、卓上物は机の天板へ置く。

## Blender内のシーン

- `01 Furnished Study`: 組み立て済み書斎。奥に書斎・会議卓、手前に応接席をまとめ、東壁の入口から通路を確保する。
- `02 Asset Catalogue`: 73部品の一覧。一部の小物は一覧だけ3倍にし、ラベルに`[3x]`を付ける。
- `03 Furniture Detail`: 机、ソファ、照明、小物の確認用シーン。

部品は個別のコレクションとAsset Browserのアセットマークを持つ。部屋と一覧はコレクションインスタンスで、原本の編集が両方へ反映される。
実体化には `Object > Apply > Make Instances Real` を使う。部品内の本、チェス駒、花束等も個別に編集できる。

## 生成とUnity取り込み

再生成は以下の順で行う。仕上げ工程はコレクション名を維持して内部のモデル・材質を更新する。

1. `Tools/Blender/generate_grand_study.py`
2. `Tools/Blender/refine_grand_study_details.py`
3. `Tools/Blender/refine_grand_study_focal_props.py`
4. `Tools/Blender/refine_grand_study_art_botanicals.py`

保存済み原本の検証は `Tools/Blender/validate_grand_study.py`、Unity書き出しは `Tools/Blender/export_grand_study_to_unity.py`。
Unityの `WarSim > Grand Study > Import Objects And Build Room` で部品・部屋・シーンを取り込む。取り込み処理は `Assets/Prefabs/GrandStudy/Editor/GrandStudyUnityImporter.cs`。
Blenderのプロシージャル材質にはベイクまたはUnity側での材質の作り直しが必要。

[書き出し記録](Records/GrandStudy/unity_export_manifest.json)と[Unity検証記録](Records/GrandStudy/unity_validation.json)を同じ場所に保存する。
記録時点ではFBX・Prefab各73件、URP Lit、接地、寸法一致が合格している。

## 現行の仕上げ

- 椅子は木枠とクッションを分離し、背を7度後傾。革張り椅子・ソファも背板とパッドを分ける。置きクッションは膨らみ・側面・縫い目を持ち、底面を座面上面の0.56mへ合わせ、肘掛けの内側に収める。
- カーテンは青灰色の厚手布と透ける内布。上端から留め紐へひだを集め、留め紐より下はほぼ垂直に垂らす静的メッシュ。
- 戸棚は上下板・側板・背板の接合を整理し、面取りを実寸5mmへ統一。木材・革・布・真鍮は材質を分け、壁紙・敷物・金属装飾の過度な凹凸を抑える。
- 本は単体12種、8色の装丁と3系列の背表紙意匠を持ち、棚に平積み・傾き・前後差を付ける。
- 卓上ランプはドーム形ガラスの傘、電話は前方に傾けたダイヤルと木製受話器、蓄音機は薄肉の開いたラッパと連続した曲管を持つ。電話の指穴は暗いくぼみ状の表現。
- 絵画は平面キャンバスへUV付きの生成画像を適用し、木製額と金色の縁を付ける。風景画・肖像・卓上写真立ての画像は原本内へ埋め込み済み。
- 広葉植物・ヤシ・クロトン風植物は曲面の葉、葉脈用UV、厚みと枝への接続を持つ。鉢は開口・土・縁を備える。花束はバラ9輪、彫刻は石の胸像とサギ風のブロンズ像、トロフィーの取っ手は曲面で構成する。
- 広葉植物の室内インスタンスは本棚への干渉を避けるため、Blender座標`(1.80, 2.95, 0)m`に置く。

絵画の元画像は `ArtSource/Blender/GrandStudy/Textures/landscape.png` と `portrait.png`。生成指示は同フォルダの `generation-prompts.md`。架空の風景・人物・地図を使い、参考画像の絵や地図を切り抜いていない。

## 確認範囲と制限

生成・接写画像は `Records/GrandStudy/` に出力する。`Review_01`〜`04`、部品一覧、家具確認で全体を見る。各工程の接写はその工程時点の形状確認用で、最新の全体像は最終工程の室内画像を使う。
家具の彫刻、ラグの図柄、布のしわ、革の縫製は簡略化されている。照明器具と室内確認用ライトは分離し、器具に発光材を付けない。
植物の風アニメーション、開閉アニメーション、リグ、LODは未制作。小型の室内彫刻向けの造形で、人物スキャンや高解像度の美術彫刻ではない。
