# 大型王城

- 原本: `ArtSource/Blender/Kingdom/GrandRoyalCastle.blend`
- 生成: `Tools/Blender/generate_grand_royal_castle.py`
- 検証: `Tools/Blender/validate_grand_royal_castle.py`
- Unity書き出し: `Tools/Blender/export_grand_royal_castle_to_unity.py`
- Unity取り込み: `Assets/Prefabs/Kingdom/City/Editor/GrandRoyalCastleUnityImporter.cs`
- 生成・書き出し・取り込み記録: `Records/Castle/`

ユーザー提示画像の構成を基準に再設計。
独立した一重の城壁、四隅の円塔、双円塔の城門、中央にまとまった本館と接続する両翼、
本館の円形脇塔、中央上部の主塔、青灰色の急な屋根、石積み、赤い旗で構成。
敷地は60×54m。
本館と両翼の幅は約34m。居住用窓は幅0.55〜0.85m・高さ1.5〜2.05m、入口は幅2m・高さ3m。

本館は18×19m、両翼は各8×28m。これらの壁体の平面占有面積は790平方m
（塔を除く外形面積であり、室内の有効床面積ではない）。外周城壁は一重で、独立した別棟はない。
正門から玄関までの前庭と中央通路、両側・背面の城壁沿いの通路を残した。
両側に低い植栽帯、後方の脇に小さな木箱を追加。

正面斜め、背面斜め、真上の画像で確認。
円塔と上部主塔の周囲は屋根の面自体を切り欠いて接合している。
保存ファイルで窓ガラスの近傍の構造壁、屋根の頂点・面中心が塔内へ侵入しないこと、
正門から本館前への高さ2mの通路を検査。結果は[構造検証](Records/Castle/validation.json)。
記録時点では213個の窓の壁支持、406枚の屋根面の塔との切り欠き、門からの通路が合格。

Unityでは `Assets/Models/Kingdom/City/Models/Royal_Castle.fbx` をこの原本から更新し、
同名PrefabをURP Lit・配置用MeshCollider付きで再生成した。`Assets/Scenes/KingdomAssetCatalog.unity`
も再構築し、91種類のPrefabを配置した状態で検証した。Unity側の結果は[取り込み検証](Records/Castle/unity_validation.json)、カタログ側の結果は[素材一覧の検証](Records/Catalog/validation.json)に保存している。
壁・塔の接続に意図した構造体の重なりや内部面はある。
すべての装飾メッシュの交差ゼロや、室内まで完成した構造を保証する検査ではない。
室内・NavMeshは未制作。画像の細かな彫刻や瓦模様は簡略化している。

## 2026-10-23 テクスチャ割り当ての修正

Countryの拡大画像で、屋根・窓・壁の細部が黒く欠けていた。旧FBXの247,743三角形中247,426枚は、4096角の画像でもUV面積が1ピクセル未満だった。色画像の大部分が黒い余白になり、細いUV島が縮小表示でその余白を拾っていた。照明を使わない表示でも再現し、単色の材質では消えることを確認した。

元の15材質はすべて一定の色・金属度・粗さを持つため、細かな部品ごとにUV島を詰める代わりに、十分な余白を持つ256角の色パレットへ割り当てる。各面は同じ材質の色領域を共有し、最小UV面積は128ピクセル。法線画像と金属度・滑らかさ画像にも元の材質値を出力する。UnityではこのパレットだけをPoint・ミップマップなしで読み、隣の色や余白の混入を防ぐ。

元のBlenderファイル・Prefab・Unity材質は保持し、FBXのUVと3枚の出力PNGを更新した。三角形の頂点座標を並べて比較し、修正前後の形状が一致することを検査した。書き出しは同じスクリプト、取り込みは `WarSim > Kingdom > Refresh Grand Royal Castle Textures` を使う。この操作は城のテクスチャとFBXを更新し、一覧シーンやPrefabを作り直さない。

- Unity取り込み: `Records/Castle/unity_validation.json`
- 同じ視点の変更前後: `Artifacts/CountryComparison/CastleTexture_BeforeAfter.jpg`
- 修正前のFBX・画像・表示検証: `Artifacts/CountryComparison/BeforeCastleTextureFix/`

## 2026-10-23 周囲の旧建築との配色合わせ

白く浮いていた城の壁・屋根を、旧住宅と同じ色の系統へ揃えた。石壁は `Fantasy_Stone` の `#999588`、縁石は `Fantasy_StoneTrim` の `#BCB3A0`、屋根は `Fantasy_Roof` の `#343F4A`、木部は `Fantasy_Timber` の `#49372B`、窓は `Fantasy_Window` の `#1C2B32`、旗は `Fantasy_Banner` の `#742E34` を基準にする。出力PNGには表示色としてこのsRGB値を保存し、再び明るくなる色変換の重複を避ける。

配色は書き出しスクリプトの `TOWN_COLORS` に保持し、Manifestには元の材質色と出力色の両方を記録する。今回更新したモデル用ファイルはBaseColor PNGのみ。FBX・UV・法線・金属度画像・Prefab・Unity材質・Blender原本はそのまま保持した。

同じ視点の比較は `Artifacts/CountryComparison/CastleColor_BeforeAfter.jpg`、調整前は `BeforeCastleColorMatch/`、検証記録は `castle_color_validation.json` に保存する。
