# 学校モデル：参考画像に合わせた再設計

戦士学校・魔法学校・精霊学校の各レベル1〜5、計15モデル。
編集用ファイル：ArtSource/Blender/FantasySchoolLevels.blend
再生成：Tools/Blender/generate_school_levels.py

## 造形
- 戦士学校：石造、赤い剣の旗、角の堡塁、中央指揮塔。
- 魔法学校：青い切妻屋根、円窓、ドーム、上位レベルの尖塔。
- 精霊学校：緑の反り屋根、枝状の木組み、木造中央塔。
- 全モデル26m角の同一敷地。レベルごとに建物の高さ・占有面積・装飾を増やす。
- 発光なし。参考画像の建築構成を簡略化したモデルで、画像の質感や細部の完全再現ではない。
- 今回はレベル3も含めて再設計。以前のレベル3原形保持ルールは適用していない。

## Blender内の構成
School Levels - Editable Assetsに3行×5列で配置。
各モデル名のPreviewシーンに個別カメラを設定。
各モデルは同名のルートEmptyを親とし、部位・材質ごとにメッシュを分けている。
比較画像は同じ正投影倍率でレンダリング。

## 確認範囲
15モデルの正面斜め画像を確認。低い階の窓上端を壁高さに収めた。
validation.jsonには座標の有限性、敷地内への収まり、接地、高さの増加、発光設定の検査結果を保存。
壁と窓枠などの意図した重なりがある。全メッシュの交差を網羅的に検証したものではない。
屋根は外観用の面で、内部・背面からの使用を想定していない。

既存のFantasySchools.blendとUnity内のアセット・シーンは変更していない。

## 装飾の再点検・整理
3校×5レベルを正面右斜め・背面左斜めの計30視点で確認。
- 戦士：レベル3〜5で二重だった旗を1組に統一。盾に干渉する追加控え壁、旗と接する塔の縦飾り、入口内部に埋まった旧補強を除去。
- 魔法：入口の小さな天体環を整理。星・紋章板を壁面に寄せ、紋章と横帯の干渉を回避。
- 精霊：木組みと重なる壁面の蔓・軒飾りを除去。枝の張り出しを短くして窓を避ける。入口の蔓と葉彫刻は保持。レベル2の屋根に隠れる塔窓を除去。
- 共通：入口の二重の柱飾りを除去。角塔と重なる隅石・側面柱を省略。背面の窓を角の構造・装飾から離す。
- 屋上ブロックの均等配置、建物本体、同一敷地、発光なしを維持。
*_Comparison.jpgが正面、*_Rear_Comparison.jpgが反対側の比較画像。
意図した壁・枠の接合は残している。全ポリゴン交差ゼロを保証する検査ではない。
Unity内のモデル・シーンは未更新。
