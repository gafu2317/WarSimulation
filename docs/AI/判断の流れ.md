# 判断の流れ

関連: [README](README.md) · [移動](移動.md) · [スキルと対象](スキルと対象.md) · [性格](性格.md)

主な実装: `CombatCharacterSystem.TickAiDecisionsNow`, `CombatAiBrain`, `CombatAiPlanner`

## 目的と戦況

### 目的

戦略ステートは次の六つだけ。既存の `CombatObjective` をステート名として使う。

| 値 | 意味 |
|---|---|
| `AttackEnemy` | 敵を攻撃する |
| `DestroyEnemyStone` | 敵魔石を破壊する |
| `DefendOwnStone` | 自軍魔石を防衛する |
| `SupportAlly` | 味方を支援する |
| `Search` | 敵を索敵する |
| `EmergencyRetreat` | HP15%以下で自軍魔石またはロザリオへ緊急退避する |

高所、森林、進攻ルート、追従、遮断、回復、待機、詠唱、死亡は追加ステートにせず、六ステート内の条件・行動として扱う。

### 戦況指標

ステート優先判定に必要な二つの危険度だけを、おおよそ 0〜100 で事前計算する。

| 指標 | 概要 |
|---|---|
| `OwnStoneThreat` | 自軍魔石付近の既知敵 |
| `AllyFragility` | 援護中ではない味方のうち、最も危険な一人の危険（味方全員分は加算しない） |

敵の有無、敵魔石の生存、射程圏、高所・森林、進攻ルートなどは `Context` の事実を各ステート内で直接判定する。使わない総合指標は計算しない。

### ステート選択

`SelectState` は、HP基準の緊急撤退を最初に確認し、その後に性格の明示分岐と通常行動を固定優先順で判定する。

HPが15%以下で自軍魔石の安全圏外なら `EmergencyRetreat` を選ぶ。緊急撤退中は通常目的へ切り替えず、退避先が無効になったときだけ別の退避先を選び直す。退避先は水平距離が近い到達可能な自軍魔石または生存・行動可能な味方ロザリオで、同距離なら自軍魔石を優先する。

自軍魔石を選んだ場合は魔石中心から18m以内で緊急撤退を解除する。ロザリオを選んだ場合は到着しても解除せず、HPが50%以上になるまで維持する。魔石の安全圏内で通常目的へ戻った後も、HP15%以下で圏外へ出れば再び `EmergencyRetreat` を選ぶ。退避先がない場合は、その場で緊急撤退を維持する。

#### 性格による前段分岐

| 条件 | 選択ステート | 意味 |
|---|---|---|
| 門番かつ自軍魔石位置あり | `DefendOwnStone` | 魔石防衛を常に優先 |
| 復讐鬼かつ直近攻撃者が生存・既知位置あり | `AttackEnemy` | 直近攻撃者を追跡 |
| 便乗屋かつ設定対象が目的と対象または目的地を持つ | 味方と同じ目的 | 設定対象の計画へ同調 |
| 猪突猛進かつ生存中の敵魔石あり | `DestroyEnemyStone` | 敵魔石への前進を優先 |
| 戦闘狂かつ直接視認または認識保持中の攻撃対象あり | `AttackEnemy` | 敵キャラクターの最終既知地点まで追う |
| 戦闘狂かつ攻撃対象なし・生存中の敵魔石あり | `DestroyEnemyStone` | 敵魔石へ前進 |
| 寂しがりかつ近くに味方なし | `Search` | 技能を使わず味方を探す |

#### 通常の優先順

性格分岐に該当しない場合は次の順で判定する。

1. 自軍魔石の脅威度が `25` を超えるなら `DefendOwnStone`
2. 自軍魔石を最後に攻撃した生存中の敵がマークされていれば `AttackEnemy`
3. 使用可能な支援技能と傷ついた味方があるか、盾の危険な護衛対象がいれば `SupportAlly`
4. 交戦条件を満たす敵がいれば `AttackEnemy`
5. 支援・妨害武器（魔導書・聖書・ロザリオ）で、支援条件も直接視認中の敵もなければ `Search`
6. 生存中の敵魔石位置が分かれば `DestroyEnemyStone`
7. それ以外は `Search`

`EmergencyRetreat` 中は攻撃目的へ変更せず、保護・回復・不可視系スキルだけを使う。
盾は無傷で脅威のない味方を護衛対象にしない。

武器や性格ごとの数値重みを合計して状態を決めることはしない。高所好きはここで別ステートを選ばず、高所領域外なら選択済みステートの移動を高所へ上書きし、領域内なら技能なしの移動先も高所領域内に制限する。

攻撃職（双剣・杖）は、性格による前段分岐が成立しない場合、敵魔石位置が分かるとき魔石破壊を基本方針にする。索敵や射程圏外の既知敵への切り込みより魔石前進を優先し、自身の有効交戦射程圏内の敵（双剣は武器射程＋余裕、杖はおおよそ 10m 以内）がいるときだけ敵攻撃へ割り込む。

支援・妨害寄り（聖書・ロザリオ・魔導書）は、支援条件も直接視認中の敵との交戦条件も成立しないとき、既知の敵魔石より `Search` を優先する。

「前線が安定したら火力職だけ押し込む」「誰か一人だけ強襲させる」といった専用割当ルールは置かない。

### 敵情報

- **直接視認**: 現在の位置・体力・状態・行動
- **認識保持・非視認**: 最後に観測した位置・体力・状態・行動と時刻。見えていない間の実変化では更新しない
- **未認識**: 実位置・実体力をステート条件・移動・対象・範囲攻撃に使わない
- 復讐鬼の直近攻撃者はダメージイベントから保持し、敵として生存し既知位置がある場合だけステートと対象に使う
- 自軍魔石を最後に攻撃した敵は陣営で共有してマークし、生存中は現在位置を追跡対象に使う
- 索敵は最終既知地点、高所、森林の順に利用可能な行動を選ぶ

## チーム一括の Prepare → Execute

既定の判断間隔は `CombatCharacterSystem` の AI 間隔（既定 0.5 秒）。

1 回の tick:

1. 視界スキャンと味方間の視界共有
2. 陣営ごとのチーム予約をクリア
3. 全 Brain を順に Prepare（成功した計画を予約へ登録）
4. 全 Brain を順に Execute

後続キャラは、先行キャラの計画・予測ダメ／回復を文脈に含められる。
援護対象の選択では、すでに `SupportAlly` を選んだ味方を除外し、援護先が別の援護役へ連鎖しないようにする。

## 1 キャラの Prepare

- AI 無効・行動不能・詠唱中は計画を作らない
- 文脈収集
- `BuildPlan`: 戦況 → `SelectState` → 性格・武器を反映した `BuildPlanForState`
- 寂しがりが単独のときは `Search` を選び、技能を使わず味方探索移動だけを行う
- 便乗屋は編成側で設定された味方の予約計画または直前計画を参照し、その目的・対象へ追従する。設定対象が利用できない場合は通常の目的・対象選択へ戻る
- 復讐鬼は被ダメージイベントで保持した攻撃者が生存し既知位置を持つ間、その攻撃者を追う

詠唱中は新しい判断を行わず、開始済みスキルの完了を待つ。

「スキル」には通常攻撃を含む。

## BuildPlan

1. 文脈から戦況指標を作る
2. 上記の `SelectState` の順に確認し、六ステートから一つを選ぶ
3. 選んだステート専用ビルダーが、整合する移動とスキルを一つの `Plan` にする
4. `Plan(ステート, 行動コード, 移動, スキル, スキル文脈, 遷移理由)` を返す

短時間の敵フォーカスは、双剣または戦闘狂が計画した対象を一定時間維持する。復讐鬼の追跡は時間ロックではなく、保持した攻撃者の生存と既知位置に依存する。ステートそのものを時間でロックしない。

## Execute

1. 移動を出す
2. 計画の攻撃／スキルを実行する

診断ログには、前ステート、選択ステート、遷移理由、行動コード、対象／目的地、移動・スキル開始可否、失敗理由を残す。

魔石への攻撃も、敵への攻撃と同じく計画上の攻撃手段として扱う。  
目的が魔石だからといって、Execute だけ別系統の通常攻撃を差し込む形は本線にしない。

詠唱なしスキルは移動しながら開始でき、詠唱ありは詠唱開始で移動が止まる。

## 移動失敗

到達不能・停滞が続く目的地は、短時間候補から外してよい。これは経路失敗の局所対処であり、目的選択の押し込みではない。
