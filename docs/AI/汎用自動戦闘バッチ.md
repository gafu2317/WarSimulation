# 汎用自動戦闘バッチ

編成・敵・マップ・シード・試合数をJSONで指定し、Standalone Playerを分割・並列実行する。

## 実行

まずUnityで `Tools > War Simulation > Auto Battle > Setup And Build Lightweight Player` を実行する。
その後、短いスモークを行う。

```bash
python3 Tools/AutoBattle/batch_battles.py \
  --config Tools/AutoBattle/batch-example.json \
  --smoke \
  --output-directory /private/tmp/WarSimulation-smoke
```

本実行は同じ設定を使い、出力先を固定する。

```bash
python3 Tools/AutoBattle/batch_battles.py \
  --config Tools/AutoBattle/batch-example.json \
  --output-directory Logs/AutoBattleBatch/run1
```

## 再開

同じ設定と出力先で再実行する。fingerprintが一致する完了ジョブは再利用し、失敗・中断ジョブだけを再実行する。
長時間処理はCodexのセッションに依存せず、Terminal.appから起動する。

## 比較の注意

比較中はマップ、敵編成、シード、TimeScale、固定刻み、並列条件を揃える。
速度設定や並列負荷を変えた結果を同じ母集団へ混ぜない。

詳細な設定項目は `Tools/AutoBattle/` のJSONと `batch_battles.py` を正本とする。
