# 戦闘AI 性格補正

関連: [README](README.md) · [仕様](仕様.md) · [デザイナーズコンボ](デザイナーズコンボ.md)

性格は原則として武器の役割を置き換えず、その武器の動き方へ一つの目立つ特徴を加える。通常候補の採点補正だけで表現できない行動は、通常の目的選択より先に判定する性格固有状態として扱う。

### 性格固有状態

性格固有状態は、戦闘離脱、単発行動、継続行動、移動・休止の順に判定し、該当する最初の状態だけを実行する。どの状態にも該当しない場合は通常の目的選択へ進む。

| 状態 | 性格 | 開始条件 | 終了条件 |
|---|---|---|---|
| 戦闘離脱 | 下世話 | 追従していた恋人のどちらかが戦闘を離脱する | 自分も戦闘を離脱し、通常判断へ戻らない |
| 報復 | メンヘラ | 自分が攻撃を受け、庇える盾が庇わなかった | 記憶した盾へ一度報復する、または盾が対象外になる |
| 選択ミス | おっちょこちょい | 判断開始時に、設定された低確率で選択ミスが発生する | 対象、移動先、スキルのいずれか一つを選び直した計画を一度実行するか、実行不能になる |
| 無作為行動 | 不思議ちゃん | 三秒ごとの行動更新時 | 無作為に選んだ一回の行動を実行するか、実行不能になる |
| 敵周回 | 天真爛漫 | 認識中の敵がいる | 敵を認識できなくなる。攻撃禁止は戦闘中継続する |
| 魔石突進 | 猪突猛進 | 破壊可能な敵魔石がある | 敵魔石が破壊され、戦闘が終了する |
| 恋人追従 | 下世話 | 恋人二人が戦闘中で、その中間から離れている | 二人の近くへ到着する |
| 異性追従 | スケベ | 同行可能な異性から一定距離以上離れている | 異性の近くへ到着するか、同行対象が無効になる |
| 味方合流 | 寂しがり | 一定距離内に味方がいない | 味方へ合流する |
| 待機 | 怠け者 | 移動またはスキルを一回実行する | 待機時間が終わるか、危険が迫る |

天真爛漫の攻撃禁止、猪突猛進の敵攻撃禁止など、性格固有の候補制限は固有状態の終了後も各性格の記述に従う。それ以外の性格は通常の目的、移動、対象、スキル候補へ補正を加える。

### 目立ちたがり屋

- 達成したいこと
  - 敵の注意を自分へ集める。
- そのための方法
  - 武器の有効距離を保ちながら、複数の敵から見える正面位置へ出る。
  - 敵の注意が別の味方へ向いた場合は、再び敵の正面へ移動する。

### 戦闘狂

- 達成したいこと
  - 一度始めた敵との戦闘を最後まで続ける。
- そのための方法
  - 一度攻撃した敵を長く追い、敵が逃げても対象を変えにくくする。
  - 攻撃対象が生存している間は、魔石破壊や別対象への変更を後回しにする。

### 冷静

- 達成したいこと
  - 危険なときに退き、無駄な離脱を防ぐ。
- そのための方法
  - 自分の危険度が基準を超えたときだけ、現在の行動を中断して後退する。
  - 安全な位置まで下がったら停止せず、元の武器役割へ戻る。

### 慎重

- 達成したいこと
  - 交戦地点へ向かう間の被害を減らす。
- そのための方法
  - 敵の射程を横切る直線経路を避け、安全な迂回路を通って交戦位置へ向かう。
  - 安全な経路がない場合は味方の到着を待ってから前進する。

### おっちょこちょい

- 達成したいこと
  - 普段は通常どおり行動し、まれに判断を間違える。
- そのための方法
  - 低い確率で、通常計画が選んだ対象、移動先、スキルのいずれか一つを、実行可能な別候補から無作為に選び直す。
  - 一つの判断で間違える項目は一つだけとし、その計画を一度実行した後は通常の武器行動へ戻る。

### 臆病者

- 達成したいこと
  - 敵の注意と危険な交戦を避ける。
- そのための方法
  - 敵から狙われたら、攻撃や支援を中断して最寄りの味方の後ろへ下がる。
  - 敵の注意が外れた後も、味方より前へ出ない位置を維持する。

### 狡猾

- 達成したいこと
  - 敵に見つかりにくい位置から攻撃する。
- そのための方法
  - 攻撃、妨害、支援のいずれかを行った後、敵の射線が切れる森林や遮蔽物へ移動する。
  - 射線を切った後は同じ場所へ留まらず、別方向から再び射程へ入る。

### 卑怯者

- 達成したいこと
  - 味方を盾にして自分への攻撃を避ける。
- そのための方法
  - 最寄りの敵と自分の間に味方が入る位置を維持する。
  - 間にいる味方が移動した場合は、その味方の後方へ追従する。

### 献身的

- 達成したいこと
  - 自分が危険を負って味方を守る。
- そのための方法
  - 敵に狙われている味方を見つけたら、その味方と敵の間へ移動する。
  - 味方への危険がなくなるまで前方を維持し、その後に武器本来の位置へ戻る。

### 不思議ちゃん

- 達成したいこと
  - 戦況によらない予測不能な行動をする。
- そのための方法
  - 一定時間ごとに、実行可能な目的、移動、スキルを無作為に選び直す。
  - 同じ行動へ固執せず、他の性格より頻繁に進行方向と対象を変える。

### 下世話

- 達成したいこと
  - 恋人同士の戦いを近くで見届ける。
- そのための方法
  - 恋人関係の二人がいる場合は、その二人の中間付近へ移動して追従する。
  - 二人の近くでは能力が上がり、どちらかが離脱したら自分も戦場から離れる。

### 熱血

- 達成したいこと
  - 周囲の味方と一緒に勢いよく前進する。
- そのための方法
  - 単独で先行せず、近くの味方が前進を始めたときに一緒に敵側へ進む。
  - 自分の近くにいる味方も、同じ敵への攻撃と前進を選びやすくする。

### 天真爛漫

- 達成したいこと
  - 敵を攻撃せずに引きつけ、周囲を動き回る。
- そのための方法
  - 最寄りの敵から一定距離を保ち、その敵の周囲を回り続ける。
  - 敵から狙われやすくする代わりに、一定確率で攻撃を回避する。

### 怠け者

- 達成したいこと
  - 必要な状況でも行動を怠ける。
- そのための方法
  - 移動またはスキル使用の後に、他の性格より長い待機時間を挟む。
  - 危険が迫るか味方から離れすぎた場合は待機を終える。

### スケベ

- 達成したいこと
  - 異性の近くで戦う。
- そのための方法
  - 最寄りの異性を同行対象にし、その周囲で武器本来の行動を行う。
  - 同行対象の近くでは能力が上がり、離れた場合は合流を優先する。

### 寂しがり

- 達成したいこと
  - 単独行動を避け、味方と一緒に行動する。
- そのための方法
  - 常に最寄りの味方と一定距離以内を維持する。
  - 一人になった場合は現在の行動を中断し、味方へ合流してから再開する。

### 一匹狼

- 達成したいこと
  - 味方と別の敵を単独で相手にする。
- そのための方法
  - 周囲に味方が少ない敵を優先する。
  - 現在の敵へ味方が合流したら、まだ誰も相手をしていない別の敵へ移る。

### クソ真面目

- 達成したいこと
  - 不意打ちを避け、敵と正面から戦う。
- そのための方法
  - 森林、隠密、回り込みを使わず、敵の正面へ最短経路で進む。
  - 正面へ到達した後は武器本来の距離と攻撃方法で戦う。

### 猪突猛進

- 達成したいこと
  - 敵キャラクターを無視して敵魔石を破壊する。
- そのための方法
  - 戦闘開始から敵魔石を目的にし、途中の敵へ対象を変えず直進する。
  - 敵魔石へ到達した後は、破壊されるまで攻撃を続ける。

### メンヘラ

- 達成したいこと
  - 自分を守らなかった味方へ報復する。
- そのための方法
  - 自分がダメージを受けたとき、庇える位置にいた味方を一人記憶する。
  - その味方へ接近して一度報復した後、通常の武器行動へ戻る。
