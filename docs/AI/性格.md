# 性格

性格は武器の役割や6つの目的を置き換えず、目的・対象・移動へ偏りを加える。
固有ステートや性格ごとの実行クラスは増やさない。

実装の入口: `CombatAiPersonalityKind`、`CombatAiPersonalityProfile`、`CombatAiPersonalityBehavior`、`CombatAiPlanner`

## 意図

| 性格 | 行動の偏り |
|---|---|
| 標準 | 武器と目的の通常ルールに従う |
| 陽キャ | 人が集まる場所へ寄る |
| 戦闘狂 | 認識した敵を追い、いなければ敵魔石へ向かう |
| 狡猾 | 敵の少ない進攻ルートを選ぶ |
| 献身的 | 危険な味方へ駆けつける |
| 寂しがり | 味方と合流するまで戦闘行動を控える |
| 猪突猛進 | 敵魔石への前進を優先する |
| 門番 | 自軍魔石の防衛を優先する |
| 便乗屋 | 指定された味方の計画に同調する |
| 復讐鬼 | 直近の攻撃者を追う |
| 高所好き | 高所を維持し、そこから行動する |
| 影薄い | 通常の敵対象として後回しになる |

## 共通ルール

- 条件を満たせないときは通常の目的・対象・移動へ戻る。
- 性格は全武器に適用し、想定武器は演出・編成上の目安に留める。
- `PersonalitySignature` は診断・観戦用の行動理由であり、目的そのものではない。

検証は勝敗より先に、発火条件 → Plan → 行動開始 → 完了をログで確認する。
