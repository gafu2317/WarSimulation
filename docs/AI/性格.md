# 性格

性格は武器の役割や6つの目的を置き換えず、目的・対象・移動へ偏りを加える。
固有ステートや性格ごとの実行クラスは増やさない。

実装の入口: `CombatAiPersonalityKind`、`CombatAiPersonalityProfile`、`CombatAiPersonalityBehavior`、`CombatAiPlanner`

## 意図

| 性格 | 行動の偏り |
|---|---|
| 標準 | 武器と目的の通常ルールに従う |
| 陽キャ | 人が集まる場所へ寄る。武器・手動補正込みの最大HP・STR・INT・FAI・AGIが常時10%増加する（確定仕様） |
| 戦闘狂 | 認識した敵を追い、いなければ敵魔石へ向かう |
| 狡猾 | 敵の少ない進攻ルートを選ぶ。武器・手動補正込みのAGIが常時20%増加する（確定仕様） |
| 献身的 | 危険な味方へ駆けつける |
| 寂しがり | 味方と合流するまで戦闘行動を控える |
| 猪突猛進 | 敵魔石へ一直線に前進し、魔石を狙えるダメージ技能を優先する。武器補正込みのAGIが20%減少する |
| 門番 | 自軍魔石の防衛を優先する。最大HPが20%増加する |
| 便乗屋 | 指定された味方の計画に同調する |
| 復讐鬼 | 直近の攻撃者を追う |
| 高所好き | 高所を維持し、そこから行動する |
| 影薄い | 通常の敵対象として後回しになる |

## 共通ルール

- 条件を満たせないときは通常の目的・対象・移動へ戻る。
- 性格は全武器に適用し、想定武器は演出・編成上の目安に留める。
- `PersonalitySignature` は診断・観戦用の行動理由であり、目的そのものではない。

検証は勝敗より先に、発火条件 → Plan → 行動開始 → 完了をログで確認する。

猪突猛進のAGI減少は戦闘中の実効値に適用する。武器補正込みの値を0.8倍して四捨五入し、最低1とした後に一時的なAGIバフ・デバフを適用する。基礎能力データは変更せず、性格を変更すると性格による減少は解除される。復帰待ちは変更しない。

門番の最大HPと狡猾のAGIは、手動・武器補正後の値を1.2倍して四捨五入し、最低1とする。門番は戦闘開始・復帰時に増加後の最大HPまで回復する。補正は常時適用し、性格を変更すると解除する。

## 狡猾の確定仕様

AGI＋20%を標準の性格効果として採用する。進攻中・非交戦中などの条件は設けず、全武器・戦闘中の全行動に適用する。

計算順は基礎AGI＋武器補正＋手動補正 → 1.2倍して四捨五入・最低1 → 一時的なAGIバフ・デバフ。例: 補正前30なら36、31なら37。基礎AGIそのものは書き換えず、性格変更で解除し、再設定しても重複しない。

実装は `CombatAiPersonalityProfile.CunningAgiMultiplier` と `GetStatMultiplier` を共通の定義とし、戦闘の実効AGIと編成画面の補正後表示で同じ倍率を使う。

## 陽キャの確定仕様

最大HP・STR・INT・FAI・AGI＋10%を標準の性格効果として採用する。全武器に常時適用し、AIの行動は変更しない。

計算順は基礎能力＋武器補正＋手動補正 → 1.1倍して四捨五入・最低1 → 一時的な能力バフ・デバフ。最大HPは戦闘開始・復帰時に増加後の最大HPまで回復する。基礎能力そのものは書き換えず、性格変更で解除し、再設定しても重複しない。

実装は `CombatAiPersonalityProfile.AttentionSeekerStatMultiplier` と `GetStatMultiplier` を共通の定義とし、戦闘と編成画面で同じ倍率を使う。全ステータス＋20%は過去の検証条件であり、採用値は＋10%。
