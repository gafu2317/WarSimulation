# 性格

関連: [README](README.md) · [判断の流れ](判断の流れ.md) · [コンボ](コンボ.md)

性格は武器の役割を置き換えない。武器の周期の上に、**観戦して一眼で分かる仕草を一つ**足す。

表現は採点補正と少数の Signature／強制寄り・技能ゲートに留め、排他的な固有状態パイプラインは置かない。
性格ごとの実行クラスは置かない。意図は本ドキュメント、実装は `CombatAiPlanner` と `CombatAiPersonalityProfile`（`Assets/Scripts/Combat/Characters/AI/`）に集約する。

## 設計方針（見てわかる優先）

1. 各性格は「戦場で区別できる仕草」を一つ持つ。仕草が薄い性格は、係数だけでは調整しない。
2. 効きやすい順にレバーを使う。弱い加点の積み上げで差を出そうとしない。
3. 武器の目的枠（攻撃／支援／魔石／防衛）は壊さない。性格は偏りと例外に留める。
4. 強制寄り（極端な加点／減点）は、その性格の核そのものに必要な場合だけ使う。

### レバーの優先順位

| 優先 | レバー | 見えるもの | 使いどころ |
|---|---|---|---|
| 1 | `PersonalitySignature` 移動 | 立ち位置・移動先 | 主戦力。まずここを太くする |
| 2 | Kind 別の目的・スキル加点／減点と強制寄り | 何を選ぶか | 猪突・戦闘狂・寂しがりの単独時など |
| 3 | プロファイル係数 | 全体の温度感 | 最後の微調整だけ |

### 見え方の段階

| 段階 | 意味 | 対象の扱い |
|---|---|---|
| A はっきり見える | Signature か強制寄りで仕草が成立 | 維持し、差が埋もれたら Signature 当選を強める |
| B 見える化が必要 | 意図はあるが観戦では埋もれやすい | Signature／目的偏りを厚くする調整対象 |
| C 味付け | たまに違う程度 | 仕草を足すか、薄い味付けのままにする |

## フックの種類

| フック | 役割 |
|---|---|
| プロファイル係数 | Aggression / Caution 等が目的・移動・スキル点へ |
| Kind 別の加点・減点 | 目的・移動・スキルへの偏り |
| `PersonalitySignature` 移動 | 性格固有の位置を通常候補と競合 |
| Kind 強制寄り／技能ゲート | 猪突・戦闘狂・寂しがり単独時など |

## Kind 一覧

標準 / 目立ちたがり屋 / 戦闘狂 / 狡猾 / 献身的 / 寂しがり / 猪突猛進

## 見てわかる行動（設計の核）

観戦チェックは「このキャラだけ見て、性格が分かるか」。

| 性格 | 見てわかる行動 | 段階 | 主レバー | 適正武器 |
|---|---|---|---|---|
| 標準 | 武器の役割どおり | — | なし | 全武器 |
| 目立ちたがり屋 | キャラの多いところへ寄る | B | Signature | 盾 |
| 戦闘狂 | 何があっても敵への攻撃をやめない | A | 強制寄り＋フォーカス維持 | 剣、杖 |
| 狡猾 | 敵の少ないルートで魔石へ向かう | A | 目的加点＋ルートリスク | 剣、杖 |
| 献身的 | 低HPの味方のもとへ駆けつける | A | Signature | 盾、ロザリオ、聖書 |
| 寂しがり | 仲間と行動し、一人だと探索だけする | A | Signature＋単独時ゲート | ロザリオ、聖書、盾 |
| 猪突猛進 | 敵を無視して敵魔石へ直進 | A | 強制寄り＋Signature | 杖、剣 |

## 強制寄り・技能ゲート（許容する少数）

| 性格 | 例外 |
|---|---|
| 寂しがり | 近くに味方がいない間は攻撃・支援スキルを出さず、探索目的と味方合流移動だけを選ぶ |
| 猪突猛進 | 魔石破壊と魔石前進を強く選ぶ（強制寄り） |
| 戦闘狂 | 敵攻撃目的を強く選ぶ（強制寄り）。フォーカス粘着が長い |

それ以外は採点と Signature で表現する。

## 調整の進め方

1. A 段階は仕草が消えないよう維持する。埋もれたら Signature／例外の頻度を上げる。
2. B 段階を優先して厚くする。目標は「ログを見なくても移動だけで区別できる」。
3. C 段階は、仕草を一つ足すか、薄い味付けのままにするかを決めてから触る。
4. 自動戦闘では診断ログの目的・移動コード偏りと、観戦の両方で確認する。
5. Aggression / Caution などの係数は、仕草が成立したあとの温度調整にだけ使う。

## 各性格の意図

各項の「見てわかる行動」が設計の核。方法はその仕草を成立させる手段。
適正武器は仕草が武器周期と噛み合う組み合わせ（編成・観戦の目安）。他武器を禁じない。

## 標準

- 適正武器
  - 全武器（剣、盾、杖、魔導書、聖書、ロザリオ）
- 見てわかる行動
  - 武器の役割どおり。
- 達成したいこと
  - 装備武器の周期をそのまま見せる。
- そのための方法
  - 性格由来の偏りを足さない。

## 目立ちたがり屋

- 適正武器
  - 盾
- 見てわかる行動
  - キャラの多いところへ寄る。
- 達成したいこと
  - 人が集まっている場所で目立つ。
- そのための方法
  - 味方と敵を含む生存キャラの密集塊を探し、その重心へ移動する。
  - 密集が動いたら、その重心付近を追いかけて位置を取り直す。

## 戦闘狂

- 適正武器
  - 剣、杖
- 見てわかる行動
  - 何があっても敵への攻撃をやめない。
- 達成したいこと
  - 魔石や撤退より、敵キャラへの攻撃を続ける。
- そのための方法
  - 敵攻撃目的を強く選び、魔石破壊や撤退を後回しにする。
  - 一度掴んだ敵を長く追い、対象を変えにくくする。
  - 敵キャラを認識できない間は、敵魔石へ進む。

## 狡猾

- 適正武器
  - 剣、杖
- 見てわかる行動
  - 敵の少ないルートを使って魔石へ向かう。
- 達成したいこと
  - 交戦を避けつつ敵魔石を狙う。
- そのための方法
  - 敵魔石破壊を目的に選び、進攻ルート候補のうち経路リスクが低いものを強く選ぶ。
  - 敵の多い直線路より、迂回路や橋経由を優先する。

## 献身的

- 適正武器
  - 盾、ロザリオ、聖書
- 見てわかる行動
  - 一定範囲内のHPが低い味方のもとへ駆けつける。
- 達成したいこと
  - 傷付いた味方へ寄り、援護する。
- そのための方法
  - 一定半径内でHP比率が低い味方を見つけたら、そのもとに移動する。
  - 支援目的と援護スキルを選びやすくする。

## 寂しがり

- 適正武器
  - ロザリオ、聖書、盾
- 見てわかる行動
  - 他のキャラと一緒に行動する。一人になると行動せず他のキャラを探し続ける。
- 達成したいこと
  - 単独行動を避け、味方と一緒に行動する。
- そのための方法
  - 近くに味方がいる間は味方と一定距離を保ちながら通常行動する。
  - 一人になった場合は攻撃や支援をせず、味方探索の移動だけを続ける。

## 猪突猛進

- 適正武器
  - 杖、剣
- 見てわかる行動
  - 途中の敵を無視して敵魔石へ直進する。
- 達成したいこと
  - 敵キャラクターを無視して敵魔石を破壊する。
- そのための方法
  - 戦闘開始から敵魔石を目的にし、途中の敵へ対象を変えず直進する。
  - 敵魔石へ到達した後は、破壊されるまで攻撃を続ける。

## 検討中

以下は、単体では明確な欠点を持ち、別のキャラクターがその欠点を補ったときに強くなる性格案。
「有利な行動を少し選びやすい」ではなく、戦場で一目で分かる偏りと、相手が突ける破綻の両方を持たせる。

### 現在のマップ・戦闘データから使える軸

- マップは約60m四方で、平地視界は30m、高所視界は現行マップのほぼ全域まで伸びる。高所は魔導書のデバフ、聖書のバフ、敵情報の共有と特に噛み合う。
- 現行の手作りマップには、川・湖・森・橋・複数の進攻ルートを持つものと、それらがほとんどないものがある。地形依存の性格はマップ選択の強弱も生む。
- 未認識の相手への奇襲は1.5倍、杖の魔弾は遠距離ほど強く、ロザリオの遠隔癒しは近距離ほど強い。立ち位置を極端に選ぶ性格に実利と弱点を同時に与えられる。
- 大技には1.0〜2.5秒の詠唱と長いCTがあり、拘束は3秒、範囲攻撃・回復は半径3m。拘束、密集、詠唱保護を別キャラクターに分けると連携が生まれる。
- ロザリオの神の雷は認識敵全体へ届くが、自分も12ダメージを受ける。無敵や肩代わりと組み合わせる余地がある。

### 検討時の制約

- 各性格は表の「見てわかる行動」を1つだけ Signature として持つ。強みを追加するための専用ステートは作らない。
- 強制寄りや技能ゲートを使う場合は、表の欠点が実際に起き、標準性格より安定しないことを残す。
- 各案は、相性が良いマップだけでなく、平坦で遮蔽の少ないマップと進攻ルートが分かれるマップの両方で観戦する。
- 採用条件は「単体で弱い」ではなく、「弱点を意図して補った編成でのみ強みが再現し、相手にも崩す手段が見える」こととする。

### 事前検証

勝率より先に、性格の仕草が実際に発火するかを確認する。

1. `CombatAiPlanner.BuildDebugSnapshot` を使い、発火条件あり・なし・欠点が出る状況の単体テストを作る。
2. 自動戦闘で「発火機会 → 性格候補の選択 → 行動開始 → 完了 → 成果」を集計する。途中が0なら、勝敗にかかわらず未機能とみなす。
3. 同じマップ・編成・シード・魔石配置で Neutral と比較し、意図した強みと欠点の両方が増えるかを見る。
4. 組み合わせは「Neutral＋Neutral」「性格＋Neutral」「Neutral＋補完役」「性格＋補完役」の4条件で比較し、補完役が単独で強いだけでないことを確認する。

発火しない、行動が完了しない、Neutralと差がない、欠点が出ない、補完役を入れても改善しない性格は、人力観戦の前に不採用または再調整とする。
