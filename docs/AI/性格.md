# 性格

関連: [README](README.md) · [判断の流れ](判断の流れ.md)

性格は、武器の役割と通常AIの優先順を置き換えず、目的・対象・移動・技能選択に一つの偏りを加える。性格固有の条件は装備武器を判定せず、同じロジックを全武器へ適用する。

「想定武器（参考）」は仕草と武器の周期が噛み合う編成の目安であり、実装の分岐条件ではない。他の武器でも同じ性格として動く。

## 実装状況

- **実装済み**: 下表の13種類。`CombatAiPersonalityKind` に登録され、共通の `CombatAiPlanner` などから実行される。
- **検証中**: コードに存在していても、固有行動の発火・開始・完了を確認するまでは検証中として扱う。勝敗は別の評価である。

性格の実装は `CombatAiPersonalityProfile`、`CombatAiContextCollector`、`CombatAiBrain`、`CombatAiPlanner`、`CombatAiPersonalityBehavior` に分担し、性格ごとの実行クラスは作らない。

## 実装済み性格

| 性格 | `Kind` | 見てわかる行動 | 性格による制御 | 想定武器（参考） |
|---|---|---|---|---|
| 標準 | `Neutral` | 武器の役割どおりに動く。 | 性格による上書きなし。 | 全武器 |
| 陽キャ | `AttentionSeeker` | `Search` 中にキャラが集まる場所へ寄る。 | 密集の重心を `PersonalitySignature` で選ぶ。 | 盾 |
| 戦闘狂 | `BattleJunkie` | 一度認識した敵を見失っても最終既知地点まで追い、認識中の敵がいなければ敵魔石へ向かう。 | `AttackEnemy` を優先し、直接視認と認識保持の対象へのフォーカスを長く保持する。 | 剣、杖 |
| 狡猾 | `Cunning` | 敵の少ないルートで敵魔石へ向かう。 | 進攻ルートのリスクを比較し、低リスク候補を優先する。 | 剣、杖 |
| 献身的 | `Devoted` | HPの低い味方のもとへ駆けつける。 | 支援対象への移動を `PersonalitySignature` として優先する。 | 盾、ロザリオ、聖書 |
| 寂しがり | `Lonely` | 味方が近くにいない間は攻撃・支援をせず、味方を探す。 | 単独時は `Search` と合流移動だけを選ぶ。 | ロザリオ、聖書、盾 |
| 猪突猛進 | `Reckless` | 敵を無視して敵魔石へ進む。 | `DestroyEnemyStone` を優先し、敵魔石を中心に実行できるダメージ技能だけを使う。 | 杖、剣 |
| 門番 | `Gatekeeper` | 自軍魔石へ戻り、魔石前で脅威を迎撃する。 | 自軍魔石位置が分かる間は `DefendOwnStone` を優先し、脅威範囲外の敵は追わない。 | 全武器 |
| 便乗屋 | `Tagalong` | 近くの味方と同じ目的・対象または目的地へ向かう。 | 目的を持つ最寄りの味方を選び、その計画と対象へ同調する。 | 全武器 |
| 復讐鬼 | `Avenger` | 直近で自分を攻撃した敵を、位置が分かる間は追う。 | 攻撃者を `AttackEnemy` の対象として保持し、見失うと解除する。 | 剣、盾 |
| 浪漫派 | `BigMagic` | 大技だけを候補にし、条件が整うまで通常攻撃を使わない。 | 大技分類の技能だけを選び、実行できなければ移動・待機する。 | 杖、ロザリオ |
| 高所好き | `HighGround` | 最初に高所へ向かい、到着後は射程内から攻撃・支援し、必要なら敵や敵魔石へ動く。 | 高所到達までは `PersonalitySignature` を優先し、到達後は目的が変わっても高所へ戻り続けない。 | 魔導書、聖書 |
| 怖がり | `StandoffSiege` | 敵との間合いを保ちながら敵魔石を攻撃し、現在位置から攻撃できなければ射程まで前進する。 | `DestroyEnemyStone` と距離を保つ移動を優先し、攻撃不能な待機を続けない。 | 杖 |

## 共通ルール

- 性格の固有行動は、通常の六ステート、ステート内の移動・対象選択、`PersonalitySignature`、技能ゲートで表現する。
- 条件を満たせない場合は通常の目的・対象・技能選択へ戻る。性格専用ステートを時間で固定しない。
- `PersonalitySignature` は観戦・診断用の行動コードであり、性格名や武器名の別名ではない。

## 未実装・検討中

現在、未実装の性格案はない。新しい案を考える場合はここに「未実装」と明記し、コード登録と固有行動の検証が終わったら「実装済み性格」へ移す。

## マップ・戦闘データとの相性

- 高所は視界と射線が広く、魔導書の妨害・聖書の支援・高所好きと相性がよい。
- 川・湖・森・橋・複数ルートの有無で、狡猾の低リスク移動、怖がりの距離取り、門番の防衛範囲が変わる。
- 拘束・範囲攻撃・回復には詠唱時間や範囲があるため、詠唱中の位置取りが検証対象になる。

## 検証

勝敗より先に、性格固有の行動が観戦できる形で成立するかを確認する。

1. `CombatAiPlanner.BuildDebugSnapshot` で、発火条件あり・なし・欠点が出る状況を確認する。
2. 自動戦闘の `AI_PLAN` で性格理由または `PersonalitySignature` の発火を確認し、`AI_EXECUTE` で移動・技能の開始と失敗理由を確認する。
3. 同じマップ・編成・シードで標準性格と比較し、固有行動の発火機会 → 計画選択 → 行動開始 → 完了を記録する。
4. どれか一つでも観測できなければ、その性格は「実装済み・未検証」として人力観戦や勝率比較へ進めない。

勝敗・ダメージ・勝率は、固有行動の動作確認が終わった後に、必要な評価として別途確認する。
