# 性格

関連: [README](README.md) · [判断の流れ](判断の流れ.md) · [コンボ](コンボ.md)

性格は武器の役割を置き換えない。武器の周期の上に、**観戦して一眼で分かる仕草を一つ**足す。

表現は採点補正と少数の Signature／Runtime 例外に留め、排他的な固有状態パイプラインは置かない。

## 設計方針（見てわかる優先）

1. 各性格は「戦場で区別できる仕草」を一つ持つ。仕草が薄い性格は、係数だけでは調整しない。
2. 効きやすい順にレバーを使う。弱い加点の積み上げで差を出そうとしない。
3. 武器の目的枠（攻撃／支援／魔石／防衛）は壊さない。性格は偏りと例外に留める。
4. 強制寄り（極端な加点／減点）は、その性格の核そのものに必要な場合だけ使う。

### レバーの優先順位

| 優先 | レバー | 見えるもの | 使いどころ |
|---|---|---|---|
| 1 | `PersonalitySignature` 移動 | 立ち位置・移動先 | 主戦力。まずここを太くする |
| 2 | Kind 別の目的・スキル加点／減点 | 何を選ぶか | 猪突・天真・戦闘狂など核の選択 |
| 3 | Runtime 例外 | 特殊行動 | 報復・ポーズ・回避・関係補正など少数 |
| 4 | プロファイル係数 | 全体の温度感 | 最後の微調整だけ |

### 見え方の段階

| 段階 | 意味 | 対象の扱い |
|---|---|---|
| A はっきり見える | Signature か Runtime で仕草が成立 | 維持し、差が埋もれたら Signature 当選を強める |
| B 見える化が必要 | 意図はあるが観戦では埋もれやすい | Signature／目的偏りを厚くする調整対象 |
| C 味付け | たまに違う程度 | 仕草を足すか、薄い味付けのままにする |

## フックの種類

| フック | 役割 |
|---|---|
| プロファイル係数 | Aggression / Caution 等が目的・移動・スキル点へ |
| Kind 別の加点・減点 | 目的・移動・スキルへの偏り |
| `PersonalitySignature` 移動 | 性格固有の位置を通常候補と競合 |
| Runtime 例外 | ごく少数（報復、関係補正、短時間ポーズ、被弾回避など） |

## Kind 一覧

目立ちたがり屋 / 戦闘狂 / 冷静 / 慎重 / おっちょこちょい / 臆病者 / 狡猾 / 卑怯者 / 献身的 / 不思議ちゃん / 下世話 / 熱血 / 天真爛漫 / 怠け者 / スケベ / 寂しがり / 一匹狼 / クソ真面目 / 猪突猛進 / メンヘラ

## 一眼の仕草（設計の核）

観戦チェックは「このキャラだけ見て、性格が分かるか」。

| 性格 | 一眼の仕草 | 段階 | 主レバー |
|---|---|---|---|
| 目立ちたがり屋 | 敵の正面・目立つ位置へ出る | B | Signature |
| 戦闘狂 | 一度掴んだ敵を追い続ける | B | 目的加点＋フォーカス維持 |
| 冷静 | 危なくなったときだけはっきり下がる | C→B | 撤退目的の条件付き加点 |
| 慎重 | 直線突撃せず迂回・待機してから前進 | C→B | 安全移動の加点 |
| おっちょこちょい | たまに変な方向／対象へ寄る | C | Signature（稀） |
| 臆病者 | 味方の後ろへ下がる | B | Signature＋撤退 |
| 狡猾 | 撃ったあと森・遮蔽へ引っ込む | B | Signature |
| 卑怯者 | 味方を盾にしてその後ろにいる | B | Signature |
| 献身的 | 味方と敵の間に割って入る | A/B | Signature |
| 不思議ちゃん | ときどき無関係な行動へ切り替わる | C | 無作為加点 |
| 下世話 | 恋人二人の間にへばりつく | A | Signature＋Runtime |
| 熱血 | 味方の前進に合わせて一緒に出る | B | Signature（味方） |
| 天真爛漫 | 攻撃せず敵の周囲をぐるぐる回る | A | Signature＋攻撃回避＋被弾回避 |
| 怠け者 | 行動のあとしばらく立ち止まる | A | Runtime ポーズ |
| スケベ | 異性のそばへ合流して戦う | A | Signature＋Runtime |
| 寂しがり | 常に味方に張り付く | B | Signature（味方） |
| 一匹狼 | 味方がいない敵へ寄る | B | Signature |
| クソ真面目 | 森を避けて正面から最短接近 | B | Signature＋森移動減点 |
| 猪突猛進 | 敵を無視して敵魔石へ直進 | A | 強制寄り＋Signature |
| メンヘラ | 庇わなかった味方へ一度報復する | A | Runtime 報復計画 |

## Runtime 例外（許容する少数）

| 性格 | 例外 |
|---|---|
| メンヘラ | 報復計画が通常 BuildPlan より先に確定しうる |
| 怠け者 | 行動後の短時間ポーズ |
| 下世話 | 恋人追従と近傍の能力補正。片割れ離脱で自分も離脱 |
| スケベ | 異性への合流と距離による能力補正 |
| 天真爛漫 | 攻撃を大きく避け、被弾を低確率で無効化しうる |
| 猪突猛進 | 魔石破壊と魔石前進を強く選ぶ（強制寄り） |
| おっちょこちょい | Signature が稀に誤った方向へ寄る |
| 不思議ちゃん | 間隔つきの無作為寄りの加点 |

それ以外は採点と Signature で表現する。

## 調整の進め方

1. A 段階は仕草が消えないよう維持する。埋もれたら Signature／例外の頻度を上げる。
2. B 段階を優先して厚くする。目標は「ログを見なくても移動だけで区別できる」。
3. C 段階は、仕草を一つ足すか、薄い味付けのままにするかを決めてから触る。
4. 自動戦闘では診断ログの目的・移動コード偏りと、観戦の両方で確認する。
5. Aggression / Caution などの係数は、仕草が成立したあとの温度調整にだけ使う。

## 各性格の意図

各項の「一眼の仕草」が設計の核。方法はその仕草を成立させる手段。

## 目立ちたがり屋

- 一眼の仕草
  - 敵から見える正面へ出る。
- 達成したいこと
  - 敵の注意を自分へ集める。
- そのための方法
  - 武器の有効距離を保ちながら、複数の敵から見える正面位置へ出る。
  - 敵の注意が別の味方へ向いた場合は、再び敵の正面へ移動する。

## 戦闘狂

- 一眼の仕草
  - 同じ敵を長く追い、途中で魔石や別敵へ切り替えない。
- 達成したいこと
  - 一度始めた敵との戦闘を最後まで続ける。
- そのための方法
  - 一度攻撃した敵を長く追い、敵が逃げても対象を変えにくくする。
  - 攻撃対象が生存している間は、魔石破壊や別対象への変更を後回しにする。

## 冷静

- 一眼の仕草
  - 危険が乗った瞬間だけ、はっきり後退する。
- 達成したいこと
  - 危険なときに退き、無駄な離脱を防ぐ。
- そのための方法
  - 自分の危険度が基準を超えたときだけ、現在の行動を中断して後退する。
  - 安全な位置まで下がったら停止せず、元の武器役割へ戻る。

## 慎重

- 一眼の仕草
  - 危険な直線路を避け、迂回や待機してから前進する。
- 達成したいこと
  - 交戦地点へ向かう間の被害を減らす。
- そのための方法
  - 敵の射程を横切る直線経路を避け、安全な迂回路を通って交戦位置へ向かう。
  - 安全な経路がない場合は味方の到着を待ってから前進する。

## おっちょこちょい

- 一眼の仕草
  - たまにだけ、明らかにおかしな移動や対象選択をする。
- 達成したいこと
  - 普段は通常どおり行動し、まれに判断を間違える。
- そのための方法
  - 低い確率で、通常計画が選んだ対象、移動先、スキルのいずれか一つを、実行可能な別候補から無作為に選び直す。
  - 一つの判断で間違える項目は一つだけとし、その計画を一度実行した後は通常の武器行動へ戻る。

## 臆病者

- 一眼の仕草
  - 狙われたら味方の後ろへ下がる。
- 達成したいこと
  - 敵の注意と危険な交戦を避ける。
- そのための方法
  - 敵から狙われたら、攻撃や支援を中断して最寄りの味方の後ろへ下がる。
  - 敵の注意が外れた後も、味方より前へ出ない位置を維持する。

## 狡猾

- 一眼の仕草
  - 何かした後、森や遮蔽へ引っ込む。
- 達成したいこと
  - 敵に見つかりにくい位置から攻撃する。
- そのための方法
  - 攻撃、妨害、支援のいずれかを行った後、敵の射線が切れる森林や遮蔽物へ移動する。
  - 射線を切った後は同じ場所へ留まらず、別方向から再び射程へ入る。

## 卑怯者

- 一眼の仕草
  - 常に味方の影にいる。
- 達成したいこと
  - 味方を盾にして自分への攻撃を避ける。
- そのための方法
  - 最寄りの敵と自分の間に味方が入る位置を維持する。
  - 間にいる味方が移動した場合は、その味方の後方へ追従する。

## 献身的

- 一眼の仕草
  - 狙われた味方の前に割って入る。
- 達成したいこと
  - 自分が危険を負って味方を守る。
- そのための方法
  - 敵に狙われている味方を見つけたら、その味方と敵の間へ移動する。
  - 味方への危険がなくなるまで前方を維持し、その後に武器本来の位置へ戻る。

## 不思議ちゃん

- 一眼の仕草
  - 戦況と無関係な行動へ、ときどき切り替わる。
- 達成したいこと
  - 戦況によらない予測不能な行動をする。
- そのための方法
  - 一定時間ごとに、実行可能な目的、移動、スキルを無作為に選び直す。
  - 同じ行動へ固執せず、他の性格より頻繁に進行方向と対象を変える。

## 下世話

- 一眼の仕草
  - 恋人二人の間にへばりついてついて回る。
- 達成したいこと
  - 恋人同士の戦いを近くで見届ける。
- そのための方法
  - 恋人関係の二人がいる場合は、その二人の中間付近へ移動して追従する。
  - 二人の近くでは能力が上がり、どちらかが離脱したら自分も戦場から離れる。

## 熱血

- 一眼の仕草
  - 味方が出たら一緒に前へ出る。
- 達成したいこと
  - 周囲の味方と一緒に勢いよく前進する。
- そのための方法
  - 単独で先行せず、近くの味方が前進を始めたときに一緒に敵側へ進む。
  - 自分の近くにいる味方も、同じ敵への攻撃と前進を選びやすくする。

## 天真爛漫

- 一眼の仕草
  - 攻撃せず、敵の周囲をぐるぐる回る。
- 達成したいこと
  - 敵を攻撃せずに引きつけ、周囲を動き回る。
- そのための方法
  - 最寄りの敵から一定距離を保ち、その敵の周囲を回り続ける。
  - 敵から狙われやすくする代わりに、一定確率で攻撃を回避する。

## 怠け者

- 一眼の仕草
  - 動いたあと、しばらくその場で止まる。
- 達成したいこと
  - 必要な状況でも行動を怠ける。
- そのための方法
  - 移動またはスキル使用の後に、他の性格より長い待機時間を挟む。
  - 危険が迫るか味方から離れすぎた場合は待機を終える。

## スケベ

- 一眼の仕草
  - 異性のそばへ寄って、そこを拠点に戦う。
- 達成したいこと
  - 異性の近くで戦う。
- そのための方法
  - 最寄りの異性を同行対象にし、その周囲で武器本来の行動を行う。
  - 同行対象の近くでは能力が上がり、離れた場合は合流を優先する。

## 寂しがり

- 一眼の仕草
  - 味方から離れたら、すぐ合流しに行く。
- 達成したいこと
  - 単独行動を避け、味方と一緒に行動する。
- そのための方法
  - 常に最寄りの味方と一定距離以内を維持する。
  - 一人になった場合は現在の行動を中断し、味方へ合流してから再開する。

## 一匹狼

- 一眼の仕草
  - 味方がいない敵を選び、単独で寄る。
- 達成したいこと
  - 味方と別の敵を単独で相手にする。
- そのための方法
  - 周囲に味方が少ない敵を優先する。
  - 現在の敵へ味方が合流したら、まだ誰も相手をしていない別の敵へ移る。

## クソ真面目

- 一眼の仕草
  - 森や回り込みを使わず、正面から最短で接近する。
- 達成したいこと
  - 不意打ちを避け、敵と正面から戦う。
- そのための方法
  - 森林、隠密、回り込みを使わず、敵の正面へ最短経路で進む。
  - 正面へ到達した後は武器本来の距離と攻撃方法で戦う。

## 猪突猛進

- 一眼の仕草
  - 途中の敵を無視して敵魔石へ直進する。
- 達成したいこと
  - 敵キャラクターを無視して敵魔石を破壊する。
- そのための方法
  - 戦闘開始から敵魔石を目的にし、途中の敵へ対象を変えず直進する。
  - 敵魔石へ到達した後は、破壊されるまで攻撃を続ける。

## メンヘラ

- 一眼の仕草
  - 味方へ寄って一度殴る／報復する。
- 達成したいこと
  - 自分を守らなかった味方へ報復する。
- そのための方法
  - 自分がダメージを受けたとき、庇える位置にいた味方を一人記憶する。
  - その味方へ接近して一度報復した後、通常の武器行動へ戻る。
