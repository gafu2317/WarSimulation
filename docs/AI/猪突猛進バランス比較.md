# 猪突猛進の能力デバフと復帰待ちの比較

`Tools/AutoBattle/balance_comparison.py` は、固定した5編成を全条件で総当たりにする。条件ごとの編成選抜は行わず、マップ・配置・乱数シードを揃える。

初期設定は以下の66条件、計7,920試合。

- 猪突猛進への補正: なし、HP / STR / INT / FAI / AGI / HP＋AGI / STR＋INT＋FAI の各10%・20%・30%減（22通り）。
- 全員の自陣到着後の復帰待ち: 15秒・30秒・60秒（3通り）。撃破から自陣へ撤退する時間は別に加算される。
- 混成、魔石速攻、剣5人・猪突猛進、盾だけ門番、聖書だけ猪突猛進の5編成。3マップ×魔石配置の両方向、同編成同士は除く。

能力倍率は両軍の猪突猛進だけに適用する。HPは最大HP、他の能力は武器補正込みの値を四捨五入し、最低1とする。通常プレイでは猪突猛進のAGIを20%減少させる。`Balance` の `RecklessAGIMultiplier` を省略または-1にすると性格の既定値0.8を使う。0より大きく1以下を明示するとAGIの性格倍率をその値へ置き換えるため、0.8指定で二重に減少しない。1指定は旧仕様の無補正比較用。ほかの能力倍率は省略時1、復帰待ちはプレハブ既定値となる。

```sh
python3 Tools/AutoBattle/balance_comparison.py --output-directory Logs/AutoBattleBalance/example --plan-only
python3 Tools/AutoBattle/balance_comparison.py --output-directory Logs/AutoBattleBalance/example
```

`--multipliers 0.95 0.85`、`--revive-delays 15 20 45`、`--matches 8` で範囲を変更できる。設定を変える場合は別の出力先を使う。実行中にPlayerを更新する場合に備え、長時間実行ではPlayerと設定のコピーを固定して使う。

`plan.json` に条件と試合数、`summary.md` に条件別勝率、各条件の `summary.md` に対戦相手・マップ別結果を保存する。初期設定は各方向・マップにつき1シードの予備評価であり、有望な条件は試合数を増やして再確認する。復帰前に決着する短い試合では復帰待ちの延長が影響しない。

完了通知は既存の `run_with_notification.py` を使う。ローカルプロセスが終了を待ってmacOSに通知するため、待機中のCodex呼び出しはない。失敗時も通知し、`process-status.json` に状態を記録する。

## 魔石速攻を固定した比較

`reckless-target-comparison.json` は剣2・杖2が猪突猛進、ロザリオが献身的の編成を対象とする。敵は猪突猛進を含まない決勝上位の「聖書戦闘狂の混成」と「杖便乗屋の混成」。役割の登録順も過去の編成に揃える。

```sh
python3 Tools/AutoBattle/balance_comparison.py --config Tools/AutoBattle/reckless-target-comparison.json --target-name 魔石速攻 --exclude-fai --single-stat-only --keep-revive-delay --output-directory Logs/AutoBattleBalance/target-example
```

4並列・6倍速、2マップの両配置、各方向2シードで13条件・416試合。HP・STR・INT・AGIのいずれか1つだけを10%・20%・30%下げ、無補正と比較する。FAIと複合補正は外し、復帰待ちはプレハブ既定値を維持する。敵同士の対戦は行わず、対象編成を自軍・敵軍の両方に置く。
