# 戦闘AI

戦闘AIは、戦況からいきなり1手を決めない。次の順で候補を採点する。

```text
文脈 → 戦況 → 目的 → 移動 → スキル → 実行
```

魔石破壊も敵攻撃も、同じ「目的」の枠で扱う。
