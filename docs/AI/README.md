# 戦闘AI

戦闘AIは、戦況から優先順に六つのステートを選び、そのステート専用の処理で移動とスキルを一緒に決める。

```text
文脈／戦況 → ステート選択 → ステート別Plan（移動＋スキル） → 実行
```

ステートは既存の `CombatObjective` 六値をそのまま使う。地形利用・追従・遮断・待機・詠唱はステートではなく、各ステート内の行動である。
