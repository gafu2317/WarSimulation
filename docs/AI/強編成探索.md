# 強編成探索

5人対5人、同一キャラクターPrefabの能力・スキル条件で、武器と性格の組み合わせを比べる。
現行の6武器・12性格を全て含む96候補を用意し、6種類の敵を等重みで評価する。
総当たりではなく、測定した候補の中から安定した編成と相性を探す。

## 準備

Unityで `Tools > War Simulation > Auto Battle > Build Search Player` を実行する。
元のGafuTestを探索専用シーンへ複製し、両軍を同じPrefabから生成する。
Playerとマップ・能力の検証結果は `.unity/CombatAutoBattleSearch/` へ出力する。

```bash
python3 Tools/AutoBattle/create_league_config.py \
  --build-metadata .unity/CombatAutoBattleSearch/build.json \
  --output Tools/AutoBattle/league-search.json
python3 Tools/AutoBattle/league_search.py \
  --config Tools/AutoBattle/league-search.json \
  --output-directory Logs/AutoBattleLeague/run_20261004 \
  --plan-only
```

## 評価

- 予選: 96候補を6敵・3マップの通常/反転配置で各2戦。
- 本評価: 上位10候補を6敵・全利用可能マップの通常/反転配置で各8戦。
- リーグ: 上位6候補同士を、両軍入替・全マップの通常/反転配置で各6戦。
- 各段階のシードは分け、同じ段階の候補間では共通シードを使う。
- 時間切れは勝率の分母に含め、時間切れ率も別表示する。
- 平均勝率に加えて相手別・マップ別の結果とAI判断の取りこぼしを確認する。

通常/反転とも9マップを利用できる場合、最大18,792試合となる。
TimeScale=6、固定刻み維持、2 Player並列、各Playerのjob worker=1で揃える。
便乗屋の追随先は役割配列の直前のキャラで、配列順を固定する。配置順の最適化は行わない。
少数試合による選抜なので、僅差を確定した優劣とみなさない。

## 独立実行と通知

Terminal.appから次を実行する。実行中のCodexや外部APIは不要。

```bash
cd /Users/fukutomi/Unity/WarSimulation
python3 Tools/AutoBattle/run_with_notification.py \
  --output-directory Logs/AutoBattleLeague/run_20261004 \
  --title '強編成探索' \
  --result-file Logs/AutoBattleLeague/run_20261004/summary.md \
  -- python3 Tools/AutoBattle/league_search.py \
  --config Logs/AutoBattleLeague/run_20261004/config.json \
  --output-directory Logs/AutoBattleLeague/run_20261004
```

終了時にmacOSへ成功/失敗と結果の場所を通知する。通知表示はmacOSの通知設定に従う。
`process-status.json` が実行状態、`status.json` が対戦段階の進捗、`runner.log` が全体ログ、`summary.md` が結果の入口となる。
Terminalの実行ウィンドウでCtrl+Cを押すと、対戦Playerも終了させて中断状態を保存する。
Macを起動したままにする。実行中はcaffeinateでアイドルスリープを抑制するが、蓋を閉じたスリープや再起動では処理が止まる。
同じ設定・Player・出力先で再実行すると、完了した試合ジョブを再利用する。

2026-10-04の実行は設定・ビルド検証情報・Playerを出力先へ複製し、`start.command` から起動する。
この実行の設定は出力先の `config.json` が正本で、`Player/` の固定したビルドを使う。


## 2026-10-11 性格補正後の再探索

標準効果は門番の最大HP＋20%、狡猾のAGI＋20%、猪突猛進のAGI−20%。復帰待ちは既定値のまま。性格の説明と編成画面の補正後表示にも反映する。

`Tools/AutoBattle/league-search.json` は5人編成96候補、6武器×12性格の72組み合わせを含む。4並列・6倍速、物理の時間刻み維持、Playerのworker数1。両軍は同じキャラクタープレハブを使用する。

- 予選: 96候補×敵6編成×2マップ両配置×1シード＝2,304試合。
- 再評価: 上位10候補×敵6編成×3マップ両配置×4シード＝1,440試合。
- 総当たり: 上位6候補の同編成対戦を除く両軍方向×3マップ両配置×4シード＝720試合。

合計4,464試合。マップはAuthoredMap、AuthoredMap 3、最終段階はAuthoredMap 5も含める。段階ごとにシード範囲を分け、候補間では共通シードを使う。順位は探索した候補と条件内の評価であり、全編成を網羅した最適解ではない。

探索には新Playerとスクリプト・設定を固定したコピーを使い、ローカルの完了・失敗通知を有効にする。待機中のCodex呼び出しは行わない。


## 地形と性格の組み合わせ探索（2026-10-13）

`create_specialist_config.py` と `specialist_search.py` は、全体平均だけで落ちる地形特化候補と、性格同士の組み合わせを探索する。

- 119候補、平地中心・丘陵・森林湿地・川橋・雪氷の5マップ、3対戦相手、両魔石配置。
- 12組の性格ペアは、武器・登録順・残りの性格を固定した基準/A/B/ABの4編成で比較。
- 予選3,570戦。その後、各地形の最良候補・全体上位・有望3組の比較編成・共通基準を選ぶ。
- 最大20の共通候補を全5地形で、新規3シード・両軍入替により再評価。最大3,600戦、起動確認は別に8戦。
- 地形別順位、基準との差、AB−A−B＋基準の組合せ差、相手/配置/軍側別の結果を保存。少数試合の差は暫定。
- 陽キャ全ステ＋10%を含む確定仕様。過去の実験バフは適用しない。4並列・6倍速、物理刻み維持。

```bash
python3 Tools/AutoBattle/create_specialist_config.py --build-metadata .unity/CombatAutoBattleSearch/build.json --output /tmp/specialist-config.json
python3 Tools/AutoBattle/specialist_search.py --config /tmp/specialist-config.json --output-directory Logs/AutoBattleSpecialist/example --plan-only
```

実行時はPlayerと設定・スクリプトを凍結し、既存の`run_with_notification.py`から起動する。2026-10-13の実行先は`Logs/AutoBattleSpecialist/terrain_personality_20261013/`。
