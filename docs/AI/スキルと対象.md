# スキルと対象

関連: [判断の流れ](判断の流れ.md) · [性格](性格.md)

## スキル選択

ステート別Plan生成の中で、使用可能なスキルごとに実行文脈を作り、カテゴリ優先順と対象条件で一つを選ぶ。

選択条件:

- `Retreat`: 保護→回復→不可視
- `SupportAlly`: 回復→保護→強化
- `DefendOwnStone`: 保護→攻撃→弱体
- `AttackEnemy`: 弱体→攻撃→保護
- `DestroyEnemyStone`: 魔石へ当たる攻撃→強化
- `Search`: 移動・不可視

同じカテゴリでは、回復は予約込みの予測HPが低い対象、攻撃は予約ダメージを引いて生存している対象、範囲技は対象数が多い文脈を先にする。全ステートを横断する合計点は使わない。

## 性格による技能・対象の制限

ステートのカテゴリ選択に加えて、性格が次の候補制限をかける。

| 性格 | 制限 |
|---|---|
| 寂しがり | 近くに味方がいない間は、技能を一つも選ばない。`Search` の味方合流移動だけを行う |
| 猪突猛進 | ダメージ技能かつ敵魔石を中心に実行できる技能だけを選ぶ |
| 便乗屋 | リーダーに意図対象がある場合、その対象を含む実行文脈だけを選ぶ。目的地追従だけの場合は通常の対象選択へ戻る |
| 復讐鬼 | 直近攻撃者を含む実行文脈だけを選ぶ。対象が生存・既知位置を失うと通常の対象選択へ戻る |
| 浪漫派 | 大技分類に入る技能だけを選び、通常攻撃へ戻らない。大技分類は杖3種とロザリオ4種 |

浪漫派の大技候補は、キャラクターへの実効ダメージ・回復量（地点回復を含む）、対象数、詠唱時間、クールダウン、範囲、技能IDの順で比較する。魔石は対象数の比較に含める。大技候補が装備にない場合は、通常のステート別選択へ戻る。

未認識敵の実位置は範囲攻撃地点に使わない。認識保持中は最後の観測位置のみ（古いほど価値低下）。

## 予測ダメージ・回復

文脈に載せる pending は次の両方でよい。

1. 詠唱中のダメージ／回復
2. 同 tick で先に Prepare した味方の予約（推定ダメ／回復）

敵の予測 HP から味方 pending を引き、倒し切りや過剰攻撃を抑える。

## 対象

- 直接視認を、記憶のみより優先しやすい
- 双剣は直接視認中の、戦闘狂は直接視認または認識保持中の計画した敵対象を短時間維持する
- 便乗屋は味方リーダーの意図対象、復讐鬼は直近攻撃者を優先する
- 遠距離武器は敵座標へ突っ込まず、得意距離の射撃位置を移動側で作ることが多い

バフ／デバフ／回復の武器対応などはヒューリスティックとしてよい。スキル一覧は [戦闘スキル.md](../戦闘スキル.md)。

## 実行

Execute 時に再評価し、使えるときだけ詠唱開始する。失敗したスキルは診断ログの `SKILL` に出さない。

魔石攻撃も、敵攻撃と同じくこのスキル／攻撃経路で扱う。
