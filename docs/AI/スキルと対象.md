# スキルと対象

## 意図

目的ごとの技能カテゴリから、実行可能な技能と対象を選ぶ。
全技能を1つの点数で比較せず、目的・武器・性格の順序を保つ。

| 目的 | 優先する行動 |
|---|---|
| `EmergencyRetreat` | 保護・回復・不可視 |
| `SupportAlly` | 回復・保護・強化 |
| `DefendOwnStone` | 保護・攻撃・弱体 |
| `AttackEnemy` | 弱体・攻撃・保護 |
| `DestroyEnemyStone` | 魔石に届く攻撃・強化 |
| `Search` | 移動・不可視 |

## 対象の原則

- 直接視認を、記憶だけの情報より優先する。
- 未認識の敵の実位置は、対象・移動・範囲地点に使わない。
- 詠唱中の効果と、先にPrepareした味方の予約を予測に含める。
- 攻撃は過剰攻撃を避け、回復は倒される味方を優先する。
- 遠距離武器は敵へ突っ込まず、射撃位置を移動側で作る。

## 性格による制限

- 寂しがり: 味方と合流するまで技能を選ばない。
- 猪突猛進: 敵魔石へ届くダメージ技能を優先する。
- 便乗屋: 設定された味方の目的・対象へ同調する。
- 復讐鬼: 直近の攻撃者を優先し、情報が失われたら通常選択へ戻る。
- 影薄い: 通常対象より後回しにする。範囲攻撃・支援対象は変えない。

Execute時にも実行可能性を再確認する。失敗した技能は成功ログに出さない。

実装: `CombatAiPlanner` / `CombatAiSkillClassifier` / `CombatAiSkillContextBuilder`
