# 診断ログ

AIの判断を後から追うための開発専用ログ。ゲーム内の判断は変えない。

## 使い方

- `CombatBattleEventLogger` を戦闘シーンへ置き、`Enabled` を有効にする。
- ログは `Logs/CombatBattles/battle_*.log` に1戦1ファイルで出る。
- 本番ビルドには含めない。

## 見るイベント

- `AI_PLAN`: 目的・行動・対象・移動先の計画
- `AI_PLAN_REPEAT`: 同じ計画の継続と停滞
- `AI_EXECUTE`: 移動・技能の開始または失敗
- `OBJECTIVE`: 目的の変更理由
- `SKILL_RESULT`: 技能の成功・無効・失敗・キャンセル
- `STONE_TARGET` / `STONE_DESTROYED`: 魔石への攻撃と破壊
- `DEFEATED` / `SNAPSHOT` / `BATTLE_END` / `BATTLE_ABORTED`: 戦況と終了理由

通常攻撃の成功は、個別行ではなく `BATTLE_END` の集計にまとめる。

## 調査コマンド

```bash
rg "AI_PLAN|AI_EXECUTE|AI_PLAN_REPEAT" Logs/CombatBattles/battle_*.log
rg "BATTLE_END|BATTLE_ABORTED" Logs/CombatBattles/
rg "SKILL_RESULT outcome=(Failed|NoEffect|Cancelled)" Logs/CombatBattles/
```

実装: `CombatBattleEventLogger`、`CombatBattleLogFormatter`、`CombatAiDecisionEvents`
