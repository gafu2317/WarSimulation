# コンボ

関連: [README](README.md) · [武器](武器.md) · [性格](性格.md)

コンボは AI に専用経路を増やさない。武器と性格の偏りが重なって、観戦上の連携として見えることを目指す。

デザイナーズコンボは一人の武器と性格だけでは完結させない。強い役割を持つ一人に明確な弱点を残し、別の味方が自分の武器と性格を使ってその弱点を補うことで成立させる。参加者が倒されたり引き離されたりすればコンボも崩れるため、相手側は弱点を狙って対処できる。

## 魔石強襲

**杖（猪突猛進）+ 盾（献身的）**

魔石しか見ない杖を、盾の護衛で生存させる。

**杖（猪突猛進）+ ロザリオ（寂しがり）**

魔石しか見ない杖を、ロザリオの回復で生存させる。

## 拘束追撃

**魔導書（狡猾）+ 双剣（戦闘狂）**

魔導書が敵の薄いルートから魔石へ寄りつつ拘束し、追跡で孤立しやすい双剣がその場で倒し切れるようにする。

## 前線突破

**双剣（戦闘狂）+ 聖書（寂しがり）**

敵を追い続ける双剣へ聖書が同行し、強化と保護で攻撃を続けさせる。

**双剣（戦闘狂）+ 盾（献身的）**

敵を追い続ける双剣の近くで盾が低HP味方を支え、前線が崩れにくくする。

## 囮密集

**盾（目立ちたがり屋）+ 杖（戦闘狂）**

盾が人の多いところへ出て目立ち、杖がその密集を攻撃し続ける。

## 陽動魔石強襲

**盾（目立ちたがり屋）+ 杖（猪突猛進）**

盾がキャラ密集側へ寄って敵を引き付け、その間に杖が一直線で魔石を攻撃する。

## 傷付き護衛

**盾（献身的）+ ロザリオ（寂しがり）**

献身的な盾が低HP味方へ駆けつけるあいだ、寂しがりのロザリオが合流して回復を続ける。

## 連携に必要な共通処理（設計目標）

以下はコンボを成立させるための設計目標である。現状の専用 API としては未完のものがあり、契約の正本ではない。

| 目標 | 現状の目安 |
|---|---|
| 支援役が連携相手を短時間保持する | チーム予約・支援移動採点で近似。専用ホールドは未整備 |
| 妨害役が味方攻撃中の敵を候補に含める | スキル／対象採点のヒューリスティックに依存 |
| 目立ちたがり屋が密集へ寄る | 密集 Signature はある。敵側の対象バイアスは未実装 |
| 陽動と攻撃の不要な合流を避ける | 移動先重複の減点で近似。陽動専用ロジックは未整備 |
