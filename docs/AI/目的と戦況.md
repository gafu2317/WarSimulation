# 目的と戦況

関連: [判断の流れ](判断の流れ.md) · [移動](移動.md) · [性格](性格.md)

## 目的

目的は次の六つ。魔石破壊もその一つであり、特別枠ではない。

| 値 | 意味 |
|---|---|
| `AttackEnemy` | 敵を攻撃する |
| `DestroyEnemyStone` | 敵魔石を破壊する |
| `DefendOwnStone` | 自軍魔石を防衛する |
| `SupportAlly` | 味方を支援する |
| `Search` | 敵を索敵する |
| `Retreat` | 危険な戦闘から撤退する |

前提がそろわない目的は候補にしない（例: 敵魔石位置が無いときの破壊、攻撃対象が無いときの敵攻撃）。

## 戦況指標

おおよそ 0〜100 の指標で戦況を表す。

| 指標 | 概要 |
|---|---|
| `OwnStoneThreat` | 自軍魔石付近の既知敵 |
| `SelfThreat` | 自分の危険（HP・近接敵・射線・被詠唱・人数差） |
| `AllyFragility` | 味方の危険 |
| `ReachableEnemyValue` | 攻撃価値の高い既知敵 |
| `EnemyStoneReachability` | 敵魔石への到達しやすさ |
| `TerrainAdvantage` | 高所・森林などの有利さ |
| `EnemyLocationConfidence` | 敵位置の確信 |
| `RetreatRouteSafety` | 退却経路の安全さ |
| `SelfExposure` | 敵からの露出 |
| `EnemyThreatLevel` | 敵集団の脅威 |
| `KillableTargetValue` | 今倒せる敵の価値 |
| `WinProximity` | 敵魔石残り HP から見た勝利近さ |

敵単体脅威の武器係数の目安: 双剣 0.9、杖 0.9、魔導書 0.7、盾 0.55、聖書 0.35、ロザリオ 0.25。  
集団脅威は最大単体＋その他合計の一定割合。死亡した敵は含めない。

## 目的採点

合計は概ね次の和。

- 基本点
- 戦況点（上記指標）
- 武器重み
- 性格点

最高点の目的を採用する。

魔石破壊は、到達性・勝利近さ・前線の余裕・自分の危険など **通常の戦況点** で上がる。
「前線が安定したら火力職だけ押し込む」「誰か一人だけ強襲させる」といった専用ルールは置かない。

## 敵情報

- **直接視認**: 現在の位置・体力・状態・行動
- **認識保持・非視認**: 最後に観測した位置・体力・状態・行動と時刻。見えていない間の実変化では更新しない
- **未認識**: 実位置・実体力を目的・移動・対象・範囲攻撃の採点に使わない
- 索敵は未探索・最終既知方向・敵魔石方面などの候補で評価する
