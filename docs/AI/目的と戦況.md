# 目的と戦況

関連: [判断の流れ](判断の流れ.md) · [移動](移動.md) · [性格](性格.md)

## 目的

戦略ステートは次の六つだけ。既存の `CombatObjective` をステート名として使う。

| 値 | 意味 |
|---|---|
| `AttackEnemy` | 敵を攻撃する |
| `DestroyEnemyStone` | 敵魔石を破壊する |
| `DefendOwnStone` | 自軍魔石を防衛する |
| `SupportAlly` | 味方を支援する |
| `Search` | 敵を索敵する |
| `Retreat` | 危険な戦闘から撤退する |

高所、森林、進攻ルート、追従、遮断、回復、待機、詠唱、死亡は追加ステートにせず、六ステート内の条件・行動として扱う。

## 戦況指標

ステート優先判定に必要な三つの危険度だけを、おおよそ 0〜100 で事前計算する。

| 指標 | 概要 |
|---|---|
| `OwnStoneThreat` | 自軍魔石付近の既知敵 |
| `SelfThreat` | 自分の危険（HP・近接敵・射線・被詠唱・人数差） |
| `AllyFragility` | 味方の危険 |

敵の有無、敵魔石の生存、射程圏、高所・森林、進攻ルートなどは `Context` の事実を各ステート内で直接判定する。使わない総合指標は計算しない。

## ステート選択

`SelectState` は危機から通常行動へ向かう固定優先順で判定する。

1. 自分が危険なら `Retreat`
2. 自軍魔石への既知脅威が高ければ `DefendOwnStone`
3. 傷ついた味方や護衛対象がいれば `SupportAlly`
4. 交戦条件を満たす敵がいれば `AttackEnemy`
5. 生存中の敵魔石位置が分かれば `DestroyEnemyStone`
6. それ以外は `Search`

戦闘狂・寂しがり・猪突猛進は、性格の見える特徴を成立させる明示分岐をこの前段に持つ。武器や性格ごとの数値重みを合計して状態を決めることはしない。

攻撃職（双剣・杖）は、敵魔石位置が分かるとき **魔石破壊を基本方針** にする。
索敵や射程圏外の既知敵への切り込みより魔石前進を優先し、**自身の有効交戦射程圏内の敵**（双剣は武器射程＋余裕、杖はおおよそ 10m 以内）がいるときだけ敵攻撃へ割り込む。

支援・妨害寄り（聖書・ロザリオ・魔導書）は、支援条件も直接視認中の敵との交戦条件も成立しないとき、既知の敵魔石より `Search` を優先する。

「前線が安定したら火力職だけ押し込む」「誰か一人だけ強襲させる」といった専用割当ルールは置かない。

## 敵情報

- **直接視認**: 現在の位置・体力・状態・行動
- **認識保持・非視認**: 最後に観測した位置・体力・状態・行動と時刻。見えていない間の実変化では更新しない
- **未認識**: 実位置・実体力をステート条件・移動・対象・範囲攻撃に使わない
- 索敵は最終既知地点、高所、森林の順に利用可能な行動を選ぶ
