# 自動戦闘デバッグ

マップ候補・味方編成・敵編成・試合回数を指定し、Standalone Player を CLI から起動して連戦する。

Editor Play は使わない。低 FPS になるため。

主目的は、各試合の[診断ログ](診断ログ.md)を残してあとから AI 判断を追えるようにすること。

## 準備

1. 戦闘シーン（例: `Assets/Scenes/GafuTest.unity`）を開く
2. 空の GameObject に `CombatAutoBattleRunner` を追加する（無ければ実行時に `CombatBattleEventLogger` も追加される）
3. Inspector で次を設定する
   - マップ候補（`AuthoredMapDefinition`）
   - 味方編成 / 敵編成（武器・性格）
   - 試合数・基準シード・タイムアウト・時間倍率
4. シーンを保存する
5. Build Target を StandaloneOSX にする
6. `Tools/War Simulation/Auto Battle/Build Player` でビルドする（Development Build）

ビルド出力: `.unity/CombatAutoBattle/CombatAutoBattle.app`

## 設定 JSON

```json
{
  "MapNames": ["AuthoredMap 1"],
  "Allies": [
    { "Weapon": 1, "Personality": 0 },
    { "Weapon": 3, "Personality": 19 }
  ],
  "Enemies": [
    { "Weapon": 1, "Personality": 0 },
    { "Weapon": 1, "Personality": 1 }
  ],
  "MatchCount": 10,
  "BaseSeed": 12000,
  "TimeoutSeconds": 180,
  "TimeScale": 16
}
```

- `MapNames` はシーン上 Runner に割り当て済みのマップ名。省略時は Inspector の候補を使う
- `Weapon` / `Personality` は enum の整数値（JsonUtility）
- 編成・試合数などを省略した項目は、ビルド時の Inspector 値を使う

`WeaponKind`: Unarmed=0, Sword=1, Shield=2, Wand=3, Grimoire=4, Bible=5, Rosary=6  
`CombatAiPersonalityKind`: Neutral=0 …（`CombatAiPersonalityKind.cs` を参照）

## CLI

プロジェクトルートで実行する。

```bash
cd /path/to/WarSimulation
./.unity/CombatAutoBattle/CombatAutoBattle.app/Contents/MacOS/CombatAutoBattle \
  -screen-fullscreen 0 \
  -screen-width 1280 \
  -screen-height 720 \
  -logFile Logs/AutoBattles/player.log \
  -autoBattleConfig /absolute/path/to/run.json
```

実行ファイル名が異なる場合は `Contents/MacOS/` 内を確認する。

Editor から設定ファイルを選んで起動する場合:  
`Tools/War Simulation/Auto Battle/Build And Run With Config...`

## 結果

### 診断ログ（本体）

各試合 1 ファイル:

```text
Logs/CombatBattles/battle_yyyyMMdd_HHmmss_fff.log
```

内容・読み方は[診断ログ](診断ログ.md)と同じ（OBJECTIVE / SKILL / SNAPSHOT / DEFEATED / BATTLE_END など）。

時間切れの試合は `BATTLE_END outcome=Timeout` になる。

### ラン要約 JSON

`Logs/AutoBattles/<timestamp>.json`

試合ごとの index / seed / map / outcome / 秒数に加え、`DiagnosticLogPath` で対応する診断ログファイルを指す。
