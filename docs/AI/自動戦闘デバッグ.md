# 自動戦闘デバッグ

Standalone Playerで同じ戦闘を繰り返し、AIログと結果を比較するための手順。
勝率より先に、性格固有の「発火 → Plan → 実行 → 完了」を確認する。

## 実行口

| 用途 | 実行口 |
|---|---|
| 単一編成 | `-autoBattleConfig` |
| 編成探索 | `-autoBattleSweepConfig` |
| 分割・再開 | `Tools/AutoBattle/batch_battles.py` |

Editor Playではなく、`StandaloneOSX` のDevelopment Buildを使う。
ビルドメニューは `Tools/War Simulation/Auto Battle/Build Player`。

## 確認順

1. マップ候補・キャラプール・設定JSONを確認する。
2. 1試合のスモーク実行で `BATTLE_START` とレポートを確認する。
3. `AI_PLAN` で性格理由・行動を確認する。
4. `AI_EXECUTE` で開始可否と失敗理由を確認する。
5. 同じマップ・編成・シードで標準性格と比較する。

勝敗だけで性格の正しさを判定しない。

## 出力

- 詳細ログ: `Logs/CombatBattles/`
- 連戦レポート: `Logs/AutoBattles/`
- Player: `.unity/CombatAutoBattle/CombatAutoBattle.app/`

## 注意

`BATTLE_START` 前にPlayerが終了した場合は、AIではなく起動環境を疑う。
macOSで `-batchmode -nographics` が失敗する場合は、アプリケーションバンドルを通常起動する。

長時間実行と再開は [汎用自動戦闘バッチ](汎用自動戦闘バッチ.md) を使う。

実装: `Assets/Scripts/Combat/Debug/AutoBattle/`、`CombatAutoBattlePlayer`
