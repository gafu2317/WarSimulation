# AI進攻ルート

進攻ルートは、敵魔石へ向かう複数の道をAIへ渡すためのマップデータである。

## 正本と検証

- 編集データ: `AuthoredMapDefinition.AssaultRoutes`
- ベイク後データ: `BakedMapData` → `MapData.AssaultRoutes`
- 実行時キャッシュ: `CombatAssaultRouteCache`
- NavMeshと地形の変更はfingerprintで検出する。
- 自軍魔石・経由点・敵魔石を結ぶ経路だけを有効にする。

自動生成は `CombatStoneAssaultRoutes.BuildCandidates` を使い、手動ルートは残す。
候補がない、古い、または検証失敗のときは既存データを壊さない。

## AIでの利用

AIは現在位置をルートへ投影し、次の未通過cornerへ進む。
敵軍は逆順に使い、通過済みの地点へ戻らない。

複数ルートでは、`DestroyEnemyStone` 中の集合可能な味方数が少ないルートを優先する。
固定位置支援、別任務、`Regroup` 中の味方は集合人数に含めない。
低HPで `Regroup` を選んだ味方は、集合可能な味方が最も多いルートへ向かう。
そのルートより近い有効なロザリオがいる場合だけ、ロザリオを合流先にする。集合可能な味方がいない場合も最寄りの利用可能なルートを使い、ルートもロザリオもなければ待機する。自軍魔石へ戻るフォールバックは持たない。
ルート上の味方数は、武器種や地形ではなく、Planの移動意図とルートへの近さで決める。

実装: `CombatStoneAssaultRoutes`、`CombatAssaultRouteCache`、`CombatMapSystem`
