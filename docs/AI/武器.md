# 武器

武器は戦場での基本周期を決める。魔石破壊も通常の目的・移動・攻撃の組み合わせとして扱う。

| 武器 | 役割の意図 |
|---|---|
| 双剣 | 敵魔石へ進み、接敵した敵を近距離火力で処理する |
| 盾 | 味方や自軍魔石の前に立ち、敵の進路を遮る |
| 杖 | 敵魔石へ圧力をかけ、得意距離から攻撃する |
| 魔導書 | 高所・情報共有を使い、弱体・拘束・毒で妨害する |
| 聖書 | 高所・情報共有を使い、味方を強化・保護する |
| ロザリオ | 味方の危険度を見て回復し、後方を維持する |

## 守る判断

- 剣・杖は、敵が有効射程に入るまでは魔石前進を優先する。
- 盾は同行対象を守り、対象がいなければ自軍魔石の脅威を遮る。
- 魔導書・聖書は前線へ出ず、高所と射線を使う。
- ロザリオは回復対象がいる間、攻撃や魔石破壊より回復を優先する。
