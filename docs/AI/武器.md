# 武器

関連: [README](README.md) · [移動](移動.md) · [性格](性格.md)

武器は戦場で繰り返す基本周期を決める。目的を選ぶだけでなく、接近・実行・次の位置取りまで一つの周期として見えるようにする。

魔石破壊は周期の一部になりうるが、特別な AI 経路ではない。到達と攻撃の成立はマップ／攻撃手段側の前提とする。

## 役割一覧

- 双剣: 基本は敵魔石へ進み、有効交戦射程圏内の敵がいるときだけ交戦する前衛火力。
- 盾: 味方や自軍魔石の前へ出て、敵の接近と攻撃を遮る防衛役。
- 杖: 基本は敵魔石へ圧力をかけ、おおよそ10mの有効交戦射程圏内に敵がいるときだけ交戦する遠距離火力。
- 魔導書: 高所から索敵・情報共有しつつ、視界内の敵を弱体化・拘束・毒で妨げる妨害役。
- 聖書: 高所から索敵・情報共有しつつ、視界内の味方を能力強化・防御する支援役。
- ロザリオ: 味方の体力と生存見込みを見て回復する治療役（索敵・同行寄り）。

## 双剣

- 達成したいこと
  - 敵魔石へ圧力をかけ、有効交戦射程圏内の敵だけを処理しながら前線を押し込む。
- そのための方法
  - 敵魔石位置が分かるときは魔石破壊・前進を基本にする。
  - 射程＋少しの距離に敵がいるときだけ敵攻撃へ切り替え、その敵へ接近する。
  - 接近後はダメージスキルを使い、一度狙った敵を短時間追い続ける。
  - 軽い攻撃で倒せる敵はその場で仕留め、倒した後は再び敵魔石へ進む。
  - 遠い既知敵だけのために魔石前進を止めない。
  - 自軍魔石が攻撃されている場合は前線から戻り、敵を排除した後に再び前進する。

## 盾

- 達成したいこと
  - 敵へ攻め込む味方と一緒に進み、その味方と自軍魔石を敵の攻撃から守る。
- そのための方法
  - **剣または杖への追従を索敵より優先する。**
  - 敵または敵魔石へ向かっている味方を一人選び、その味方へ並走する。
  - 敵を未発見の間でも、戦場にいる剣／杖へ同行する。
  - 自軍魔石から敵魔石方向へ進んでいる割合が高い味方と、双剣・杖を同行対象として優先する。
  - 同行する味方の移動先を先読みし、味方と最寄りの敵の間へ移動する。
  - 敵が味方へ近づいたら進路を遮り、保護スキルを使った後も味方の前方を維持する。
  - 同行対象が後退または死亡した場合は、別の前進中の味方へ移る。
  - 敵側へ進んでいる味方がいない場合は、自軍魔石へ接近する敵の進路を遮る。
  - 自軍魔石が明確に脅かされているときは防衛を優先する。
  - 防衛対象への危険がなくなった場合は、その対象と一緒に敵側へ進む。

## 杖

- 達成したいこと
  - 基本は敵魔石へ圧力をかけ、おおよそ10mの有効交戦射程圏内に敵がいるときだけ交戦する遠距離火力。
- そのための方法
  - 敵魔石位置が分かるときは、剣と同程度に魔石破壊・前進を優先する。
  - おおよそ 10m 以内に敵がいるときだけ敵攻撃へ割り込む（武器射程いっぱいでは割り込まない）。
  - 射線が通ったらその場で攻撃し、敵が接近したら後退して得意距離を取り直す。
  - 後退後も同じ敵へ射線を通せる位置を探し、再び攻撃する。
  - 敵が密集している場合は範囲攻撃を使い、瀕死の敵には軽い攻撃を使う。
  - 通常の杖はステートの攻撃技能優先順と実行可否に従う。
  - 攻撃ステートで、現在地より見下ろせる既知敵が多い到達可能な高所があり、敵が準備済み技能の有効射程内にいない場合は、高所を先に選ぶ。
  - 安全な射撃位置がない場合は、高所や森林を経由して別の射撃位置へ移る。
  - 味方前線が敵を抑えている場合は、その後方から敵魔石を攻撃する。

## 魔導書

- 達成したいこと
  - 高所で広く見て情報を共有し、視界内の脅威を弱体化・拘束・毒で妨げる。
- そのための方法
  - 敵情報が薄いときは索敵を優先し、無理に魔石破壊へは寄せない。
  - 視界と射線が広がる高所を平地の接近より優先し、見下ろせる敵へ能力低下を配る。
  - 妨害効果が付いていない脅威の高い敵を選び、必要なら中距離まで移動する。
  - 敵の武器に合う能力低下を使い、接近職には拘束または敏捷低下を使う。
  - 妨害を付けた後は、同じ効果を重ねず別の敵または別の効果へ切り替える。
  - 体力が十分残る敵には毒を使い、瀕死の敵には即効性のある行動を選ぶ。
  - 敵に接近された場合は距離を取り直し、不可視または森林から次の妨害を行う。
  - 妨害できる敵がいない場合は、索敵や高所・森林経由で次の対象を探す。

## 聖書

- 達成したいこと
  - 高所で広く見て情報を共有し、視界内の味方を強化・保護する。
- そのための方法
  - 視界と射線が広がる高所を取り、前線の複数味方へ能力強化を届ける。
  - これから交戦する味方を選び、その少し後ろまたは見下ろせる位置まで移動する。
  - 味方の武器に合う強化を使った後、同じ効果が付いていない次の味方へ移る。
  - 敵に接近されている味方には、能力強化より無敵や防御を優先する。
  - 支援後は前線へ出ず、支援対象へ射線が通る後方・高所を維持する。
  - 前線が移動した場合は、見下ろせる位置を保ちながら一緒に移動する。
  - 支援対象が全員安定している場合は、前線の後方から攻撃または魔石破壊へ参加する。

## ロザリオ

- 達成したいこと
  - 危険な味方を回復し、倒されることを防ぐ。
- そのための方法
  - 通常時は味方集団の後方に位置し、最も危険な味方を監視する。
  - 傷ついた味方が出たら、その味方へ回復が届く位置まで移動して回復する。
  - 遠隔回復で足りない場合だけ前へ出て近距離回復を使い、回復後は後方へ戻る。
  - 複数の味方が傷ついている場合は、その中間へ回復領域を置く。
  - 敵が接近した場合は、回復対象への射線を保ちながら敵から離れる。
  - 継続回復中の味方より、まだ回復を受けていない危険な味方を優先する。
  - 味方の治療が必要な間は、敵攻撃や魔石破壊より回復を優先する。
