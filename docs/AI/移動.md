# 移動

移動は目的達成のための手段であり、専用の「高所ステート」などは作らない。

## 移動先の種類

敵魔石、進攻ルート、自軍魔石、敵、味方、遮断位置、高所、森林、最終既知地点、待機位置を目的に応じて選ぶ。

## 意図

- 目的地は到達可能性と短時間の停滞を確認して選ぶ。
- 進攻では複数ルートへソフト分散する。担当を固定しない。
- 盾は味方と脅威の間、支援職は後方・高所を優先する。
- 遠距離職は得意距離と射線を保つ。近接職は接敵を優先する。
- 索敵は最終既知地点、高所、森林を使い分ける。
- 高所好き・便乗屋・復讐鬼の位置取りは目的を増やさず、現在のPlanの移動先を上書きする。

到達不能や停滞は、その候補だけを一時的に外す。目的そのものを押し込まない。

実装: `CombatAiPlanner`、`CombatAiPlanner.MoveTargets`、`CombatAssaultRouteCache`
