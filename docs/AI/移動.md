# 移動

関連: [判断の流れ](判断の流れ.md) · [目的と戦況](目的と戦況.md)

## 移動候補

目的に対して、意味のある移動先を候補にし、経路距離と経路リスクで採点する。

| 種類 | 意味 |
|---|---|
| 敵魔石へ前進 | 敵魔石周辺の到達点へ |
| 橋経由 | 地図上の橋付近を経由して前進 |
| 自軍魔石へ戻る | 防衛・退却 |
| 敵へ接近 | 攻撃対象へ |
| 味方へ接近 | 支援・同行 |
| 進路遮断 | 味方と脅威の間 |
| 高所 | 視界・射程・射線の改善（盾以外が主） |
| 森林 | 遮蔽・距離取り |
| 最終既知地点 | 索敵 |
| 性格 Signature | 性格固有の位置（薄い例外） |
| 待機 | 目的地なし |

到達不能な候補、および短時間ブロック中の近い座標は落とす。

## 経路評価

- 経路長と、敵射程・射線に晒される度合いを見る
- 近くに援護可能な味方がいればリスクを下げる
- 味方がすでに向かっている近い地点は減点（チーム予約も参照）
- 慎重など性格はリスク係数を変えてよい

## 橋・進攻ルート

橋は前進の移動候補になる。複数橋があるマップでは、[進攻ルートとソフト分散](進攻ルートとソフト分散.md) に従い、ルート単位で味方の偏りを減点して分散する。担当ルートの固定はしない。

対岸からの遠距離射撃点は後回し。

## 高所・森林・索敵

- 高所: 既知敵への射線・射程、視界面積、索敵価値と、移動コスト・リスク・味方重複で採点
- 森林: 遮蔽と得意距離の維持。遠距離／支援は遮蔽寄り、近接は近い点を選びやすい
- 索敵: 敵位置確信が低いとき最終既知・高所・敵魔石方面が相対的に上がる

## 位置取り

武器や性格が求める立ち位置は、毎判断の移動候補生成と採点で表現する。  
専用の「必須再配置ステート」は置かない。
