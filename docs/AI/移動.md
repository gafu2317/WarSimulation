# 移動

関連: [判断の流れ](判断の流れ.md) · [性格](性格.md)

## ステート別の移動

各ステートは、自分に必要な移動だけを優先順に試す。通常は到達不能または短時間ブロック中の目的地を飛ばすが、高所好きは最初の高所到達までは候補が残る限り待機へ寄せる。

| 種類 | 意味 |
|---|---|
| 敵魔石へ前進 | 敵魔石周辺の到達点へ |
| 進攻ルート経由 | マップに保存されたルートの次cornerへ前進 |
| 自軍魔石へ戻る | 防衛・退却 |
| 敵へ接近 | 攻撃対象へ |
| 味方へ接近 | 支援・同行 |
| 進路遮断 | 味方と脅威の間 |
| 高所 | 視界・射程・射線の改善。通常は遠距離・支援武器が主だが、高所好きは全武器で選ぶ |
| 森林 | 遮蔽・距離取り |
| 最終既知地点 | 索敵 |
| PersonalitySignature | 性格固有の位置（薄い例外） |
| 待機 | 目的地なし |

`EmergencyRetreat` はHP15%以下で水平距離が近い到達可能な自軍魔石またはロザリオを一度選び、その退避先が無効になるまで維持する。自軍魔石を選んだ場合は魔石中心から18m以内で解除し、ロザリオを選んだ場合は到着後もHP50%まで維持する。`DefendOwnStone` は遮断→自軍魔石から18m以内の脅威迎撃→魔石帰還、`SupportAlly` は献身的なら低HP味方→遮断→支援位置（聖書は条件を満たす高所を先に試す）、`AttackEnemy` は杖・魔導書なら有効高所→得意距離、それ以外は敵への接近、`DestroyEnemyStone` は狡猾なら前回の有効目的地→低リスク路→空いている進攻ルート→魔石前進、`Search` は陽キャ／寂しがりの `PersonalitySignature`→最終既知地点→高所→森林を使う。

## 経路評価

- 撤退先と狡猾の進攻路では、敵射程・射線に晒される経路を避ける
- 近くに援護可能な味方がいる経路は相対的に安全とみなす
- 通常の魔石前進では、利用中の味方が最少の進攻ルートを選ぶ
- 通常の魔石前進は毎判断で現在の意図目的地を見直す。狡猾の進攻中は到達可能な前回目的地を維持し、高所好きも移動中の高所候補を維持する

## 進攻ルート

文脈の `AssaultRoutes`（キャッシュ済みの進攻ルート候補）から、ルートごとの次地点を前進候補にする。
複数ルートがあるときは [進攻ルート](進攻ルート.md) のソフト分散に従い、現在利用者が最少のルートへ分散する。ルートはマップに焼き付けられており、橋を含むかどうかはマップごとに異なる。
猪突猛進の `DestroyEnemyStone` はこの候補を使わず、川を含む通常のNavMesh経路を評価して敵魔石へ進む。

## 高所・森林・索敵

- 高所: 直接視認できる敵へ射線を通せる数が多い地点を優先し、同数なら近い地点を選ぶ。高所好きは最初の到達までこの候補をステートより優先し、到着後は射程内ならその場から技能を使い、必要なら敵や敵魔石へ移動する
- 森林: 遮蔽と得意距離の維持。遠距離／支援は遮蔽寄り、近接は近い点を選びやすい
- 索敵: 最終既知地点、高所、森林の順に利用可能な地点を使う
- 魔導書・聖書: 情報共有と能力バフ／デバフのため、他職より高所移動を強く選ぶ。通常の攻撃・支援では高所候補が到達可能で、射程内の敵・味方に有効な場合に使う

## 位置取り

武器や性格が求める立ち位置は、各ステートの行動順と対象問い合わせで表現する。高所好き・便乗屋・復讐鬼などは `BuildPlanForState` で移動対象を上書きするが、専用の「必須再配置ステート」は置かない。到達不能・短時間ブロック中は通常の移動候補を飛ばす。ただし高所好きは戦闘中の最初の高所到達まで、高所候補が残る限り待機を `PersonalitySignature` として保持する。
