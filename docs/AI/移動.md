# 移動

関連: [判断の流れ](判断の流れ.md) · [目的と戦況](目的と戦況.md)

## ステート別の移動

各ステートは、自分に必要な移動だけを優先順に試す。到達不能または短時間ブロック中の目的地は飛ばす。

| 種類 | 意味 |
|---|---|
| 敵魔石へ前進 | 敵魔石周辺の到達点へ |
| 進攻ルート経由 | マップに保存されたルートの次cornerへ前進 |
| 自軍魔石へ戻る | 防衛・退却 |
| 敵へ接近 | 攻撃対象へ |
| 味方へ接近 | 支援・同行 |
| 進路遮断 | 味方と脅威の間 |
| 高所 | 視界・射程・射線の改善（盾以外が主） |
| 森林 | 遮蔽・距離取り |
| 最終既知地点 | 索敵 |
| 性格 Signature | 性格固有の位置（薄い例外） |
| 待機 | 目的地なし |

`Retreat` は安全な森林→自軍魔石、`DefendOwnStone` は遮断→脅威迎撃→魔石帰還、`SupportAlly` は遮断→支援位置、`AttackEnemy` は有効高所または得意距離、`DestroyEnemyStone` は空いている進攻ルート、`Search` は最終既知地点→高所→森林を使う。

## 経路評価

- 撤退先と狡猾の進攻路では、敵射程・射線に晒される経路を避ける
- 近くに援護可能な味方がいる経路は相対的に安全とみなす
- 通常の魔石前進では、利用中の味方が最少の進攻ルートを選ぶ
- 担当ルートは固定せず、毎判断で現在の意図目的地を見直す

## 進攻ルート

文脈の `AssaultRoutes`（キャッシュ済みの進攻ルート候補）から、ルートごとの次地点を前進候補にする。
複数ルートがあるときは [進攻ルートとソフト分散](進攻ルートとソフト分散.md) に従い、現在利用者が最少のルートへ分散する。ルートはマップに焼き付けられており、橋を含むかどうかはマップごとに異なる。

対岸からの遠距離射撃点は後回し。

## 高所・森林・索敵

- 高所: 見下ろせる既知敵が多い地点を優先し、同数なら近い地点を選ぶ
- 森林: 遮蔽と得意距離の維持。遠距離／支援は遮蔽寄り、近接は近い点を選びやすい
- 索敵: 最終既知地点、高所、森林の順に利用可能な地点を使う
- 魔導書・聖書: 情報共有と能力バフ/デバフのため、他職より高所移動を強く選ぶ

## 位置取り

武器や性格が求める立ち位置は、各ステートの行動順と対象問い合わせで表現する。専用の「必須再配置ステート」は置かない。
