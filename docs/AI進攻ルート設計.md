# AI進攻ルート設計

## この段階の責務

マップから進攻ルート候補を作ることだけ。AIの選択・戦力配分は後段。

## いま実装していること（薄い版）

1. スタート = 自軍メイン魔石、ゴール = 敵軍メイン魔石  
2. まず直進 `start → goal` を試す  
3. 直進が通って **どの橋にも触れない** → 直進1本だけ（川なし／同じ岸）  
4. 直進が橋を使う、または直進不可 → 各橋で `開始 → 岸A → 岸B → ゴール` を列挙  
5. River/Lake area は areaMask から除外（高コストではなく不通）

対岸射程・幾何的な重複除去は後段。

## 計算タイミング

**Play 中のみ**表示する。Edit モードの Generate では線を作らず、残っていれば削除する。Play 開始後、マップ生成と NavMesh ベイク完了を待ってから描画する。

## 注意

NavMesh の「高コスト」は歩ける。長い川渡りを防ぎたいならコスト任せではなく、River 除外＋水面棄却が必要。
