# AI進攻ルート設計

## この段階の責務

マップから進攻ルート候補を作ることだけ。AIの選択・戦力配分は後段。

## いま実装していること（薄い版）

成功条件を最小化している。

1. スタート = 自軍メイン魔石  
2. ゴール = 敵軍メイン魔石（今はこれだけ）  
3. 配置済みの各橋について `開始 → 岸A → 岸B → ゴール` の完全 NavMesh 経路を作る  
4. できた橋ルートを短い順に最大3本表示する  
5. 陸上区間は水面禁止。橋区間だけ橋 footprint 内の水を許可  
6. River/Lake area は areaMask から除外（高コストではなく不通）

対岸射程・直通・幾何的な重複除去は、橋2本が安定して出るまで入れない。

## 計算タイミング

**Play 中のみ**表示する。Edit モードの Generate では線を作らず、残っていれば削除する。Play 開始後、マップ生成と NavMesh ベイク完了を待ってから描画する。

## 注意

NavMesh の「高コスト」は歩ける。長い川渡りを防ぎたいならコスト任せではなく、River 除外＋水面棄却が必要。
