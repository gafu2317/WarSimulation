## 現在の実装

- 国家HUDは人口・国庫・木材・鉱石、日付、停止／通常／2倍速、ミニマップとメニューボタンを表示する。操作と情報はセーフエリア内、上帯の背景と街は画面全体に表示する。
- 月初に収入、遠征の帰還、施設や武器の完成を報告する。施設配分と建設費を国庫・資源から精算し、工期の完了日に施設Lvを上げる。訓練は2か月で完了する。CP0からの復活時に性格を再抽選する。迎撃できる編成が組めない襲撃は敗北として終了する。
- 26名の兵士、武器の付け替え、訓練、CP0からの復活、遠征と防衛編成を国家側で管理する。遠征の到着と防衛の出撃から既存の戦闘へ移動し、結果を持ち帰る。敵は経過月に応じて能力が成長し、学校の習得表から段階的に技を解放する。成長規則と調整値は [敵の成長](UI.md#敵の成長) を参照する。鍛冶場は配分を受けた月に武器を3本製作し、確定した進行は自動保存する。
- 遠征の地図と編成は別ページとし、下の操作帯から切り替える。編成の兵士選択欄は育成と配置を揃え、一覧と詳細はそれぞれスクロールできる。政務・兵士一覧・武器一覧・防衛編成も、画面の切替や情報を戻る操作と同じ下の帯に置く。設定から資源の変更、襲撃の切り替え、戦闘画面への移動ができる。
- 保存済みの街は新モデルを表示する。新旧の比較は両方の国を生成したシーンで使う。土と草の地面、石畳の大通り、北東の学院通りに加え、東門の荷役・市場・住宅の共同庭・学院に用途別の小物を配置した。配置と検証状況は [城壁都市比較](城壁都市比較.md) にまとめる。
- 街の描画は建物・小物単位で材質別に統合し、国シーン専用の一時URPで影の負荷を抑える。統合の再生成と計測記録は [描画負荷の削減](城壁都市比較.md#描画負荷の削減2026-11-10) を参照する。

## 確認と資料

UIは既存EditorのDevice Simulatorで、`iOS Notch Device (1170×2532)` の横向き、描画2532×1170、Scale 50、Fit to Screenオフを使う。端末枠とノッチを含む確認手順は [入力と表示確認](UI.md#入力と表示確認) にまとめる。

- [モダンゲームUI調査](モダンゲームUI調査.md) に配色や、改善点を探す10の評価観点を残す。
- [UXAudit-v1](../../Artifacts/CountryUI/UXAudit-v1/verification.md) は公開版17の検査、[UXFix-v1](../../Artifacts/CountryUI/UXFix-v1/verification.md) はその後の修正記録。人の利用者テストは未実施。
- [PanelStyle-v2](../../Artifacts/CountryUI/PanelStyle-v2-reverted/verification.md) は全面却下・撤回済み。現行の部品として使わない。
- 過去の検証結果と再現手順は `Artifacts/CountryUI/` の文書に残す。画像・UI状態ダンプ・差分・退避コピーは一時出力としてGit管理しない。各記録は当時の状態を示し、動作確認と見た目の採用は別に扱う。
