# 国家画面のUI

`Country` シーンの `CountryHud` が、国家画面のUIを持つ。uGUIの保存済みPrefabを使い、画面サイズに合わせて拡縮する。

現行の見た目と共通部品はこの文書、政務の操作要件は [月初の政務UI](月初の政務UI.md) を基準にする。文書の担当、試作の状態、過去の版との区別は [国家ドキュメントの入口](README.md) を参照する。確認記録は末尾にまとめる。

[配色変更の計画](#配色変更の計画)に沿う初回の配色を2026-11-03に反映。共通部品と実行時の状態表示を揃え、同日のitch.io版17へ収録した。見た目はユーザー確認待ち。適用と公開後の確認は [ColorPass-v1](../../Artifacts/CountryUI/ColorPass-v1/verification.md) に記録する。

街は保存シーンと再生開始時に新モデルのCityV2を表示し、城と周辺の街並みへ寄せる。旧・新・両国の比較操作は維持する。2026-11-02は指摘された場所から街全体へ同じ見た目の基準を適用して改修した。用途の分かる空地、つながる歩行経路、石の実寸と目地の揃い方を全街区で確認する。共通石畳の地面と土を残す植栽床、サービス囲い・橋・桟橋・闘技場の構造、既存を含む全小物を再点検する。詳細は [城壁都市比較](城壁都市比較.md)、変更前後と検証は [CityCoherence20261102](../../Artifacts/CityCoherence20261102/verification.md) を参照する。保存後の全域検査と20街区・全40道路の画像確認を実施。見た目はユーザー確認待ち。StreetLife20261101は前段の過去記録で、追加小物の検査だけでは街全体の用途・構造・石の大きさを保証できていなかった。

## 文字の配置と余白

- ボタンやクリックできる技名の文字に下線を付けない。技名の末尾の「›」と詳細を開く操作は維持する。

2026-11-02。文字はRectTransformの端ではなく、実際に見える枠・画像の内側に収める。余白を全UIで同じ値にはしない。紙の折り目、封蝋、旗の支柱と切り欠き、看板の留め具には文字を置かず、表・一覧・見出し・操作の密度に応じて空きを決める。文字サイズを一括で下げて収めない。

- 兵士・武器の一覧行は名前と状態を二段にし、基準高さ152、名前の上24、文字の左120・右28を確保する。状態は折り返し、長いときは行を高くする。上段の丸アイコン列はこの行高を適用しない。
- 共有の兵士選択領域は外枠から左右20・上下12を空ける。詳細の本文と固定の操作欄は分け、長いスキルや説明をスクロールしても操作へ重ねない。詳細内の主操作は488 × 112とし、長い操作名のための幅を取る。
- アイコン付きの主操作・政務タブ・学校切替は、アイコンと文字を一組として面の内側へ揃える。間隔は16、左右の安全域は部品ごとに変える。通常の詳細操作は28／28、政務タブは24／24、学校は16／16、配分の指令書は32／68、訓練旗は32／48、建設看板は64／64を使う。文字数が変わってもアイコンだけを端に固定しない。
- `CountryButtonContent` は文言と幅の変化に合わせて配置を更新し、`CountryButtonFeedback` に新しい基準位置を渡す。文字生成中に位置を変更せず、押下・解除でも文字とアイコンが重なったり横へ跳ねたりしないようにする。
- 施設バナーは文字幅＋128を基準に伸ばし、文字を左88・右24より内側へ置く。建設の施設名札もアイコンが金属縁へ接しない位置へ揃える。ミニマップのNには読める高さを確保する。
- 襲撃の参加不可理由は「防衛メンバー」の帯の右端から24を空け、長い一行でも帯の縁に接しないようにする。

上記の数値は既存Canvasの基準座標であり、全ての部品に同じ内側余白を課す規則ではない。確認は [入力と表示確認](#入力と表示確認) のスマホ端末設定で行う。既に空きのある報告書・設定・確認ダイアログなどの面と形は維持する。

`WarSim > Country > Set Up Text Layout` は対象の共有Prefabだけを更新し、開いているシーンの保存・再読込は行わない。通常のPrefab生成元にも同じ配置を適用する。[TextLayout-v1の確認記録](../../Artifacts/CountryUI/TextLayout-v1/verification.md)に、実画面の目視・操作確認と見た目の採用状態を分けて記録する。見た目はユーザー確認待ち。

## 画像の縮小描画

2026-11-03。大きな原画を小さく表示する共用SpriteにはMip Mapを生成し、Trilinearで段階間を補間する。対象は `CountryButtonSpriteImporter.SamplingTextures` に列挙した10枚。政務・学校のタブ、兵士選択の面・枠・点線の丸、指令書・訓練旗・建設看板、遠征ボタン、学校と施設の共用アイコン、配分コイン、他国の拠点素材に適用する。

元のPNG、SpriteのGUID・fileID・切り出し・9-slice・表示サイズ・色は維持する。フォントSDF、紙や布の背景、3Dモデルのテクスチャは既存設定を維持する。原寸で固定表示する画像やドット絵などは用途ごとに判断し、UI画像すべてへ一律に適用する規則にはしない。

`WarSim > Country > Update Shared Texture Sampling` は対象画像のMip Mapと補間だけを更新し、Prefabの再生成や切り出し直しを行わない。通常のボタン画像生成も同じ設定を使う。Spriteの参照保持、縮小時の輪郭と共有画像のにじみ、実画面の確認は [MipMaps-v1](../../Artifacts/CountryUI/MipMaps-v1/verification.md) に記録する。実装への反映と、ユーザーによる見た目の採用は分けて扱う。

右下の遠征は224 × 208の領域に地図と旗を分けて置く。左下の4ボタンと右下の遠征は、安全域の左下・右下へ追加余白0で揃える。遠征の地図画像は縦横比を保って領域の下端に置き、画像の中央配置による下側の空きを作らない。旗と文字は別部品のままにする。CanvasScalerは幅と高さを均等に使って拡縮する。

通常ボタンの面は `#93A4B7` と濃紺文字 `#253344`、上の帯は `#526071` を基準にする。画像に描かれた外縁や金属縁の固有色は素材として保つ。灰色を主体に、わずかに紺色を混ぜた配色にする。左下の4区画は共通Prefabで面と縁を管理し、遠征は地図の輪郭を使う。

時間操作ボタンと左下の4区画の外周は角丸にする。左下は内部の継ぎ目をつなぐ。`Shapes/RoundedPanel.png` を9-sliceで使い、サイズが変わっても角の丸みを保つ。遠征にこの四角い外枠を描かない。

共有の `CountryGovernmentPlate` の縁は、画面に対して軸が揃う枠で画素単位に揃え、拡大率による四辺の太さの差を抑える。1画素程度の細い枠は元の描画を保つ。確認対象と結果は [ButtonBorders-v1](../../Artifacts/CountryUI/ButtonBorders-v1/verification.md)。

共通の押下演出を持つボタンは、有効時の色を維持し、操作できないときは灰色の面と読める操作名、抑えたアイコンで示す。暗い面と全体45％の透明度を重ねる処理は使わない。状態が戻ると元の表示へ戻す。訓練・遠征・防衛や設定などに共通し、襲撃の有効ボタンは赤を保つ。見た目は確認待ち。[ButtonAvailability-v1](../../Artifacts/CountryUI/ButtonAvailability-v1/verification.md) に確認を記録する。

ボタンの形は用途から決める。戻る・閉じる・確定などモチーフを持たない操作はシンプルな長方形にし、理由のない切り欠きや装飾を付けない。モチーフを使う操作は、何を表すか分かるデフォルメにする。今回のボタン素材には光沢・発光・光の筋を入れない。背景やパネル全体を一括で置き換えない。

月初の政務画面では、形と枠を用途ごとに使い分ける。月初の画面切り替えは下の戻る・次へを使い、各画面を直接開く場合はページ送りを表示しない。選択中の状態と、ホバー・キーボードフォーカスの強調を区別する。施設やメンバーの選択は、色以外の印でも示す。共通部品の現行仕様は下の「政務画面の共通部品」にまとめる。

国家UIのホイール感度は縦・横とも `CountryGovernmentBuilder.ScrollSensitivity` の18で統一する。一覧、詳細、施設選択、配分、育成のメンバー列に適用する。Input Systemの1目盛り分の入力6に対し108 UI座標分を移動し、一覧の行を数行まとめて飛び越えない速度にする。ドラッグ操作はこの感度を掛けず、指やポインターの移動量に追従する。解像度やGameビューのScaleでスクロールの速さを補正しない。

## 訓練・兵士一覧・武器一覧の設計

2026-10-27実装更新。今回の制作対象は次の3つ。訓練は既存の育成部分を作り直し、兵士一覧と武器一覧は新たに作る。3画面と国家側データの接続を実装済み。仮データを使い、UnityのGameビューで表示と操作を確認。見た目はユーザー確認前。

| UI | 役割 | 扱う内容 |
| --- | --- | --- |
| 訓練 | 学校への配属を決め、開始済みの訓練を確認する | 学校レベル・定員、配属前の兵士選択、2職の習得対象、2か月の期間と進捗。開始後は変更・キャンセル不可 |
| 兵士一覧 | ネームド26名の現在の状態を確認する | 名前、職業、装備、ステータス、CP、訓練・復活待ち、習得済みと使用可能なスキル。兵士ごとの詳細と装備変更へつなぐ |
| 武器一覧 | 一品ものの武器を確認し、装備先を扱う | 武器名、6種類の分類、その品固有の能力補正、現在の装備者、装備変更 |

兵士一覧と訓練は同じ26名のデータを参照する。武器一覧と兵士詳細は同じ装備品・装備者の情報を参照し、画面ごとのコピーを持たせない。ゲームルールと仮の習得テーブルは [兵士と訓練](兵士と訓練.md) を基準にする。

ゲーム画面には、数値・画像・効果の開発段階を説明する注釈を表示しない。この規則は全画面と詳細ダイアログに適用する。

### 一覧と詳細の共通構造

以下はユーザーが指定したレイアウト。兵士一覧と武器一覧は同じ左右分割構造にする。

- 左はアイコンと名前を組にした1列の行を縦に並べ、上下にスクロールできる一覧とする。複数列のカードやグリッドにはしない。
- 一覧の行を選ぶと、右にその1人・1品の詳細を表示する。一覧をスクロールしても右の詳細の位置を動かさない。
- 兵士の右側は、選択中の1人の立ち絵と、ステータス・スキル・CP・装備・訓練や復活の状態を表示する。立ち絵の枠は幅1：高さ2とし、表示領域に収まる大きさで比率を保つ。画像自体も引き伸ばさない。
- 武器の右側は、選択中の1品の個別画像と、武器種・固有の能力補正・現在の装備者などを表示する。「一品もの」のラベルは付けない。個別画像を登録するまでは画像欄を空欄にし、カテゴリ画像・シルエット・注記で埋めない。
- 左の行には名前とアイコンを中心に置き、詳細な数値は右に集約する。小アイコンは円形の背景とマスクを共用し、外縁に共通の画像を重ねる。行の面・選択枠・立ち絵枠も [兵士選択の共用画像](#兵士選択の共用画像) を使う。右の立ち絵と武器画像は縦横比を保つ。
- 左右分割の枠、一覧行、選択表現を共用し、兵士と武器で表示内容を差し替える。右の詳細も同じ対象を複数人分並べない。
- ステータスは項目名と合計値だけを表示し、基礎・訓練・装備の細かな内訳は表示しない。CP・最大HP、STR・INT、FAI・AGIの2列×3段へまとめ、文字の大きさを保って縦幅を減らす。CPは現在値／上限、ほかは既存の戦闘データと同じ項目の合計値を表示する。国家側は現在HPを保持していないため、最大HPを現在HPとして表示しない。数値の計算は変更しない。武器の能力補正も同じコンパクトな部品を使い、CPを表示しない。

### 習得済みスキルの武器別表示

- 習得済みの技を、戦闘UIと共用する武器種アイコン・技名と簡単な効果説明の１行で表示する。同じ武器種では最初の技だけに武器アイコンを表示する。長い説明は横にドラッグして全文を読める。
- 装備中の武器種の技を先頭に並べ、技名を黄色系で表示する。武器種は `SkillDefinition.RequiredWeaponKind` を使い、装備の変更に合わせて並びを更新する。
- 武器一覧では習得済みの技を表示しない。兵士一覧、育成、遠征・防衛の兵士詳細では同じ部品を使う。

### 訓練の上段と兵士選択

訓練画面も下側は「左に兵士の1列一覧、右に選択中の1人の立ち絵と詳細」を使い、その上に訓練へ入れる兵士のアイコンを1行で並べる。上段は左右にスクロール可能とする。この列は兵士を表し、学校を切り替えるアイコン列ではない。

上段は丸い人物アイコンだけとし、兵士名・状態・武器名や長方形のカード面は表示しない。選択中は円形の金色の縁で示す。開始・完了日と進捗は選んだ兵士の詳細で確認する。遠征と同じ部品を使うが、アイコン下の武器名は遠征・防衛で表示する。

操作は以下のように実装。開始前の選択と訓練中のデータを分ける。

- 左の行を押す操作は、右に表示する兵士の選択とする。押しただけで訓練への登録・解除が行われる形にはしない。
- 詳細から訓練対象へ加えると、上段の兵士アイコン列へ反映する。上段のアイコンを押しても、その兵士の詳細を確認できる。左の一覧には緑色の「選択中」を表示し、選んだ兵士を一覧の上へまとめる。詳細表示中を示す金色の枠とは区別する。学校を切り替えると、その学校の選択状態に切り替わる。
- 上段には学校の定員分の枠を常に示す。兵士が入っていない枠は点線の丸とし、空き枠数は定員から訓練中と開始前の人数を引いて求める。追加で丸が埋まり、開始前の選択を外すと点線の丸が戻る。空き枠は操作ボタンにしない。
- 開始前の選択案は、定員内で対象を調整できる。開始済みの訓練は閲覧と進捗確認を行い、途中変更・キャンセル・停止の操作を出さない。
- 学校ごとの定員と選択人数、開始後の完了予定・進捗を、兵士のアイコンや詳細と対応付けて表示する。学校の選択操作は、この兵士アイコン列と区別する。

訓練・遠征・防衛の兵士選択一覧は、選択済み、未選択で参加可能、未選択で参加不可の順に並べる。 兵士アイコンを上段へドラッグして追加し、上段の選択中アイコンを一覧へドラッグして解除できる。ドラッグ中はアイコンが指やマウスに追従し、各画面の参加条件はボタン操作と同じ。追加・解除ボタンは兵士詳細の上側に置き、遠征・防衛の武器変更は装備表示の横に置く。各グループ内では元の兵士順を保ち、選択解除や学校切替に追従する。選択済みの状態文字は共通の緑 `CountryGovernmentTheme.Positive` とし、後から参加不可になった場合も理由を併記する。行全体の透明度を落とさず、名前と理由の読みやすさを保つ。行は詳細を開けるままにし、編成済みの兵士が後から参加不可になっても先頭の選択グループに残して解除できる。訓練は定員と他校の選択案を含めて判定し、遠征は遠征先に応じた帰還日も判定する。通常の兵士一覧と武器一覧は並べ替えない。見た目は確認待ち。以前の選択不可のみを後ろへ送る確認は [MemberSelection-v1](../../Artifacts/CountryUI/MemberSelection-v1/verification.md) に残す。

### 兵士ボタンからの導線

既存HUDの「兵士」から兵士一覧を開き、上部の「武器一覧へ」から武器一覧に移動する。武器一覧からは「兵士一覧へ」で戻れる。上部には画面名、兵士一覧・武器一覧の切り替え、防衛編成への入口を置く。帯の背景は画面の左右端まで広げ、文字とボタンはセーフエリアに収める。帯と一覧パネルの間隔は配分・建設画面に揃える。下部に帯は置かず、政務画面と同じ角丸・黒枠の「戻る」を左下に置く。

武器一覧の見出しには「合計26点」のように所持品の総数を表示する。値は `CountryRosterData.Weapons.Length` を参照し、未装備品も含める。兵士一覧の見出しには人数を表示しない。

政務画面の上の帯は背景を画面の左右端まで広げ、文字や操作は安全域内に置く。帯には、日付・画面名・国庫と、配分の集計とスイッチ、建設の種別切り替え、または育成の学校選択と武器種を各画面に応じて横に並べる。資源の項目名と数値は間隔を詰めた上下二段とし、配分額などの数値の横にコイン、国庫の数値の横に袋のアイコンを置く。国庫使用のラベルとスイッチは近づける。学校・建設の選択は面の色で示し、下線を付けない。配分・建設画面は帯と施設パネルの間に同じ余白を設け、建設画面では施設名の見出しをパネル内に収める。政務画面の下部は帯の背景を置かず、戻る・次へ・完了のボタンを内容の端から離して配置する。月初の最初の報告画面には戻るボタンを表示しない。戻るは明るい青灰色、次へ・完了は青緑色とし、角丸の面に濃い文字と太い黒枠を付け、押下時は枠も面と一緒に動かす。左右のボタンは安全域内で同じ高さと端からの余白に揃える。月初は報告・配分・建設・育成を順にページ送りし、国画面のボタンから開くと該当画面と「戻る」だけを表示し、翌月の予定を編集する。月初の画面ではその予定を再編集でき、最後の「完了」で訓練を開始する。配分・建設は計画の保存までで、実際の資源支出や完成は未接続。既存の「育成」からは訓練部分を開く。兵士詳細は立ち絵の横に名前とステータスを置き、装備名の横に「装備を変更」を置く。押すと、遠征・防衛と同じ角丸のポップアップに武器一覧を表示する。武器一覧から装備先の兵士を選ぶ逆向きの操作も同様にポップアップで行い、閉じるボタン・枠外・Escで元の一覧に戻る。装備品・変更前後・他の装備者を確認して付け替える。一品が別の兵士へ移ると、元の装備者から外れる。装備を選んでいる間は5項目の合計値を「変更前→変更後」で表示し、上の補足に使用可能な技の変化を示す。確認本文にも合計値と技の比較、元の装備者への影響を残す。細かな能力内訳は表示しない。選択中の兵士と武器、各一覧のスクロール位置を保持し、国へ戻る際はカメラ入力とフォーカスを復元する。兵士一覧の今回のレイアウトと操作はユーザー確認待ち。

登録されていない技は画面へ表示せず、習得済みの実スキルと同じ扱いにしない。ステータスは合計値をコンパクトに表示する。数値や画像についての開発用注釈は付けない。

予算・育成・建設は [適用する月](月初の政務UI.md#適用する月) を見出し・決定ボタン・フッター・詳細画面に明記する。2日以降の育成は「訓練を開始」ではなく「来月の訓練を予約」と表示し、実際の開始日と完了日を示す。兵士の一覧・詳細も訓練予約と訓練中を区別する。

## 上の帯と時間操作

上の帯の背景は画面の横幅いっぱいに描く。内側の文字・アイコン・操作ボタンは安全域内に置き、背景と同じ幅へ引き伸ばさない。左から「アルトリア王国」「日付・時間モード」「人口」「国庫」「木材」「鉱石」「設定」を1列に並べる。4資源は同じPrefabを使い、左にアイコン、右に名称と数値を上下に揃える。細い縦線で区切り、情報ごとの背景パネルは付けない。

日付と時間操作は既存の `DateManager` に接続する。時間操作は背景のない記号ひとつとし、押すたびに「停止→通常進行→2倍速→停止」と切り替える。アイコンは次の操作ではなく現在のモードを示す。停止は赤い縦棒2本の一時停止記号、通常進行は緑の右向き三角1個、2倍速は濃い緑の右向き三角2個。ボタン内に文字を置かない。背景・外枠は描かず、小さめの記号だけを帯へ直接表示する。通常と2倍速は形の数でも区別する。

月末ボタンと専用の時間進行ポップアップはHUDから撤去する。通常進行・2倍速とも翌月1日に停止し、既存の報告画面を自動表示する。襲撃や他画面を開く処理による停止も赤い停止マークへ反映する。内部時計の初期日付、速度、停止・再開、日次通知は [時間進行](時間進行.md) を基準にする。UI側に表示専用の日付や別の時間ループを持たせない。過去の日めくり・ゲージの記録は現行UIの採用状態と区別する。

人口・国庫・木材・鉱石の4欄は、既存の基準幅236で同じ固定幅とする。欄自体の伸縮を無効にし、空き幅は各欄の後ろの描画しない余白へ均等に渡す。文字欄の幅も一定になり、数値が1桁・複数桁・上限表記へ変わっても他の資源や設定の位置を変えない。生成元は `CountryTextLayoutBuilder` と `CountryResourceBuilder.BuildLayout`。設定と確認は [FixedResources-v1](../../Artifacts/CountryUI/FixedResources-v1/verification.md)。

人口・国庫・木材・鉱石は `CountryResourceHud` が `PlayDataManager` の実データから表示し、人口の変更・月末の入金・既存の支出で更新する。国庫欄は月収の税収ではなく `PlayDataManager.Treasury` の残高を表示する。資源の初期値、税収と国庫の意味、入金の規則は [資源と収入](資源と収入.md) を基準にする。設定は歯車アイコンのみのボタンとし、資源を直接変更する設定画面を開く。

資源の数値表示は `CountryResourceDisplay.Format` を共用し、99,999を超えたら半角の `99999+` とする。99,999以下は従来の桁区切り、税収の小数は1桁表示を維持する。HUD・政務の国庫・報告の受取額と所持数・配分・建設の金額へ適用する。内部の資源量、収入、費用、％と可否の計算は実値を使う。設定の数値入力欄は編集のため実値を表示する。

帯の文字は指定の日本語フォントと専用共有マテリアル `Materials/NotoSansJP-Regular SDF - Country HUD.mat` を使う。標準ウェイトに揃え、縁取りと影を外す。国名・日付・資源名・操作名は36、資源の数値は38の固定サイズにする。資源名は少し暗い灰青、数値と国名は明るい灰白色にして、太字だけに頼らず区別する。小さい横画面で自動縮小しない。

帯の操作は共通ボタンのVariantを共有する。時間モードは背景・外枠を非表示にし、入力範囲を幅112・高さ112へ縮める。日付欄は幅160、日付・時間操作のグループは幅280で固定する。日付は右寄せにし、1桁・2桁で文字幅が変わっても記号や資源欄・設定の位置を動かさない。日付欄と入力範囲の間隔は8。各記号の見える左端を入力範囲の約16の位置へ揃え、日付のすぐ右へ表示する。短い日付も同じ欄へ収め、末尾の「日」と記号の間隔を揃える。停止は縦棒2本の既存画像を72四方、通常の三角も72四方、2倍速は64四方の画像を2個使い、中心間隔34で少し重ねる。輪郭の重なりは7で、2532×1170では約8.4pxとなる。画像の透明な余白を含む寸法で、記号の見える位置で合わせる。2532×1170では停止記号の高さが約59px、入力範囲は約134×134px（基準端末の460dpiで約7.4mm四方）となる。

記号と見えない入力領域を分け、記号の押し込み・縮小・ホバーの反応を保つ。背景のフェードや色変更は行わない。帯に直接表示する色は、停止 `#FF6B6B`、通常 `#C2E4C8`、2倍速 `#6FC78E`。通常より2倍速の緑を濃くする。停止は、淡い赤より鮮明な赤にする指定を優先し、縦棒2本の形でも他のモードと区別する。3状態と日付への隣接配置の確認は [TimeModes-v4](../../Artifacts/CountryUI/TimeModes-v4/verification.md)。大きい背景付きのv1は却下され、現行表示へは使わない。見た目はユーザー確認待ち。

資源アイコンは `Assets/Images/Icons/Country/` の `budget-v1`（国庫）、`population-v1`（人口）、`wood-v1`（木材）、`ore-v1`（鉱石）。設定は同じ場所の `Controls/` の歯車画像。時間の三角は `Controls/play-v1` を着色して共用し、2倍速は2個並べる。停止は同じ場所の `Controls/pause-v1` の縦棒2本の画像を赤く着色する。

## 設定と資源の変更

設定画面の「月末に飛ばす」は設定画面を閉じ、日付を１日ずつ進める。襲撃などで途中停止しなければ翌月１日で停止し、月初の報告を表示する。

Web版は `Country` を入口にする。設定画面の下部に「戦闘へ移動」を置き、既存の `GafuTest` の編成画面へ移動する。資源入力と襲撃スイッチの変更はその場で反映する。戦闘側の編成画面には「国家へ戻る」を置く。戦闘中・結果画面からは既存の編成画面へ戻る操作を経由する。両ボタンは既存部品・指定フォントと対応マテリアルを使い、新しい開発用の注釈は表示しない。見た目はユーザー確認待ち。

シーンは非同期で切り替え、移動中の連打で二重に読み込まない。資源・日付・兵士・装備・訓練・遠征・防衛・襲撃のON／OFFと、予算・建設の操作案を起動中は保持する。戦闘中と帰還後は国家時計を停止し、戦闘音と戦闘の時間倍率を帰還先へ持ち越さない。戦闘結果・編成・消費・報酬は国家へ反映しない。カメラ位置・開いている画面・未確定の訓練候補は復元しない。ビルドと配布は [Webプレイテスト](../Webプレイテスト.md) を参照する。

歯車ボタンから `CountrySettings.prefab` の設定画面を開く。人口・国庫・木材・鉱石を既存の資源アイコンと数値入力欄で2列×2段に並べる。税収は従来どおり人口から計算し、「税収は人口に応じて変わる」と示す。共有する布地・金属縁と通常の決定・キャンセル用ボタンを使い、個別の完成画面画像は作らない。基準サイズは1160 × 900。安全域の高さに収めるため行間を調整し、数値入力の高さ112、入力文字44、下部ボタンの高さ112は維持する。エラー行とフッターは重ねない。新しい文字も指定のNoto Sans JPと対応マテリアルを使う。

開いた時点の実データを読み、各資源欄の有効な整数は入力するたびに即時反映する。空欄・負数・範囲外は反映せず、入力を終えたときに最後の有効な値へ戻す。閉じる・×・枠外・Escでは反映済みの変更を維持する。入力は0〜2,147,483,647の整数とし、入力欄はTMP_InputFieldを使い、タッチ端末では数値キーボードを使う。

表示中は国の時間を停止し、カメラ・国の比較ショートカット・背後のUIへの入力を止める。閉じると元のカメラ・比較入力と選択フォーカスを復元する。時計は停止状態のままとする。設定を開く際は政務・兵士一覧・施設ポップアップを閉じる。

`WarSim > Country > Set Up Resource Settings` は共有PrefabとHUDの参照を更新し、開いているシーンは保存・再読込しない。実データへの反映は接続済み。アプリ終了後の保存・復元は既存の未接続の範囲を維持する。資源・月収・入金記録の扱いは [資源と収入](資源と収入.md#設定からの直接変更) を基準にする。

襲撃のON／OFFを同じ設定画面に置く。「襲撃を発生させる」をOFFにすると即時反映され、日付が進んでも新しい襲撃は発生しない。閉じる・Escでも変更を維持する。再びONにした日から次の襲撃間隔を数え、OFF期間の襲撃をまとめて発生させない。アプリ終了後の保存は未接続。

## 月初報告

報告書の「現在の合計量」は3行とも数値だけに揃え、税収行の残高にも「国庫」の接頭辞を付けない。表示する値は実際の国庫残高とする。

2026-10-28実装。月替わりに開く報告の内容領域を、右上の角を折った一枚の報告書として表示する。紙面は `Assets/Images/UI/Country/ReportPaper-v1.png` の無記入の紙素材と `CountryReportPaper` の輪郭で構成し、画像へ文章・数値・罫線を焼き込まない。紙面の上部に「報告書」と前月分の受取状態を並べ、続いて資源の収入を「項目・受取額・現在の合計量」の3列、税収・木材・鉱石の3行で示す。各項目には既存の資源アイコンを表示する。合計量は税収行に現在の国庫残高、木材と鉱石の行に現在の所持数を表示する。国庫残高は予定国庫ではなく実際の残高であり、資源の変化に応じて更新する。受取額は月初に受け取った額を維持する。次に遠征の帰還一覧を置き、見出しと罫線で書類の読み順を示す。数値・文字には暗いインク色、補助情報には灰色、見出しには落ち着いた茶色を使う。拠点の画像は既存のものを使う。

帰還行は紙面上に区切り線と濃い文字を使う `CountryExpeditionReportRow.prefab` を使用し、ホバー・選択時は入力可能な範囲を示す。領地名・帰還日・人数・獲得結果を表示する。行全体を押すと既存の詳細を開き、行が多い場合は縦にスクロールする。上の報告・配分・建設・育成タブと国へ戻る操作は共通のまま。収入の受取処理、帰還記録、月初以外の政務画面は変更しない。操作と実データの範囲は [月初の政務UI](月初の政務UI.md#遠征の帰還報告) を参照する。

## 入力と表示確認

シーンの `CountryEventSystem` はInput System用のUI入力を使う。帯と通常ボタンの面がポインターを受け、装飾の縁・文字は入力を遮らない。遠征は地図と旗の両方から同じButtonへ入力を渡し、透明な余白は `CountryButtonShape` で除外する。読み取り可能なSpriteのアルファを使い、折り地図の縦横比と旗の位置に追従する。

約6.1インチ級のスマホを基準にし、既存EditorのDevice Simulatorを次の設定で使う。2026-11-05の指定により、確認時はScaleを50にして拡大する。`WarSim > Country > Use Phone Simulator` で再設定できる。

- 端末：組込の `iOS Notch Device (1170x2532)`。460dpiの汎用ノッチ付き端末で、iPhone 13専用の定義ではない。
- 向き・実描画：端末の回転270度、描画方向はAutoRotationで端末へ追従させ、LandscapeLeftの2532×1170px、約19.5:9にする。回転と描画方向を逆向きに固定しない。ノッチとセーフエリアも端末定義を使う。
- 表示倍率：Simulator上部のScaleを50、Fit to Screenオフ。25に戻さず、端末プレビューを拡大して文字・入力範囲・余白を見る。
- 入力：Simulatorはマウス操作をタッチとして扱うため、ホイール入力はゲームへ届かない。スクロールはドラッグや画面内のスクロールバーで確認する。
- Fit to Screenは端末プレビュー全体をウィンドウへ収めるための表示倍率調整であり、UIを安全域へ配置する機能とは分ける。安全域の枠表示で部品の位置を確認する。
- 提示画像と分離プレビューも2532×1170を使う。ブラウザーを確認する場合もCanvasの実描画寸法と表示寸法を分けて記録する。844×390やHDの補助確認を加えない。
- CanvasScalerの基準解像度1920×1080とゲーム内の寸法は維持する。Simulatorの表示倍率とゲーム内のUI倍率を混同しない。
- 必ず端末枠を含むSimulator表示も目視する。ノッチ・丸い四隅・ホームインジケーターとの重なりと、正しい向きで描画されていることを確認する。描画テクスチャだけの画像では、この確認を済ませたことにしない。

設定・ネイティブ描画の確認は [MobileNative-v1](../../Artifacts/CountryUI/MobileNative-v1/verification.md)。この切替より前の844×390は比率確認用の縮小描画であり、ネイティブ解像度・端末形状の確認結果として扱わない。Simulatorの設定確認、再生中の入力確認、実機検証、見た目のユーザー採用は分けて記録する。

### 端末の安全域

スマホ向けの部品は制作開始時から安全域を基準にする。文字・アイコンの絵に加え、タップ範囲も内側へ収める。端末の安全域と部品内の文字余白は分けて確保する。

`CountryHud` の `CountrySafeArea` が `Screen.safeArea` に追従する。左右下のメニュー、ミニマップ、施設表示と通知は安全域へ配置する。政務・兵士・遠征・防衛の画面背景と、設定などの暗幕は画面全体を覆い、内容・操作・確認カードは安全域に置く。上帯の背景は横幅を保ち、`TopBar/Content` の横方向だけを安全域へ合わせる。固定サイズのボタンや文字は縮めない。下メニューの外側余白は0、その他の部品内の余白は維持する。街のカメラと描画領域は画面全体を使う。

`CountrySafeArea` はUnityの `Device.Screen.safeArea` と描画サイズからアンカーを更新する。背景は全画面、操作部品は安全域へ置くため、対象と基準アンカーは `CountryHud` Prefabに明示している。画面名による実行時の探索はしない。初期化時は描画領域全体を仮の配置基準としてアンカーを復元し、画面情報が描画サイズと一致したら安全域を適用する。端末に応じたアンカーは `DrivenRectTransformTracker` で管理し、コンポーネントの無効化時には基準へ戻す。Prefab編集と分離プレビューには自動適用せず、分離検証では安全域を指定する。

画面や階層を変更するときは `CountrySafeArea` の対象を同時に更新する。`WarSim > Country > Update Safe Area Target List` は共有HUD Prefabの対象一覧だけを更新し、開いているシーンを保存・再読込しない。

Editor内部の `ReadScreenPixel` 系APIはネイティブクラッシュを起こしたため使用しない。端末枠を含む画面は起動済みEditorを外部から取得する。RenderTextureから取得するゲーム画像は、端末枠を含む確認とは分ける。

下のメニュー5つは同じ書式を共有し、文字のはみ出しがなく、文字上の入力が該当ボタンに届く。2532×1170での文字サイズは左下が約43px、遠征が約81px。読みやすさはSimulatorのScale 50で確認する。時計を変更した場合は、通常進行・停止・月末の各日の通知・月替わり・年末・Esc・無効化と再有効化・入力遮断も確認する。`WarSim > Country > Set Up Time Controls` で共通Prefabとシーン参照を設定する。

## ミニマップ

左上のミニマップはセーフエリアの左端に揃え、帯の下には32の余白を置く。幅を左下の4ボタンと揃え、実際の国の縦横比をAspectRatioFitterで維持する。横長の枠へ引き伸ばさない。外枠と背景を灰紺色にし、道・建物・城壁・川を簡略化した地図を表示する。見出しは設けず、その分だけ外枠の下を詰める。地図の大きさと上端位置は維持する。城は淡い金色、北は右上のNと矢印で示す。

地図は `Assets/Data/CountryComparison/town_plan.json` の実際の配置から作る。`Minimap/CountryLayout.asset` のメッシュを使い、追加の撮影カメラやRenderTextureは使わない。`WarSim > Country > Set Up Minimap` で配置を再生成し、HUDとCountryシーンに接続する。街の再構築でも地図メッシュを更新し、土の広場、草地、石畳、砂利道を描き分ける。大通りは明るい色で示す。学院通りと学校の並びも同じ配置表から描き、施設バナーの対象を新しい建物へ結び直す。

水色の枠と薄い塗りは、メインカメラの四隅から地面へ投影した範囲を示す。中央の丸印は画面中央の注視点。移動・ホイール・ピンチ・画面の縦横比に追従し、地図外にはみ出す部分を切り取る。時間停止中も更新する。比較する国を切り替えた場合は国の原点も合わせる。ミニマップ上からの操作で背後の街を動かさない。

新しい文字も指定の日本語フォントと帯の共有マテリアルを使う。現行のスマホ端末設定で表示、移動・拡縮・国の切替・時間停止中の追従、範囲メッシュとカメラの一致を確認する。

## 施設バナー

役割のある15施設に、屋根や敷地の上へ追従するクリック可能なバナーを付ける。職業施設は戦士学校・魔法学校・教会、性格施設は図書館・広場・酒場・天文台・闘技場・美術館・診療所・カジノ・衛兵所・歓楽街、精霊施設は精霊使役学校、武器製作施設は鍛冶場。各種類で同じバナーPrefabを使う。歓楽街は4棟の区画をまとめ、広場は北側の `Plaza` を使う。礼拝堂や工房付き住宅は対象に含めない。

バナーは施設固有の56 × 56のアイコンと名前を並べる。文字は指定フォントの標準ウェイト36、灰紺の面と分類ごとの細い色帯を使う。幅は文字の自然な幅＋96とし、入力高さ112を保つ。画面上の文字サイズを距離で縮小せず、カメラの移動・拡縮・国の表示切替に追従する。画面外・非表示の国・固定HUDに重なるバナーを隠し、近いバナーの入力範囲が重なる場合は上へずらして建物との接続線を表示する。2532×1170では入力範囲の高さ約134px、文字は約43pxにする。

バナーを押すと共通ポップアップに同じ施設アイコンを96 × 96で置き、施設名・分類・役割を表示する。役割の説明は確認済みの施設仕様を使い、未指定の個別効果や数値は追加しない。閉じる・右上の×・枠外・Escで閉じる。表示中はカメラと比較用ショートカットの入力を止め、閉じたら元の入力状態と選択フォーカスを戻す。

`WarSim > Country > Set Up Facility Banners` で共通Prefabと配置参照を作る。比較シーンの旧・新2か国に同じ15施設を対応させ、モデルの描画範囲からアンカーを設定する。

編成は訓練と同じ `CountryRosterSelection.prefab` を使う。上の操作・対象表示、その下の人数表示、円形アイコンと点線の空き枠の横スクロール列、下側の左の兵士一覧／右の1人分の詳細という順に揃える。上段は兵士名とカード面を置かず、遠征・防衛編成では各アイコン下に固有の武器名を表示する。実際の装備にも追従し、アイコンを押すとその兵士の詳細へ切り替わる。遠征の空き枠は最大26人から選択人数を引いた数。遠征の兵士詳細は名前を立ち絵の右側のステータス欄の上に置き、武器種と待機状態はそこに表示せず、1：2の立ち絵の横に余分な空きを設けず、ステータス欄を広く取る。兵士のステータスは１段目にCPと最大HP、２段目にSTR・INT・FAI・AGIを並べる。武器変更の一覧では、変更対象の兵士が装備中の武器名を黄色で示す。武器変更は兵士詳細からポップアップを開き、既存の武器一覧と詳細を角丸のパネルに表示し、画面上端に余白を設ける。閉じるボタンかパネル外のタップで元の編成画面に戻る。武器の変更は編成への参加と無関係に即時実装備へ反映し、他の兵士が持つ武器を選ぶとその兵士から移る。編成の解除や画面を閉じても装備は戻らない。遠征中の兵士と持ち出し中の武器は変更できない。出発時には実装備を再確認する。立ち絵1：2、内訳なしの能力表示、戦闘と共通の武器カテゴリ画像、個別画像がない武器欄の空欄を維持する。

旧版の地形画像 `Terrain-TopDown-v1.png` と、全16領地へ城を並べた表示は撤回済み。旧画像の原本・過去の確認記録は残すが、現在の地図の参照元や採用済み素材として使わない。

出発確定後は国画面へ戻り、5秒間、行き先・到着日・帰還日を表示する。遠征ボタンの上には進行中の部隊数を継続して表示し、すべて帰還すると消す。出発後も時計は停止したまま。帰還報告の結果文字は明るい青灰の行に合わせて濃紺の文字色を使い、紙用の緑を重ねない。設定の歯車も明るい面に対して濃紺とする。

### 遠征の進行

- 1隊1〜26人。別の兵士・武器・目的地なら複数隊を同時に出せる。自領に辺で接する敵領地が対象で、遠征中の目的地への重複出発を拒否する。
- 首都と対象拠点の地図上距離を、初期地図の最短10日・最長30日へ線形換算して整数に丸める。所有者変更で移動速度を変えない。帰りも同じ日数で、往復20〜60日。
- 状態は往路→帰路→帰還。今回は到着日に戦闘をスキップし、勝利として領地を獲得して即日帰路へ入る。参加者全員のCPを到着日に20ずつ、1回だけ消費する。0未満にはしない。既存戦闘・追加の資源消費・報酬・人口増加・途中撤退は接続しない。
- CP0・訓練中・遠征中の兵士を拒否する。訓練予約は、帰還予定日が開始日以前なら維持して遠征へ参加できる。同日なら帰還を先に処理する。
- 遠征中の兵士は再出撃・訓練への新規登録・装備変更を行えない。持ち出した武器も他の兵士へ移せない。帰還日に解放し、装備自体は維持する。
- 出発確定前に隣接・目的地の予約・全メンバー・訓練日・武器の重複と持出状態を再検証する。1人でも不正なら装備も部隊も変更しない。
- 「遠征中 N隊」から一覧を開き、行き先・人数・往路／帰路・帰還日と参加者を閲覧できる。帰還した部隊はここから除き、[月初報告](月初の政務UI.md#遠征の帰還報告)へ記録する。

国の日付と `CountryCycleSystem` で進め、遠征画面に別の時計を作らない。開閉で領土・確定した遠征・帰還記録を失わない。アプリ終了後の保存は未接続。

遠征画面は戻る・出発を安全域の下端に配置し、スクロール内容はその背後と安全域外まで表示する。戻るには木の看板、出発には旗の既存素材を使う。出発できない理由はボタンの近くに表示する。見た目はユーザー確認待ち。

遠征の兵士・武器一覧は内側で縦スクロールせず、一覧全体がページの縦スクロールに続く。選択済みメンバーの横スクロールは維持する。

`WarSim > Country > Set Up Expedition Page` は既存の遠征Prefabに縦スクロール、寸法を保つセクション、固定情報と入れ子の入力振り分けを設定する。`Set Up Expeditions` の通常生成元にも同じ設定を接続する。開いているシーンの保存・再読込は行わない。現行ページの動作とスマホ横画面の確認は [ExpeditionPage-v1](../../Artifacts/CountryUI/ExpeditionPage-v1/verification.md)、見た目はユーザー確認待ち。以前のタブ切替の画像は過去記録とする。

`WarSim > Country > Set Up Expeditions` は保存済みの地図を使って遠征Prefab、訓練と編成の共通選択欄、月初の報告領域、HUD内の接続、使用画像の切り出しを更新する。`Update Expedition Map` は初期地図を現在の25領地と海岸線で再作成し、Prefabも更新する。どちらもPlay中には実行しない。Editorの起動・再起動や開いているシーンの保存・再読込は行わない。地図と移動の確認記録は [Expeditions-v4](../../Artifacts/CountryUI/Expeditions-v4/verification.md)、遠征先パネルの確認は [ExpeditionDetails-v1](../../Artifacts/CountryUI/ExpeditionDetails-v1/verification.md) にまとめ、見た目はユーザー確認待ちとする。

## 防衛編成と襲撃

2026-10-28実装。兵士ボタンから開く一覧の上部に「防衛編成」を追加する。訓練・遠征と同じ `CountryRosterSelection.prefab` と兵士・武器・丸アイコン・点線枠の画像を共用する。最大26人を選び、各兵士に一品の武器を指定して登録する。兵士だけ・武器なし・同じ兵士や武器の重複は登録できない。空の編成で登録すると全解除する。通常は「登録する」で保存し、国へ戻る・Escでは未登録の編集案を破棄する。武器変更は編成の登録とは独立して即時実装備に反映し、画面を閉じても元には戻らない。登録済み兵士の装備も現在の実装備を参照する。

登録は兵士と武器の予約・拘束ではない。登録後に遠征・訓練・CP0になっても登録内容を残し、襲撃時に再検証する。参加できない兵士や遠征へ持ち出した武器があれば編成を変更する。訓練予約中で開始前なら防衛に参加できる。

通常進行・月末進行のどちらでも20〜30日ごとに現在の自領から対象を選んで襲撃を発生させ、時計を停止する。月初報告と重ならないよう1日の襲撃は2日へ送る。未対応の襲撃を重ねて生成しない。襲撃ポップアップは緊急指令の用紙として表示する。無記入の紙素材 `Assets/Images/UI/Country/RaidDispatchPaper-v1.png` に、赤い「緊急指令」の見出しと襲撃先、日付、防衛メンバー、対応ボタンを重ねる。文章と数値は画像に焼き込まず実データを表示する。対応ボタンは紙面の内側に並べ、通常・選択中の縁と迎撃ボタンの影に赤茶系を使う。防衛メンバーは共通の丸い兵士アイコンと名前を表示し、いないときは点線の丸を1つ表示し、その横に「メンバー未設定」と示す。襲撃の文章、見出し、アイコン列の間にはそれぞれ余白を設け、見出し文字の左端をアイコンの左端に揃える。人数が多い場合は横スクロールできる。戦闘を省略する間の暫定CP消費量は画面に表示しない。「防衛編成を変更」「防衛する」を置き、空編成や参加できない編成では防衛を無効にする。見送り操作は設けない。

襲撃中は完成した兵士と武器の組合せへの変更を自動登録し、以後の防衛戦にも使う。未完成の編成では出撃できない。防衛確認では参加者・武器と、他の兵士から移す武器を示す。戦闘はスキップして成功とし、参加者全員からCP20を一度だけ消費する。結果画面から国へ戻っても時間は停止したまま。防衛するまでは襲撃を未対応のまま保持する。損失や追加報酬は今回追加しない。

表示中は背後のUI・街カメラ・国比較への入力を遮り、結果を閉じると元の入力状態へ戻す。襲撃画面のEscは編成からポップアップへ戻し、未対応の襲撃自体は閉じない。防衛編成・襲撃待ち・ON／OFFは `PlayDataManager.Defense` と設定値で保持し、画面開閉では失わない。アプリ終了後の保存は未接続。

`CountryWorldMap.asset` の `BattleCPCost`（20）、`RaidMinDays`（20）、`RaidMaxDays`（30）は調整可能な初期値。正式な難易度調整の合意を意味しない。`WarSim > Country > Set Up Defense` で共有PrefabとHUD参照を更新する。Editorの起動・再起動や開いているシーンの保存・再読込は行わない。見た目はユーザー確認待ち。現行の指令画面は [RaidDispatch-v7](../../Artifacts/CountryUI/RaidDispatch-v7/verification.md)、防衛編成と動作の確認は [Defense-v1](../../Artifacts/CountryUI/Defense-v1/verification.md) に記録する。盾と警報旗の本体案は [Defense-v2](../../Artifacts/CountryUI/Defense-v2/verification.md) で却下・撤回済み。

### 適用順と担当箇所

1. 育成を最初の適用対象にする。同じ画面でタブ、詳細対象、参加者、主操作、補足、操作不可を比較する。着手時に既存の表示と各状態を保存し、共通テーマ、画像の地の色、Tint、無効時の透明度を照合する。
2. `CountryGovernmentTheme` に面と文字の組み合わせ、選択、増加、不足、フォーカスの役割を集約する。既存のBuilderと実行時表示から使い、画面ごとの色コードの追加を抑える。明るい面と濃い面の操作状態は分ける。
3. `CountryRosterRow`、`CountryRosterView`、`CountryRosterSelection` とタブの共有部品へ適用し、育成・兵士・武器・遠征・防衛で同じ対象が同じ見え方になるようにする。PNGへ焼き込まれた色を持つ `GameTab-v1.png` や `RosterParts-v1.png` は合成後の色を確認し、形・分解・9-slice・Sprite参照・Mip Map設定を保つ。
4. 配分・建設・報告へ展開する。金の使い過ぎ、灰色の補足、紙面の文字、スライダーの配色を担当する既存Builderで整理する。指令書・旗・看板・報告書の素材を他の面へ一括適用しない。
5. HUD・時間・設定・施設・遠征地図と襲撃へ展開する。押下・ホバー・無効・焦点の共通処理を揃え、緑／赤の意味と国の色を混同しないことを確認する。
6. 2サイズで実画面と操作を確認する。実装した項目はこの文書の担当節へ現行値として反映し、この計画の進捗と入口を更新する。動作確認、見た目のユーザー確認、Web公開への反映を別々に記録する。

画像の色調整が必要な場合も、まず既存の面・文字・枠を分けた設定で合わせる。単一のTintで全ての材質・文字・アイコンを揃えようとしない。画像自体を変更する場合は必要な共用素材だけを対象にし、形や透明領域の変更を配色作業へ混ぜない。

### 確認基準

- 通常、選択、選択＋フォーカス、ホバー、押下、操作不可で、操作名と理由を読める。通常サイズの重要文字は最終表示で4.5:1以上、操作不可の操作名は3:1以上を目安にする。原画の模様や透明度がある場合は文字の背後で最も弱い箇所を測る。[Xboxのコントラスト指針](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/102)
- 選択中の対象、押すと確定する操作、参加者に加えた状態を、色以外の輪郭・位置・印・文字でも区別できる。白黒と代表的な色覚シミュレーションでも、進行／停止、不足、地図の国と選択を見分けられる。[Xboxの色と追加手掛かりの指針](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/103)
- [入力と表示確認](#入力と表示確認) の約6.1インチ級のスマホ横画面だけで確認する。プレビューの拡大倍率だけで読めると判断しない。スクロール、学校／タブ切替、メンバーの追加解除、確認ダイアログの再表示後も状態色を維持する。選択中の金とフォーカスの輪郭は同時に確認する。
- コード上の基準色の確認と、画像・Tintを合成した実画面の確認を分ける。色調整で文字の余白・画像の輪郭・押下演出・タッチの入力範囲を壊していないことも見る。
- 初回の配色を共用Prefabと生成元、各画面の更新処理へ反映。`WarSim > Country > Apply Planned Palette` で共用Prefabと既存HUDへ再適用する。既存Editorを使用し、開いているシーンの保存・再読込は行わない。Web公開とユーザーによる見た目の採用は別に記録する。

初回反映では通常／選択、押下、操作不可、参加者追加、確認画面の表示と戻る操作を実画面で確認した。基準色の比率と画像上の背景色の確認は行ったが、全画素の最弱点の計測、白黒・色覚シミュレーションは未実施。上記の確認基準すべてを達成した記録とはしない。元画像の生成り色でタブが暗くなる箇所はTintを補正し、布地上の補足文字を明るくした。施設の選択印はクリップで半分欠けないよう4 UI座標分だけ内側へ移した。
