# 新旧2種類のモデルの城壁都市比較

`Assets/Scenes/Country.unity` に、旧モデル・新モデルの国を並べる。`CountryTest` を土台にし、国家システムの参照を残した比較用の外観シーン。

2セットとも141モデルを持つが、全129種類を街に置く要件は廃止し、実際の用途に必要なモデルを選ぶ。学校は各系統のLv5のみを配置し、Lv1〜4は配置しない。保存シーンのPrefab参照から、採用したモデルの種類と新旧の配置数の対応を検証する。道路部品の見本、不要な壁角や石階段を種類の充足のために置かない。元の新旧資産は保持する。

初期表示は新モデルのCityV2とし、旧モデルは比較操作で表示する。各国は同じ街区図、敷地、入口の向き、カメラ、光、背景地形を使う。建物は縦横比を保って敷地に収めるため、元モデルの寸法によって見え方は異なる。川は市場と公共施設の間を東西に横切り、両端が城壁の水門を通って外へ続く。建物、小物、植栽、道路は城壁内に収める。

### 小物の配置と増設（2026-11-10）

前段の配置表は72種700点で、物干し105、木箱90、ベンチ81、樽77、植木鉢54が407点を占めていた。住宅に薪置き・物干し・菜園を順に割り当てており、物干し1本だけの場所も多かった。

用途別の配置で、まず小物を958点に増やした。街灯は6本から29本、道標は1本から11本、掲示板は1枚から3枚。物干しは26本にまとめ、南西の共同庭に井戸・洗い桶・バケツ・物干しを揃えた。

井戸と休憩場所を見直した現在は、`town_plan.json` と保存済みの `Country` の新モデルに900点を配置している。北西・北東・東の住宅街に井戸を1基ずつ増やし、計5基とした。新しい井戸の脇にバケツを置き、水を汲む人が立つ側を空けた。ベンチは庭の縁、木のそば、待合に絞って26脚とし、美術館東側の5脚は木の近くの1脚にまとめた。訓練人形は戦士学校の稽古場の3体を使う。数は配置表の `props` を集計したもので、建物に組み込まれた備品や庭の苗を別に数える。

小物を置く前に「誰が何をする場所か」「道のどちらから来るか」「どちら側に立つか」を決める。道から用途が見える所に一つ目印を置き、材料・道具・保管物は作業順にひとまとまりにする。正面の入口軸、道幅、荷を持って立つ場所、買う人や座る人の足元は先に空ける。施設前は左右で役割を分け、住宅は干す・薪を取る・庭を手入れする場所を路地単位で選ぶ。土や草を使う庭は範囲をまとめ、単独の木は周囲と同じ地面に植える。

## 比較操作

Unityで `Country` を開いてPlayする。Game画面を選んで操作する。新旧の比較は両方の国が配置されたシーンで使う。保存済みの新モデル1国のシーンでは、比較操作で新モデルの表示とカメラ位置を保つ。

| 操作 | 動作 |
| --- | --- |
| 1 | 旧モデルの国の全景 |
| 2 | 新モデルの国の全景 |
| 3 | 二つの国を同時に表示 |
| Tab | 相対位置・角度・画角を保ち、旧→新の順に切り替える |
| WASD / 矢印キー | 見下ろし角度と高さを保って、画面の向きに沿って移動 |
| Shift＋移動キー | 高速移動 |
| 右ドラッグ / 中ドラッグ | つかんだ地面がポインターに付いてくる平行移動 |
| ホイール | 注視点と角度を保って拡大・縮小。近距離・遠距離の上限あり |
| 1本指ドラッグ | 指でつかんだ地面を平行移動 |
| 2本指ドラッグ / ピンチ | 指の中点を基準に平行移動・拡大縮小 |

ホイールはInput Systemの`UniformAcrossAllPlatforms`設定に合わせ、1目盛り＝1の入力をそのまま`Zoom`へ渡す。旧入力用の120除算は行わない。感度0.15では1目盛りの拡大で注視点までの距離が約14％短くなる。トラックパッドの小数入力は丸めず、分割した入力も合計量が同じなら同じ距離になる。ピンチは指の間隔の比率に追従し、地面の注視点と近距離・遠距離の上限を保つ。

保存シーンと再生開始時は、新モデルのCityV2の城と周辺の街並みを大きく表示する。比較用に保存した表示が残っていても、再生開始時に一度だけ初期表示へ戻す。その後の移動・拡縮・比較切替は維持する。`ShowInitialView` は新モデル（index 1）を選び、城付近の注視点（国の中心軸上、Z方向へ130、高さ6）から距離130に寄せる。注視点は配置表の城の位置から保存する。3キーで2国を同時に表示し、1・2キーで各国の全景へ戻す。カメラは `CountryCameraController` を使い、既存の自由カメラはこのシーンでは無効にする。Game画面にフォーカスがある間だけ操作を受ける。UI上からのドラッグとホイールでは街を動かさず、文字入力中は移動キーを止める。UIに触れたタッチ操作はすべての指を離すまでカメラに渡さず、指の増減時は移動基準を取り直す。時間停止中もカメラを動かせる。`WarSim > Country > Set Up Camera Controls` で既存Countryシーンへ設定・保存でき、都市の再構築時にも同じ操作を適用する。

編集時は `WarSim > Country > View Old Country / View New Country / View Both Countries` でも切り替えられる。
