# 素材・描画タッチの比較試作

比較画像に使った教会周辺の画面から、素材セットを大きく変えた8案。画像生成によるコンセプト試作。
生成方法: 内蔵 image_gen。全プロンプトと生成元は manifest.json に収録。
A〜Dは元の形を基本に素材を変更。E〜Hは屋根・軒・窓・石・梁の形も一部調整。

index.html を開くと旧・新モデルとの比較表示と8案の一覧を使える。

## 追加の6方向

- I 赤煉瓦の商業都市: 白い目地を効かせた赤煉瓦、黒い鉄部、濃いスレート屋根。端正でにぎやかな商業国。
- J 粗石と苔の古都: 大小の粗石、古びた木目、継ぎ目に限定した苔。遺跡にしすぎず歴史を感じる街。
- K 竜鱗瓦と黒木: 大きな鱗模様の釉薬瓦、煤色の木部、白灰色の石壁。ファンタジー固有の素材感。
- L フレスコ壁画の王都: 淡い彩色漆喰、平面に描いた紋様、落ち着いた瓦。役割施設だけに象徴的な壁画。
- M 羊皮紙と銅版画: 生成り色の壁、細い彫線、褐色の屋根。古い冒険地図が立体になったような質感。
- N 金箔と紺漆の王国: 濃紺の艶消し屋根、象牙色の壁、控えめな金の縁取り。王城と職業施設の格が際立つ街。

妾の第一候補は E「太筆の冒険RPG」。剣と魔法らしさと、遠目での読みやすさを両立しやすい。
さらに画風の差を広げるなら C「墨線」か D「ガッシュ」。Gは国ごとの素材文化を変える案に合う。
