# Country 新旧マップのちらつき調査

2026-10-23 / Unity 6000.4.3f1 / URP 17.4.0 / Metal / Country.unity

## 確認できた原因

別の模様・UVを持つ面がほぼ同一の高さで重なる、Z-fighting（深度の競合）が発生している。

| 対象 | 配置上の問題 | 証拠と状態 |
|---|---|---|
| 新旧の南門内側 | Paved_Plot の上面と South gate avenue が両方 y=0.025。高さ差は約2〜6×10⁻⁹m。 | 片方の舗装だけを一時非表示にした単一変数実験で、視点移動時の大きな画素変動が減少。確認済み。 |
| 新旧の東門内側 | Paved_Plot と Merchants gate road が同じく y=0.025。 | 三角形の投影交差とUV差を確認。東門単独の視点移動実験は未実施。 |
| 新モデルの北側道路部品 | Road_Cross / Road_Straight / Road_T / Road_Corner / Road_End の Earth 下地上面がほぼ y=0、Town earth も y=0。 | Road_Cross の Earth サブメッシュだけを一時除外すると地面の矩形模様が安定。残り4部品も同じ高さ関係だが個別実験は未実施。 |

## 3mmの視点移動による比較

カメラを右へ0.003mだけ動かし、同じ投影領域でRGBいずれかの変化量が16または32を超える画素を数えた。テクスチャの通常の移動や輪郭の変化も含むため、数値全体をちらつきだけの量とは扱わない。同じ介入前後の相対差を見る。

| 対象 | 指標 | 現状 | 重複面を一時除外 |
|---|---|---:|---:|
| 旧・南門 | 変化量 >32 | 1,055 | 246 |
| 新・南門 | 変化量 >32 | 1,027 | 267 |
| 新・北側交差点 | 変化量 >16 | 19,147 | 1,324 |

旧側の道路部品には Earth サブメッシュがなく、同じ除外操作で画像差分も同値だった。対照条件として記録した。

## 関連候補・未確定事項

- 地面と街の外の草原は4mm差、広場と道路も4mm差。幾何的には近接するが、これらすべてを今回の症状の原因と断定していない。
- 新モデルの水車には独自の Water 面（y≈0.207095）が残り、本流（y≈0.21）との間隔は約2.9mm。両面は不透明・深度書き込みあり。本流が通常は上を覆うため、近接だけで原因とは断定しない。既存の Water 面だけを一時除外した撮影記録は残したが、本流の時間変化を固定していないので画像差からの判定は保留。
- 一部のモデル内に完全一致する三角形を検出したが、検出した組はすべて法線が逆向き。内部の接触面や裏表の面を含むので、重複数をそのまま見える不具合の数にしていない。
- 旧王城のBaseColorは Point / mipmapなし（材質パレット用の意図された取り込み設定）。遠距離の画素のちらつき候補だが、今回の地面のZ-fightingとは別。設定変更による確認は未実施。
- 全6060 MeshRenderer / 1533共有Meshを点検。材質スロット過多によるサブメッシュの追加描画は0件。全共有Meshからデータを読めた。

## 修正の方向

1. 門の舗装部品と道路が同じ面を描かないよう、覆われる道路領域を切り抜く、または舗装を一枚にまとめる。129種類すべてを使う比較条件があるため、舗装モデルの単純削除を最終修正にはしない。
2. 新道路部品の土の下地を、共通の地面と重ねて描かない。比較シーン用の表示Meshで下地だけを外す等、元モデルを保持する方法を優先する。
3. 他の近接面は個別の表示実験で必要性を確認する。画角や全材質の設定を一括変更して症状だけを隠さない。

## 保存状態と再現資料

今回の依頼は調査。比較撮影では一時的なカメラ、Rendererの一時非表示、複製Meshの一時差し替えだけを使い、すべてfinallyで復元した。Country.unity、既存コード、シェーダーの基準ハッシュは一致。調査前後ともシーンは未変更状態。調査用EditorスクリプトはAssetsから除去し、このフォルダに再現資料として保存した。

- surface_audit.json: 共有Mesh・材質・水平面の読み取り結果
- ground_overlap_analysis.json: 水平三角形どうしの交差面積・高さ差・材質/UV差
- capture_experiments.json: 一時除外した対象と投影領域
- pixel_comparison.json: 微小視点移動の画素比較
- CountrySurfaceProbe.cs: 調査・一時除外撮影の再現コード（Assets外、非コンパイル）
- analyze_country_surfaces.py: 地面の重なり解析。surface_audit.jsonを入力に再実行できる
- *_Baseline_[AB].png / *_OneSurface_[AB].png: Unityから撮った原寸画像
