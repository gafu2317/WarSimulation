# 資源表示の上限

2026-11-05。表示規則の管理元は [国家UI](../../../docs/Country/UI.md#上の帯と時間操作) と [資源と収入](../../../docs/Country/資源と収入.md#初期値と表示)。資源の書式を共通処理へ集約し、HUD・政務・報告・配分・建設の資源量と金額へ適用した。生成元と既存の大きな残高の検証処理も更新した。設定の数値入力欄と内部データのコードは変更していない。

## 確認

- 既存Unity Editorでコンパイルし、共通書式の境界8件と表示・内部値4件を確認。[結果](validation.json)。0、8,500、99,998、99,999、99,999.1、100,000、int.MaxValue、税収855.5を確認した。
- 実Prefabと実際の更新処理を分離プレビューで実行した。HUD・報告・配分を1280×720と844×390で描画し、6枚とも文字のはみ出し検出は0件。HUD・報告・配分の画像で `99999+` を目視確認した。[HDのHUD](HUD-1280x720.png)・[小画面の報告](Report-844x390.png)・[小画面の配分](Budget-844x390.png)。
- 人口123,456,789、国庫2,345,678、木材3,456,789、鉱石4,567,890から月収を加算し、内部の国庫14,691,356、木材5,925,924、鉱石5,802,457を確認。各画面を開き直しても値を変えず、同じ月の二重入金も発生しない。
- 最初の検証用コードには親Canvasの用意不足があり、分離プレビュー内で修正後に再実行した。ゲームのPrefabやシーンへCanvasを追加してはいない。再実行用の [検証コード](preview.cs.txt) を保存した。
- 最終のConsole照会には既知のNoto SDFインポーター不整合が1件残った。共通書式と更新後のUIコードはコンパイル・実行できた。このフォントの問題を今回解消したとは扱わない。
- 開いているCountryのパス・未保存状態・ルートオブジェクトIDは開始時と同じ。[最終Editor状態](editor-after.json)。保存済みシーン全18ファイル、PlayDataManager、設定のコードも変更していない。[ファイル比較](file-check.json)。Editorの起動・再起動、開いているシーンの保存・再読込、Playモード開始は行っていない。

分離プレビューは実ゲームの通し操作やWebGLでの確認とは区別する。itch.ioはこの変更では更新していない。公開版への収録と見た目のユーザー確認は別に残す。
