# 街マップのホイール拡縮

2026-11-05。ユーザーが感度の低い操作を「マウスホイール」と回答。現在のInput System設定は `UniformAcrossAllPlatforms` で、1目盛りの入力は1。CountryCameraControllerがこの値をさらに120で割っていたため、距離変化が1目盛りあたり約0.125％しかなかった。余分な除算を外し、感度0.15をそのまま使う。拡大1目盛りで距離は約86.07％（約14％短縮）となる。現行の操作仕様は [城壁都市比較](../../../docs/Country/城壁都市比較.md)。

既存Editorでコンパイルし、Consoleエラー0件を確認。カメラのNUnitテストメソッド12件を、新しいfixtureのSetUp・TearDownと分離プレビューへ移したカメラで直接呼び、全件成功した。[結果](tests.json)。Unity Test Runnerのジョブや、物理ホイール・実機タッチの通し操作とは区別する。テストの描画領域と指の座標はスマホ横画面844×390へ揃えた。
