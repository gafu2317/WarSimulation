# スマホ程度の大きさでの確認環境

後続の端末枠を含む表示で、回転方向の不一致と安全域を考慮していない配置が判明した。この記録のゲーム描画画像は、正しい向き・ノッチ回避の確認結果として扱わない。修正と現在の確認範囲は [SafeArea-v1](../SafeArea-v1/verification.md) を参照する。

2026-11-05。ユーザーの指定に従い、従来の844×390から約6.1インチ級の端末設定へ切り替えた。現行の確認ルールは [国家UI](../../../docs/Country/UI.md#入力と表示確認) に集約する。この記録は環境設定と今回確認した範囲であり、全画面の操作検査・見た目の採用記録ではない。

## 設定

| 項目 | 設定・取得結果 |
| --- | --- |
| 既存Editor | Unity 6000.4.3f1、WarSimulation |
| Simulator | 組込 `iOS Notch Device (1170x2532)`。専用機種の完全再現ではない |
| 向き | LandscapeLeft、表示回転90度 |
| 実描画・取得テクスチャ | 2532×1170px、約19.5:9 |
| 端末定義の密度 | 460dpi。対角は約6.1インチ |
| 表示倍率 | 25％、Fit to Screenオフ |
| Editor内の表示範囲 | 端末枠込み665.5×325ポイント、画面部分は約633×292.5ポイント |
| シミュレーション上のセーフエリア | x141、y63、幅2250、高さ1107 |
| Build Target | WebGLを維持 |

25％はスマホ程度の見かけの大きさを見るための固定倍率であり、モニターの物理寸法を校正した実寸保証ではない。描画解像度を25％へ落とす設定ではない。CanvasScalerの基準解像度1920×1080、既存のUI寸法は変更していない。

## 反映と確認

- 元のGameタブを既存Editor内のSimulatorへ切り替え、端末・横向き・倍率を設定した。設定値と実描画寸法は [simulator-settings.json](simulator-settings.json) に記録した。
- `WarSim > Country > Use Phone Simulator` で同じ設定を呼び戻せる。既存Simulatorを再利用し、端末一覧の順序に依存せず1170×2532の定義を選ぶ。
- 政務プレビューの端末設定と、解像度が固定されていた分離プレビューを共通の2532×1170へ揃えた。出力はこの記録の配下へ移し、以前の確認画像やchecks.jsonを上書きしない。今回、他の分離プレビュー一括検査は実行していない。
- [現在のCountry描画](Simulator-Country-2532x1170.png) をSimulatorの2532×1170テクスチャから取得し、目視した。画像は端末枠・ノッチの重ね合わせを含まない。Metalの読み戻し時の上下方向を補正している。
- 分離シーンで [停止](TimeModes/Stopped-2532x1170.png)・[通常](TimeModes/Running-2532x1170.png)・[2倍速](TimeModes/DoubleSpeed-2532x1170.png) を取得して目視した。[layout.json](TimeModes/layout.json) の入力範囲は約133.87px四方、上帯の文字はOverflowなし。これらは時間経過や実機タッチの再検査ではない。
- 新規スクリプトの取り込み・コンパイル後のConsoleエラーは0件。Editorは再生停止中のまま。開いているCountryはdirty=false、保存済み18シーンのSHA-256は変更前後で一致した。
- Unity Editorの起動・再起動、開いているシーンの保存・再読込、ビルド・itch.ioの更新は行っていない。

## 残る確認との区別

Simulatorの端末設定とネイティブ描画は確認済み。今回は再生を開始せず、ノッチに対する全UIの安全域、各画面の一連の入力、実機タッチ・性能、見た目のユーザー採用は確認していない。今後の確認はこの端末とスマホ程度の見かけの大きさを基準にし、HD・844×390の補助確認を追加しない。
