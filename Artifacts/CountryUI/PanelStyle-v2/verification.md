# 建設右側の共通装飾パネル

**状態：全面却下・撤回済み（2026-10-25）。以下は撤回前の検証履歴であり、採用済みの仕様や美術見本ではない。** ユーザーの意図にない右側限定と、見本から外れた質感・外形を含め、実装全体が却下された。追加前へ戻し、コードとPrefabは `rejected-implementation/` へ退避した。復帰確認は `../PanelStyle-v2-reverted/verification.md` を参照する。

2026-10-25、WarSimulationの既存Editor（Unity 6000.4.3f1）とCountryシーンで確認した。現行仕様は `docs/Country/UI.md`、この文書はこの版の確認記録。

## 適用範囲

建設画面右側の本体・見出しの名札・効果欄の3か所だけに適用した。`installation.json` に、帯・下の操作欄・収入・配分・育成の保存前後の設定比較を記録した。5領域は全て一致した。国のカメラやゲームルールは変更していない。

## 使い回し

- `Assets/Prefabs/Country/UI/CountryPanelChrome.prefab` を3か所で参照する。同じPrefabの背景色・面取り・縁・図面表示の設定を変えて使う。
- PrefabのGUID `fc21acf7a927d40c8a9ae354ce6c1901` を参照する入れ子のPrefabインスタンスが、政務Prefab内に3個存在することを確認した。
- 既存の `Assets/Models/Kingdom/CityV3/Textures/Linen_BaseColor.png` を共用する。共有Prefab内の布画像の参照は1件。UI用の新しい完成画像は作っていない。
- 背景色と布目は別の層。布目は64/255の不透明度、基準128で繰り返す。パネルの幅・高さで模様そのものを引き伸ばさない。
- 縁と角飾りは `CountryPanelFrame`、薄い図面は `CountryPanelBlueprint` が描く。文字と数値と資源アイコンは既存のUIを使う。
- 効果欄のButtonは `Backing` を押下・ホバー対象にする。布目はその子なので、面が沈む時も追従する。装飾は全てraycastTarget=false。

## 表示と操作

| 確認 | 結果 |
| --- | --- |
| 建設・1280×720 | 文字の領域外表示0件、完全表示の主要入力領域44px未満0件 |
| 建設・844×390 | 同上。別の縦横比でも同じPrefabを使用 |
| 長い施設名「精霊使役学校」 | 名札内に収まり、費用・効果も切り替わる |
| 新築と強化 | 両方で同じ装飾を使い、内容とボタン表示が切り替わる |
| 効果欄の詳細 | 新しい背景の上から開ける。閉じると元の画面へ戻る |
| 効果欄の押下 | 保持中に面が暗くなり、上端が通常-3から-6へ沈む |
| 収入・配分・育成 | 既存の見た目を維持。文字の領域外表示0件、完全表示の主要入力領域44px未満0件 |

実画面は各PNG、文字と入力領域は同名JSONに保存した。`Pressed-1280x720` は効果欄の保持中、`Long-name-1280x720` は長い名称、`New-construction-1280x720` は新築側の記録。操作結果は `interaction-actions.json`。

布目の密度512の比較画像は調整途中の記録。最終は背景色と布目を分けた基準128・不透明度64/255であり、現行見本は `Construction-1280x720.png` と `Construction-844x390.png`。

## 実装の確認と限界

Unityでコンパイルし、設定メニューから保存したPrefabを再生して確認した。新しいC#例外とコンパイルエラーは確認されなかった。Consoleには従来からのMetalのmemoryless load/storeメッセージ2件が残る。ゲームルールの変更はなく、今回は見た目とUI操作を検証した。

実機タッチとプレイヤービルドは確認していない。図面は再利用する装飾であり、正式な施設配置を定義するものではない。
