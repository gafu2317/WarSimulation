# 国家運営HTMLプロトタイプ

`index.html` をブラウザで開く。ローカル配信する場合は、このディレクトリで `python3 -m http.server 8766 --bind 127.0.0.1` を実行する。

## 画面と操作

- 城下町：全画面の王国に重なる建物の旗から詳細を開き、強化を計画する。
- 施設整備：ゲームウィンドウの施設台帳でレベル、仮の育成枠、工事進捗を比較する。
- 国家運営：下部の「予算を決める」から開き、強化数・費用・決定後の残高を確認する。
- 国家記録：投資、工事完了、月初の収入と最新の月次報告を確認する。
- 設定・保存：ブラウザ内への保存・読込、初期化を行う。

施設詳細、計画の決定確認、月次報告、設定、初期化確認はポップアップ。Esc、閉じるボタン、背景クリックで閉じられる。自動進行中に開いたポップアップは時間を一時停止し、閉じると再開する。画面遷移はURLのハッシュを使い、ブラウザの戻る・進むにも対応する。

UI方針と実ゲームの調査結果は `../../docs/Country/ゲームUI設計.md` を参照。城下町の街並みを全画面の背景に使う。高さ96pxの全幅HUDを左から「王国名」「日付と時間操作」「国庫」「設定」の順に置く。資源ごとの計画数・工事数は常時帯から外し、資源群は右側、歯車は一番右に置く。進行案内のパネルは置かず、建物の旗、下部のゲーム内コマンド、時間操作から施設選択・命令決定・日付進行を行う。資源群では小さな印と資源名、月収を左に、残高を大きく右に置く。主要ラベルは14px以上を基準にし、HUDは暗い連続面に細い金色の境界を使い、個別のカードには分けない。施設旗は対応する建物付近に置く。紹介用の見出し、スローガン、サイトのナビゲーション、施設紹介カードは使わない。

キーボードの1〜4で命令画面を切り替え、Escで城下町へ戻る。実行中はSpaceで時間を停止・再開する。

## 仮ルール

初期資源は資金1,000、木材600、鉱石360。全施設Lv.1、領土1領で開始する。

月初に計画を決め、資源を一度支払う。資源不足の場合は決定できない。施設強化をしない月も進められる。

強化費用は目標レベル×資金100・木材50・鉱石30、工期は5日。同施設は予約順、別施設は並行で進む。育成枠はレベル×5人/月という仮表示で、実際の兵士育成は未実装。

1ループは「施設を選ぶ → 費用を確認して命令を決める → 工事を進める → 月次報告を受け取る → 次月の施設を選ぶ」。城下町に常設の進行パネルは置かない。施設選択は建物の旗から、命令決定は下部の国家運営コマンドから、日送り・工事・月次報告は時間操作から行う。

計画中は日付の下に「予算未決定」と表示し、下部の国家運営ボタンを「予算を決める」に変えて次の操作を示す。予算確定後は時間を停止する。日付横の「▶ 進行」で自動進行を開始でき、1日送り、工事完了または月次報告までの進行も選べる。自動進行は任意で開始し、2秒で1日。月初には資金100・木材50・鉱石30を加算し、工事完了を報告して次の施設選択へ戻る。年も保持し、閏年は扱わない。

## 前デザインへの復帰

全幅HUDは `css/top-band-v8.css` で設計する。旧デザインはGit履歴から対応するソースを取り出し、配信用ファイルを再生成する。`rollback/` の退避コピーはGit管理しない。

操作ごとにlocalStorageへ自動保存する。手動保存は独立した1枠へ保存し、その後の自動保存では上書きしない。手動保存を読み込むと、その時点の資源・日付・工事・計画へ戻る。再読込時は日付進行を停止する。Unityのセーブデータとは連携しない。初期化はこのプロトタイプの自動保存を初期状態に戻し、手動保存を削除する。

## 配信ファイル

ソースは `index.html`、`css/`、`js/`、`assets/`。このディレクトリで `node build.mjs` を実行すると `dist/` に配信用ファイルを配置する。`dist/` はGit管理せず、必要なときに再生成する。HTMLの直接表示には生成処理も依存パッケージも不要。
