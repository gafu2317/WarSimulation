# 政務画面の形と選択表示の修正

2026-10-25。既存のCountryシーンとuGUI部品を修正した。

| 用途 | 形と状態 |
| --- | --- |
| 背景・帯・集計・情報欄 | 直角の面。共通Imageの既定値を角丸にしない |
| 画面切り替え | 隣接したタブ。選択側に金色の文字と下線 |
| 強化／新築 | 一つの枠に収めた二択。選択側に金色の下線 |
| 決定操作 | 面取りした金色の面、濃い縁、下側の影 |
| 戻る・閉じる | 直角の枠付きボタン |
| 詳細表示 | 情報欄の右に小さな枠付きの「詳細」 |
| 施設の選択 | 枠付きの行、選択側の金色の枠と左の帯 |
| メンバー・国庫利用 | 四角いチェック欄と✓。メンバーは選択枠も変更 |
| スライダー | 丸い端の細いトラック、縁と縦の溝がある細いつまみ |

## 確認

- Unity 6000.4.3f1でコンパイルし、Countryを再生した。
- 新築を選択し、施設行をクリックした後も新築側のSelectedがtrue、強化側がfalseだった。切り替え状態とフォーカスを分けた。
- メンバーをクリックした後も育成タブのSelectedがtrueのまま残り、✓と金色の選択枠が表示された。
- 国庫利用のON／OFF、効果詳細の表示と閉じる操作を確認した。
- 1280×720と844×390で4画面を表示し、TMPの領域外表示は0。各ページと同名のPNGとJSONを保存した。
- 844×390でタブの高さは112 × Canvas倍率0.3984199 = 約44.6px。タブの操作範囲を維持した。値はtab-target.jsonとcanvas-scale.jsonに保存した。
- 保存済みPrefabの角丸画像参照は、配分行のスライダートラックと塗りの2件のみ。政務画面全体・施設行・メンバー枠の角丸画像参照は0件。
- 面取り用の3つのGraphicにはCanvasRendererがある。決定ボタンの面・縁・影が描画されることを画像で確認した。
- 新しいC#コンパイルエラーやUI実行例外はなかった。console.jsonには以前から存在するMetalのmemoryless depth surfaceの通知がある。

資源計算・配分案・工事案・育成選択のゲーム仕様は変更しない。今回は表示と状態表現の修正であり、実機タッチ操作とプレイヤービルドの検証は行っていない。

Countryは保存済み。Editorは再生中で、3月1日にゲーム内時間を停止し、強化・新築画面を開いている。
