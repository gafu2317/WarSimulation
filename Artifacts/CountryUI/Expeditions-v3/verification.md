# 大陸の輪郭・25領地・国名の縁取り

2026-10-28追記：領地を引き伸ばした区切りは、ユーザーの「領土の区切り方が気持ち悪い」という指摘を受けて撤回した。現在の境界は [Expeditions-v4](../Expeditions-v4/verification.md) を参照する。大陸の輪郭、25領地、国名の縁取りは継続する。以下はv3当時の検証記録。

2026-10-28。既存のUnity 6000.4.3f1、Countryシーンで確認。実装と動作検証は完了、見た目はユーザー確認待ち。現行仕様は [UI](../../../docs/Country/UI.md#遠征)、入口は [国家ドキュメント](../../../docs/Country/README.md)。v2の16領地の輪郭と国名表示を更新し、本拠地だけの画像と訓練・編成の共通UIは維持する。

## 変更

- 大陸を非対称の輪郭へ変更。北東の半島、北と南の湾、細かな岬を曲線でつなぐ。海と領地の単色表示を使い、地形の背景画像は追加しない。
- 領地を16から25へ増加。自国は1、周辺3国は各8。旧16領地のID・名称・拠点座標を残し、9領地を追加して境界を作り直す。本拠地の画像は4個のまま。
- 海岸と論理地図の対応を三角形ごとの変形に変更。領地の辺も同じ位置で分割し、深い湾で領地が重なる・海を塗る・拠点が領地の外へ出る問題を修正する。表示とクリック判定には同じポリゴンを使う。
- 国名を明るい太字と濃紺の縁取りに変更。4国で `NotoSansJP-Regular SDF - Country Map.mat` を共用する。文字色は `#FFFCEF`、縁は `#131D26`、OutlineWidthは0.45、OutlineSoftnessは0。通常のUI用マテリアルは変更しない。
- `Update Expedition Map` で初期の地図を再作成し、既存の `Set Up Expeditions` は保存済みの地図からUIを設定する。
