# 訓練開始・予約の旗

2026-11-02。読みにくいと指摘された教本のボタンを撤回し、広い一枚の旗面へ一行のラベルを置く訓練旗へ差し替えた。実装・動作確認済み、見た目はユーザー確認待ち。現行仕様は [国家UI](../../../docs/Country/UI.md#配分育成と遠征一覧のモチーフ) と [月初の政務UI](../../../docs/Country/月初の政務UI.md) に反映した。

## 素材と接続

- built-in image_genで [TrainingPennantParts-v1.png](../../../Assets/Images/UI/Country/Buttons/TrainingPennantParts-v1.png) を生成。旗面・支柱の2つのSpriteを1枚から切り出し、画素とアルファは加工していない。[生成指示](image-prompt.md)、[原本・切り出し・SHA256](image-assets.json)。
- 共用する `CountryTrainingCommand.prefab` の画像を置き換え、既存の本アイコンとTMPラベルを別オブジェクトで重ねた。旗面は9-sliceで伸縮し、中央に折り目や部品の境界を置かない。光沢・発光の演出は追加していない。
- 入力範囲は440×112、ラベルは32のサイズで「今月の訓練を開始／来月の訓練を予約」を一行で表示する。文字は濃紺、旗は淡い灰緑。アイコンと切り欠きを避ける余白を確保した。
- 支柱は旗面と一緒に動き、`CountryButtonTint` で状態色へ追従する。文字と本アイコンは既存の `CountryButtonFeedback` で別の深さへ沈む。
- 旧ページ・しおり・分割ラベルを訓練Prefabから除き、不要になった政務パネルの分割ラベル参照を削除した。訓練の確認・開始・予約の処理は従来のまま。
- `WarSim > Country > Set Up Training Pennant` で訓練ボタンと政務参照だけを設定できる。全モチーフの生成元も新しい旗を使う。

## 確認した内容

- [設定検査](setup.json)：政務内のボタンとラベル参照、新しい2種のSprite、表示ラベルが1つで折り返さないこと、支柱が入力を遮らないこと。
- HD1280×720と844×390で「今月の訓練を開始」「来月の訓練を予約」を確認。対象画面内の文字あふれ0、旧ボタンの同時表示0。
- 対象0人では無効、兵士を追加すると有効。ボタンから開始確認を開き、確定後に兵士が訓練中となり開始ボタンが無効になる。
- 押下で主面Y=0→−3、拡縮1→0.975、文字Y=0→−1.5。解放後に復帰。支柱の状態色が主面と一致し、停止中の国でも演出が動く。
- 2日には翌月の予約表示へ切り替わる。予約確認を開く・戻る・政務を閉じて開き直す操作でも選択とラベルを保持する。
- Unityコンパイルエラー0。[コンパイル](compilation-final.json)。最終Consoleは既知のmemoryless depthの2件で、UIの実行時例外や今回のフォント取り込みエラーは確認していない。[Console](console-final.json)。

最初の設定検査では、既存Prefab内に残った旧ページと非表示ラベルを検出した。不要な子だけを取り除き、ラベルを表示へ戻してから検査とPlay確認を行った。対象PrefabのGUIDと既存ラベルの参照は保持した。

## 範囲と制限

配分の指令書・建設の看板・遠征の巻物・共用の旧画像・Noto Sans JP SDFのファイル内容と更新日時は作業前後で一致。[照合結果](protected-after.json)。旧教本の画像は履歴用の既存atlas内に残るが、現行の訓練ボタンでは使用しない。

既存Editorだけを使い、起動・再起動、シーン保存・再読込コマンドは実行していない。Playは最後に停止した。一方、Countryシーンは開始時dirty=true、終了時dirty=falseとなり、ファイルの内容と更新日時が変わっている。原因・保存主体を断定できないため、シーンが不変だったとは記録しない。[前](get_scene_info-before.json)・[後](get_scene_info-final.json)。既存の変更を巻き戻す操作は行っていない。

実機タッチ・物理キーボード・Playerビルドは未検証。局所的な画像差し替えのため新たな自動テストは追加していない。[操作ログ](actions.json)、[変更差分](diffs/)、[実装と見た目の状態](status.json)。
