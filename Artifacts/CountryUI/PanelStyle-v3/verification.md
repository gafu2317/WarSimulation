# PanelStyle-v3の実物確認

2026-10-26。実装中の試作であり、ユーザーの見た目の承認前。新しい完成画面の生成案は提示せず、UnityのScreenCaptureで取得した画面を確認に使った。

## 実装した共有部品

- `Assets/Prefabs/Country/UI/CountryWorkboard.prefab`：配分のスクロール領域、建設・育成の左右を含む領域の3か所で共有する作業面。布地、細い9-sliceの金属縁、浅い影を分離した。
- `Assets/Prefabs/Country/UI/CountrySectionPlaque.prefab`：建設の施設名と育成の学校名の2か所で共有する名札。文字と記号は既存のTMPと図形のまま保持する。
- `Assets/Prefabs/Country/UI/CountryEffectStrip.prefab`：建設の効果欄と配分行の効果欄で共有する帯。面取りした細い輪郭、小さい折り返し、押下で沈む面と影を持つ。
- `Assets/Images/UI/Country/Bookcloth-v1.png` と `PewterRim-v1.png`：3種類の部品を組み立てる共有素材。内蔵image_genで素材を生成した。原本のコピーをAssetsへ保存し、生成条件とハッシュは `materials.json` に記録した。

完成パネル、文言、数値、アイコンを一枚絵に焼き込んでいない。布地の繰り返しと9-sliceの縁を使い、サイズ変更でも織り目と角の縮尺を保つ。最初の表示で布目が大きな縞に見えたため、布地の取込解像度を256とし、MipMapとTrilinearを使って干渉を抑えた。

上部ナビゲーション、外側の背景、フッター、通常の操作ボタン、メンバーカード、収入画面、国のHUDを一括で置き換えていない。PanelStyle-v2の却下された描画クラス・Prefabは再導入していない。

## 設定と保存

`CountryGovernmentArtBuilder` の `WarSim > Country > Set Up Government Materials` で共有Prefabと既存の政務・配分行Prefabを更新する。通常の政務UI再生成からも共通の設定を呼ぶ。作業前の対象ファイルは `before/` に控えを置いた。

今回の設定はシーンを保存・再読込しない。接続時からCountryシーンに未保存変更があり、確認後も同じシーンを未保存のまま保持した。ユーザーの指示後はEditorの起動・再起動を行っていない。`AGENTS.md` の起動規則もAIによる起動・再起動禁止へ更新した。

- 1280×720と844×390で、収入・配分・建設・育成を実際に表示し、画面を目視した。布地、金属縁、名札、折り返しが表示され、細かい布目の大きな縞が解消したことを確認した。
- 建設では「精霊使役学校」の長い名称と新築への切替も確認した。
- 各表示のTMP領域外表示は0件。完全に表示された操作部の最小辺はPC約74.67px、小さい横画面約44.62px。スクロールで切れている行は完全表示の判定に含めていない。
- 月末の進行から2月1日の収入画面が開くこと、上のタブで直接切り替わること、配分と建設の効果詳細の開閉、育成メンバーの選択を確認した。
- 効果の帯の押下中に面が3単位沈み、描画色が0.72へ下がることを記録した。入れ子の影は押下前に表示、押下中に非表示、離した後に表示へ戻った。装飾は入力を受けず、既存の操作対象を使う。

新しいC#コンパイルエラー・C#実行時例外は確認されなかった。以前からのCS0618警告とMetalのmemoryless load/storeメッセージはConsoleに残っている。ゲームルールの変更はなく、今回はEditModeテストの追加・再実行を行っていない。実機のタッチ操作やターゲット向けビルドは今回の確認に含めていない。

`display-check.json` が表示寸法、`shared-prefabs.json` が共有Prefabの参照数、`pc-actions.json`・`final-actions.json`・`press-actions.json` が操作記録。各PNGは同名のJSONと対応する。技術的な確認の成功を、美術の採用やユーザー承認として扱わない。
