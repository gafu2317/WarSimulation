# 月末進行の日めくりカレンダー

2026-10-29、Unity 6000.4.3f1の既存Editorで確認。時計の針を日めくりカレンダーへ変更し、月と日を実際の `DateManager` から表示する。日付通知を受けたとき、前日の紙が上へ縮んで新しい日付が現れる。進行バーと停止操作は維持する。ゲームの時間計算は演出から変更しない。

- [1280×720](Progress-1280x720.png) と [844×390](Progress-844x390.png) で文字あふれなし。後者は二桁の日付で確認。
- 検証用に日送りを遅くし、複数の日付変更で旧日付の紙と新しい日付への切り替えを確認。停止操作で時計が止まり、画面が閉じることを確認。
- 通常速度に戻し、襲撃をOFFにした状態で月末進行すると翌月1日に到達してポップアップが閉じた。

見た目はユーザー確認待ち。実機での確認は行っていない。
