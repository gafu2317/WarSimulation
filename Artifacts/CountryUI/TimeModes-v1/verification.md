# 時間操作の3モード化

2026-11-05。月末ボタンを撤去し、時間操作をひとつの大きいアイコンボタンへ変更した。停止→通常進行→2倍速→停止で循環し、表示は現在モードを示す。停止は赤い正方形、通常は緑の三角1個、2倍速は濃い緑の三角2個。文字は置かない。

現行仕様は [UI](../../../docs/Country/UI.md#上の帯と時間操作) と [時間進行](../../../docs/Country/時間進行.md)。月初の報告・襲撃・他画面を開く処理での停止は同じ時計へ接続する。日付の途中で速度を切り替えても、その日の進み具合を保つ。

## 確認した範囲

- 既存EditorのMCPでコンパイルを確認。Consoleのエラー0件。
- `DateManagerTests` 25ケースと `CountryTimeControlsTests` 5ケース、合計30ケース成功。[tests.json](tests.json)。既存Editor内で新しいfixtureをケースごとに作り、NUnitのSetup・テスト・Teardownを直接呼んだ。Test Runnerの実行結果ではない。
- 通常の2倍の日付進行、速度変更・一時停止時の1日未満の保持、2倍速の重複指定、日次通知による中断、月末・2月・年越しでの停止を確認した。従来の検証用月末APIも退行なし。
- 実際のHUD Prefabのクリックイベントで停止→通常→2倍速→停止を確認。外部からの停止、日付表示、再有効化、アイコン色、文字と月末ボタン・専用ポップアップの撤去を確認した。押下演出のAwake・OnEnableで部品参照も検査した。
- UIの描画と入力確認はスマホ横画面844×390のみ。分離したプレビューシーンに実Prefabとカメラを置き、3モードを描画した。街の3Dモデルは含めず、背景は単色のUI確認用。[layout.json](layout.json) に入力範囲約95.6×44.6px、上帯の文字のはみ出し0件を記録した。
- [input.json](input.json) で実GraphicRaycasterによる入力対象、ExecuteEventsの押下・解放と面の沈み込みを確認。分離プレビューで更新を手動実行した確認で、実機のタッチ操作やアニメーション時間の計測ではない。
- 開いているCountryの新ボタン・3アイコン・押下演出の参照が有効で、旧ポップアップがないことを読み取り確認した。[editor-state.json](editor-state.json) で生成処理の再実行によるPrefab差分なし、シーンの未保存変更なしを記録した。
- Editorの起動・再起動、開いているシーンの保存・再読込は行っていない。[file-check.json](file-check.json) でシーン18ファイルのハッシュ不変を確認した。

## 採用状態と今回の範囲

時計と3モードの動作確認は完了。大きい背景付きの見た目は却下され、[v2](../TimeModes-v2/verification.md)の背景なしの小さめの記号へ変更した。実機・Playモード・WebGLビルド・itch.ioの更新は今回行っていない。

旧 `CountryTimeProgressPopup` と日めくり素材は保管し、HUDへの接続を外した。`AdvanceToMonthEnd()` は既存の検証用APIとして同じ時計内に残し、ゲームの時間ボタンからは呼ばない。旧日めくりの検証記録を現行UIの採用状態として扱わない。
