# 施設の大きさ・物見櫓・市場の修正 — 2026-11-01

状態: 既存のUnity Editorで実画面を確認し、Countryシーンへ保存済み。見た目はユーザー確認待ち。

住宅の大小を直す依頼ではなく、住宅に対して小さすぎる施設を調整する依頼として反映した。住宅4モデル（Fantasy_House / MerchantHouse / WorkshopHouse / CrimsonRowhouse）の幅・奥行きの候補は変更前と一致する。施設拡大と櫓の離隔に必要な範囲で、敷地・周辺道路・住宅の配置を組み直す。

## 修正内容

- 施設25種類を用途に応じて拡大。衛兵所と闘技場は1.6倍、市場会館は1.5倍、診療所は1.35倍、教会と兵舎は1.3倍。王城・学校・商工業施設などは1.1〜1.25倍を中心に調整。幅・奥行き・高さの比率を保つ。倍率一覧は [facility_scales.json](facility_scales.json)。
- 物見櫓8基を城壁の内側へ移し、6×6mの範囲を配置表で確保。石壁の最大厚を使った計算でも櫓と壁の間は最低0.5m。周辺の道路も櫓を避ける。床を持ち上げて交差を隠す方法は使わない。
- 屋台16軒・全10種類を4列へ揃え、各2列の店先を買物通路へ向ける。南北の大通りと東西の商人道の交差を空ける。井戸・掲示板・籠・商品も道路外の列の端へまとめる。欠けた屋台を周囲へ散らして補充する処理を除く。
- 比較用の新旧モデルは共通の敷地を使用し、初期表示はCityV2を維持。施設バナーの30対象とミニマップを再接続。城の初期注視点は国の中心から `(-1.5, 6, 130)`。
