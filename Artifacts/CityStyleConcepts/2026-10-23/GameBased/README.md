# 同じゲーム画面で比べる12の建築案

新モデルの市場付近の実機キャプチャを編集元として、組み込み image_gen ツールで各案を独立生成。前回の独立した街の画像は参照していない。

- 編集元：`00_reference.png`
- 一覧：`index.html`（画像を押すと拡大、元画像へボタンで切替）
- 全生成プロンプト：`prompts.json`
- 各画像の保存元と照合値：`generation_results.json` / `manifest.json`
- 配布用ZIP：`Game_Based_12_Concepts.zip`

道路・区画・建物配置・視点・ゲームの描き込み密度を保つよう指定し、屋根・窓・入口・張り出しなどの形も変更。画像生成のため細部には差があり、画素単位の一致ではない。検討用の画像であり、Unityのシーンや3Dモデルへの実装は行っていない。
